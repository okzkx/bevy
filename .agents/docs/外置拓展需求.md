### 2. Remote 虚拟鼠标 2D 可视化（2026-10-10 登记）

- **来源**：2026-10-10 用户增补（[3.13 Remote 虚拟鼠标](3-静态取数链路/3.13-Remote虚拟鼠标/README.md)收官之后）。3.13 交付了注入与自验闭环但画面上无虚拟光标——AI 在操作什么、点到哪里，人只能靠数值读回间接判断；登记为外置拓展，不回改已收官段。
- **内容**：在自研渲染器画面上叠加显示虚拟鼠标光标（2D overlay），实时反映 Remote 注入的光标位，让 AI 的虚拟操作对人可见、可录像。数据源现成：注入经官方通路自管光标位，`Window::cursor_position()` 直接可见（3.13 段 README 钉）。
- **恢复条件**：需要向用户演示/录制 AI 虚拟鼠标操作，或排查虚拟鼠标坐标链（注入→光标位→下游消费）时捡起；挂起期间不阻塞任何段。
- **边界**：只画不注入——不加新输入通路、不碰真实光标、不承 3.13 判定线责任（双闭环证据已留档，本条不补验也不改写）。实现形态（egui overlay vs 自绘管线）与逻辑→物理像素换算开工时钉明，注意 3.7.5 的 ppp 双域坑（tessellate 顶点=points 域）。
