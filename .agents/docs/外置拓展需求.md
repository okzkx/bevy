### 2. Remote 虚拟鼠标 2D 可视化（2026-10-10 登记）

- **来源**：2026-10-10 用户增补（[3.13 Remote 虚拟鼠标](3-静态取数链路/3.13-Remote虚拟鼠标/README.md)收官之后）。3.13 交付了注入与自验闭环但画面上无虚拟光标——AI 在操作什么、点到哪里，人只能靠数值读回间接判断；登记为外置拓展，不回改已收官段。
- **内容**：在自研渲染器画面上叠加显示虚拟鼠标光标（2D overlay），实时反映 Remote 注入的光标位，让 AI 的虚拟操作对人可见、可录像。数据源现成：注入经官方通路自管光标位，`Window::cursor_position()` 直接可见（3.13 段 README 钉）。
- **恢复条件**：需要向用户演示/录制 AI 虚拟鼠标操作，或排查虚拟鼠标坐标链（注入→光标位→下游消费）时捡起；挂起期间不阻塞任何段。
- **边界**：只画不注入——不加新输入通路、不碰真实光标、不承 3.13 判定线责任（双闭环证据已留档，本条不补验也不改写）。实现形态（egui overlay vs 自绘管线）与逻辑→物理像素换算开工时钉明，注意 3.7.5 的 ppp 双域坑（tessellate 顶点=points 域）。

### 3. 旋转拖拽松手后的欧拉显示连续性（2026-10-14 登记）

- **来源**：2026-10-14 用户实测反馈（[4.6 实测缺陷修复段](4-可靠增量链路/4.6-实测缺陷修复/README.md)收官之后）：拖"Y 轴"旋转松手时 X/Z 两框数值会突跳（±180°）。已核实**不是缺陷**——真实旋转（四元数、画面）恒等，松手瞬间面板从拖拽缓存（按下帧表示分支）切回 `to_euler(YXZ)` 规范分解（中间轴 X 被 asin 钉在 [-90°,90°]，越界由 X/Z 各 ±180° 等价吸收），与 Unity Inspector 同款行为；性质与处置建议已记录在[4.6 施工记录 §3 遗留](4-可靠增量链路/4.6-实测缺陷修复/4.6.1-4.6.2-实测缺陷修复施工记录：注释清扫与拖拽旋转闪烁.md)。用户要求消除"松手显示跳变"，当日拍板接受现状、外置登记。
- **内容**：让属性面板旋转三框在松手后继续显示拖拽期缓存的三元组（显示连续性），直到选中实体变化、外部途径改值或用户再次编辑，才回落规范分解读数；可选另一形态 = 松手时把缓存规范化回写显示。只动 egui 读数策略，不碰 `apply_transform_edit` 写路径与四元数本体。
- **恢复条件**：显示跳变实际干扰编辑体验（如用户在松手后要基于显示值继续微调、或读数对比教学场景需要连续读数）时捡起。
- **边界**：挂起期间姿态恒等是既有事实（4.6 判定线已验），本条只关"显示读数"不关"旋转正确性"；若实施，需钉明"缓存显示与 World 分解值不一致期间，面板读数不再逐字镜像快照"的新账面口径，并防外部改值（BRP/热重载）时的陈旧显示。
