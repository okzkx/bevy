## 放置约定

- 分站笔记一站一篇，命名 `第N站：主题.md`（冒号用全角 `：`）；同一站后续问答的结论按主题分节追加进同一篇。
- 优化候选集中写入《代码阅读优化计划》，用 `O1`、`O2`……编号；编号只是本目录的索引，不占施工编号，也不等于授权施工。
- 分站笔记开头写本站一句话说明与进度行，代码引用写符号名不写行号。
- 阅读中发现的结构优化记入《代码阅读优化计划》；具体正确性缺陷回填对应步骤文档或《[待修复清单](../待修复清单.md)》，均不在本目录直接施工。
- 跨站通用、可独立传播的机制知识按入口篇 §九 另立知识点文档，分站笔记只链接过去。
