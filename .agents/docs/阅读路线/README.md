# 阅读 ash_renderer

这是一条读 ash_renderer 的路线，不是引擎手册。目标是把三万多行代码读成一张图：每个对象谁持有、谁写、谁读、什么时候可以复用或销毁。

## 读法

1. 先读《[概念](概念.md)》。帧槽、fence、票据、屏障、描述符、bindless、indirect 这些词先有准确意思，后面不会边读边猜。
2. 再读《[路线](路线.md)》。六段读序，每段告诉你先看哪些文件、读完能回答什么。
3. 按路线读源码。卡住时翻对应的深读篇；深读篇讲机制，不替代源码。

**源码在前，文档在后。** 本文档按 2026-11-19 的 `main=10686d9ea` 核对；代码变了以源码和运行日志为准。

## 约定

- 代码引用写符号名，不写行号：文件会移动，符号名能搜到。
- “现状约束”表示代码目前就是这样，不是推荐做法；“待决”表示还没有结论。
- 路线篇只定顺序和检查点，机制细节在深读篇；同一件事不在两处各讲一遍。
- 阅读中发现的结构候选或明确缺陷，回填《[待修复清单](../开发步骤/待修复清单.md)》；本目录只负责读懂代码。
