# 7.10.1-7.10.3-PostUpdate传播块归因与治理施工记录：trace归因仪器、可见性集群豁免与候选计数治理

> 2026-10-21 当日立案当日施工收官（帧治理四段之三）。本篇写归因实数、真凶与治理实做；结论先行：**真凶不是 transform 传播（候选①否，仅 0.13ms），而是 bevy 可见性集群每帧对全部 primitive 重算 CPU 可见性（~5.8ms/帧）——而本渲染器零消费它**。

## 0. 归因仪器（7.10.1，待决 1 钉明）

- **选型：bevy `trace`/`trace_chrome` 特性**（零代码侵入，胜出自写有序打点）。`bevy_ecs/trace` 给每个系统发 `info_span!("system", name = 类型名)`（function_system.rs:51，插件构建期建、parent: None），`bevy_log/tracing-chrome` 退场落 chrome JSON（`TRACE_CHROME` 环境变量定输出路径）。构建 = `cargo build -p ash_renderer --features bevy/trace_chrome,bevy/trace`。
- **聚合器**：`.temp/7.10/aggregate.py`——chrome JSON 逐行流式（zero_day trace 1.7GB），B/E 事件按线程栈配对，按系统短名聚合（次数/合计/均/最大）；窗口过滤跳过进场段。调度窗口配对要按**精确显示名**（`"name":"schedule:`）——`check schedule ticks` 辅助 span 会混入计数（首版实踩）。
- **环境钉**：trace 开销使进场与读数整体变慢（zero_day trace 全程 ~1.7GB/百秒），归因读数只取系统均值的相对量级，绝对值供帧墙对照时注明带 trace 开销。

## 2. 治理实做（7.10.2）

### 治理 A：可见性集群豁免（scene/mechanism/visibility_exempt.rs，新增）

- **依据**：全仓 grep 零引用 `Visibility`/`InheritedVisibility`/`ViewVisibility`——可见性归 GPU 侧（5.x 设计成果），宿主无 bevy 渲染管线，`ViewVisibility` 无人读。整条集群是每帧 O(N) 纯浪费。
- **形状**：PostUpdate 逐实体幂等移除三件套（`visibility_exempt` 系统 + `AshVisibilityExemptPlugin`，main.rs 装配）。Commands 本帧调度末落地——新入场景实体（BRP spawn/glTF spawn 波）多付一帧可见性成本，下帧捕获归零。相机实体不豁外（frame.rs 只读 Projection/GlobalTransform）；整场景失明后 check_visibility 连"视图"都不再命中，集群退化为空查询走访。
- **传播正确性**：`GlobalTransform` 传播链不依赖 Visibility——BRP set-transform 写后读回一致、Mesh3d 查询/树窗零回退（判定线 3 实证）。

### 治理 B：update_ledger 候选计数去走访（ledger.rs）

- `scan_candidates` 原实现 = 每帧 `Query<(With<Mesh3d>, With<MeshMaterial3d>)>.iter().count()`——O(N) 走访只为一个统计数。集合恒等：update_ledger ②对每个持有两组件的实体入行，**候选集 == 账本行集**——替换为 `ledger.rows.len()`（语义不变，0.2ms 级收益入账）。

## 3. 待决项落定

- **仪器选型**：trace_chrome 特性（零代码侵入 + 每系统实数），自写打点退役——7.11 残余区可复用同一仪器底座（一份仪器两段受益，待决 3 兑现）。
- **治理范围**：`mark_dirty_trees`（0.55ms，bevy_transform 内部关系脏标记走访）与 `calculate_bounds` 残留（0.17ms，查询形状不含 Visibility）业务侧无治理空间，**如实立账转出**——不 fork 引擎（待决 2 兑现）。
- **animate_targets（0.35ms）**：zero_day 场景带动画 clip 但无播放器消费——可顺延选项 = main.rs 装配面剔 bevy_animation 插件；本段不做（超出"传播块治理"最小范围），顺延 7.11 或外置议题裁决。

## 5. 遗留与顺延

- **animate_targets 0.35ms**（PostUpdate 驻留）：顺延裁决剔 bevy_animation 插件的取舍（main.rs 装配面改动，归 7.11 或外置议题）。
- **mark_dirty_trees 0.55ms / calculate_bounds 0.17ms**：bevy 内部，转引擎侧议题/挂账。
- **update_ledger 残余 0.75ms**：4.1 已知成本（Changed/Removed 查询迭代 O(匹配实体)）——进一步收敛需组件生命周期钩子/observer 化，超出本段范围，如实立账。
- **trace 仪器常驻成本**：归因仪器仅在 `--features bevy/trace_chrome,bevy/trace` 构建下生效（常规构建零影响）；聚合器脚本存 `.temp/7.10/`，7.11 残余区归因复用。
