# 施工计划：egui按需求值拆解（7.8）

> 2026-10-21 立案。帧治理四段（7.8~7.11）第一段，快赢先行——立案见[路线图步骤 7 节](../../学习目标实现步骤.md)追加说明。

> **一句话说明**：本计划把 egui pass 从"每帧必跑"改为"输入/快照节拍触发才重求值、其余帧复用上一帧 shapes"，并把面板字符串从每帧 `format!` 改为随快照节拍重建（命中 egui shaping 缓存）；本计划不主张新 UI 功能、不改 7.6 帧率同步面，tessellate/图集等绘制半边成本不在本段主张（如实记边界）。

## 0. 现状核实（2026-10-21 立案期，均实测/源码复读）

- **面板内容 ~5ms、框架底价 0.55ms（实测）**：BRP 虚拟鼠标把两窗口全关后 `monitor_stats.egui_pass_ms` 5.5→0.55，帧墙钟 28→22.4ms、fps 34→43——收益全在面板内容的 pass 求值，集成框架本身便宜。
- **每帧整树重求值属实**：`run_egui_pass`（overlay/framework/ui.rs，Update 链）每帧 begin_pass→建全部窗口→end_pass；面板内容节拍实为 0.5s（FpsSnapshot/PerfPanelCache/MonitorHistory 采样节奏），立即模式默认每帧重跑是默认用法不是硬约束。
- **字符串每帧重排版属实**：调试面板几十行 `ui.monospace(format!(…))` 每帧生成新字符串，egui 文本 shaping 缓存按内容命中——ms/fps 数字逐帧变化使缓存全 miss；快照未变的行本可命中（7.5 修复后这些值 0.5s 才变）。
- **复用前提成立（属实）**：`EguiFrame`（shapes + ppp + screen_points）是独立产出资源，draw_frame 逐帧消费；egui Context 状态（记忆/图集/层）在两次 pass 之间自持；3.13 仲裁 `layer_id_at` 读 Context 状态不依赖当帧 pass 已跑（施工时以拖拽实测钉明）。
- **触发源清单在案**：输入事件（键/鼠/滚轮/窗口焦点尺寸）经 EguiInput 桥逐帧喂入；面板内容节拍=0.5s 快照；窗口开闭=总控/✕ 事件。三者之外的帧都是纯复用候选。

## 1. 任务拆解

### 7.8.1 基线取证

- 已有实数钉入施工记录（立案期 A/B：全关 0.55/全开 5.5、墙钟 28→22.4）；补一组"面板开着但无输入"的稳态分布（egui_pass_ms 逐帧），作 7.8.2 节拍化的对照面。

### 7.8.2 pass 节拍化（按需重求值 + shapes 复用）

- 触发条件成形：输入桥有未消费事件 ∨ 任一快照到期（0.5s）∨ 窗口开闭变化 ∨ 首帧；其余帧跳过 pass，`EguiFrame` 保持上一帧产物（draw_frame 照常消费，画面静止即正确）。
- 积压语义：跳过帧攒下的事件在下一次 pass 一次性喂入（RawInput 合并），指针位置用最新值；拖拽/滚轮等连续交互天然逐帧触发，不丢帧。
- BRP/相机仲裁正交：`layer_id_at` 读 Context 状态与 pass 是否当帧执行解耦；相机控制与 UI 的指针仲裁行为零变化（实测钉明）。

### 7.8.3 字符串节拍化 + 交互零回退

- 面板字符串随快照重建：快照未变的行复用原字符串（不重新 `format!`），命中 shaping 缓存；逐帧必变的行（如有）如实保留并记边界。
- 交互零回退：面板开关/点选/拖拽编辑/滚轮/着色模式单选逐项过（拖拽期间 pass 逐帧跑，编辑链路不受节拍化影响）。

## 2. 判定线草案

1. **基线证据链**：同场景同机位 pass 毫秒对照——zero_day 全开 ~5.5ms → 稳态 ≤2ms；面板全关底价 0.55ms 持平；帧墙钟同步收窄。
2. **交互零回退**：开关/点选/拖拽/滚轮逐项过；拖拽期间画面逐帧跟随（无隔帧迟滞感，实测读数）。
3. **正交性**：7.6 帧率同步行为不变（FrameSyncSettings/WinitSettings 零改动）；BRP 方法族读数不回归。
4. **回归**：库测试全绿 + 九脚本抽测零回退。
5. **工程闸门**：零 VUID、exit 0、clippy 全净。

## 2.5 收益边界（如实记）

- 复用帧的 tessellate/顶点环写入仍逐帧执行（形状未变结果相同）——若实测占比可观，缓存 tessellation 结果挂账或并入 7.11；本段不主张。
- 监控窗曲线（egui plot）每帧重画属内容侧，随 pass 节拍化整体降频，不单独立账。
- 面板全关时 pass 求值已近底价，本段收益集中在"面板开着"的开发态——发货态调试面板不存在，收益面是开发体验与压测读数纯度。
