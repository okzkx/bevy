# 7.8 egui pass 按需求值（M6 追加段）

对应[步骤 7 README](../README.md)与[路线图步骤 7 节](../../学习目标实现步骤.md)。

**目的**：zero_day 稳态帧 egui pass 求值 ~5.5ms（7.8 立案期实测，框架底价仅 0.55ms）——面板内容按快照节拍（0.5s）变化，却每帧整树重求值、每帧重排版全部字符串。本段按"按需重求值 + 复用 shapes + 字符串节拍化"收敛，为帧治理四段（7.8~7.11）的第一段。

**一句话说明**：本段把 egui pass 从"每帧必跑"改为"面板内容节拍或输入事件触发才重求值、其余帧复用上一帧 shapes"，并把面板字符串改为随快照重建（命中 egui 文本 shaping 缓存）；不主张新 UI 功能，不改 7.6 帧率同步与 BRP 行为面，绘制半边（tessellate/图集）成本如实记边界。

**当前状态：⬜ 已立案（2026-10-21 用户增补，帧治理四段之一），[施工计划](施工计划：egui按需求值拆解.md)。**
