# 步骤 7：大型正式场景（M6）

对应[执行路线图](../学习目标实现步骤.md)。本 README 是步骤索引与材料目录；各段任务面板在段目录 README（开工时立），段施工计划随段立案入段目录。

**目的**：步骤 5/6 的 GPU-driven 与流送机制已全部施工收官后，把正式场景内容接入底座——内容超出驻留预算时由流送承载、细节由 LOD 承载，让步骤 5/6 的机制在真实资产多样性下复验，并为步骤 8/9 提供长期验收场。

**一句话说明**：本步给已成立的 GPU-driven 与流送底座接入一个大型、好看的正式场景（Sponza 基座＋zero_day 规模＋Poly Haven 材质多样性），为步骤 8/9 提供材质与光照多样性的真实底座；本步不主张任何渲染画质特性（归步骤 8/9），也不做剔除/LOD/流送的机制扩展（缺陷走 7.4 单独立账修复）。

**当前验收状态：✅ 步骤级验收归档完成（2026-10-20，[验收复核](7-步骤7验收复核.md)）——7.1～7.4 四段全链施工收官，M6 完成、步骤 8 解禁**。挂账 F25（6.2 选档链潜伏缺陷，22 行口径仍绿）/F26（zero_day 帧时间空洞）见[待修复清单 §7](../待修复清单.md)。**2026-10-21 追加：7.5 持续监控与性能修复 ✅ 施工收官（当日立案当日施工）——FPS 恶化根因修复（PerfLedger 无界账），独立验收不改已归档口径。** **2026-10-21 再追加：7.8~7.11 帧治理四段已立案（用户增补"每点优化都必须要修"，逐段施工）——zero_day 稳态帧 CPU ~29ms 全账劈开的治理计划；四段段目录与施工计划已齐备（2026-10-21 补齐）；**7.8 ✅ 施工收官（当日立案当日施工，稳态 pass p50 0.0/帧墙 21.25），7.9~7.11 逐段开工。** **2026-10-21 三追加：7.12 资产加载指示弹窗已立案（用户增补小段，同日修订：进度条改菊花旋转、纯存在性提示）——右下角纯显示加载弹窗，加载期置 7.8 面板触发、完成冷却隐藏；[段目录与施工计划](7.12-资产加载指示弹窗/README.md)已齐，待施工。**
