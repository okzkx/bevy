# 步骤 7：大型正式场景（M6）

对应[执行路线图](../学习目标实现步骤.md)。本 README 是步骤索引与材料目录；各段任务面板在段目录 README（开工时立），段施工计划随段立案入段目录。

**目的**：步骤 5/6 的 GPU-driven 与流送机制已全部施工收官后，把正式场景内容接入底座——内容超出驻留预算时由流送承载、细节由 LOD 承载，让步骤 5/6 的机制在真实资产多样性下复验，并为步骤 8/9 提供长期验收场。

**一句话说明**：本步给已成立的 GPU-driven 与流送底座接入一个大型、好看的正式场景（Sponza 基座＋zero_day 规模＋Poly Haven 材质多样性），为步骤 8/9 提供材质与光照多样性的真实底座；本步不主张任何渲染画质特性（归步骤 8/9），也不做剔除/LOD/流送的机制扩展（缺陷走 7.4 单独立账修复）。

**当前验收状态：⬜ 步骤级未验收——7.1～7.4 四段均未开工。2026-10-20 纯文档立案：内容来源拍板（导入现成资产包三场景组合）＋段级拆解，见[路线图步骤 7 节](../学习目标实现步骤.md)。**
