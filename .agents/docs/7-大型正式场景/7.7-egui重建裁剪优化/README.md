# 7.7 egui 重建裁剪优化（M6 追加段）

对应[步骤 7 README](../README.md)与[路线图步骤 7 节](../../学习目标实现步骤.md)。

**目的**：实体树窗口每帧全量重建全部实体行（立即模式声明），zero_day 7159 行规模下 pass 求值是数量级白烧——tessellate 已有裁剪而 pass 求值没有。本段按"拍平缓存 + 只构建可见行"收敛：稳态每帧 egui pass 成本与实体总数解耦。

**一句话说明**：本段把实体树窗口改为"拍平行数组缓存（结构脏信号才重建）+ 每帧只声明视口内行（egui show_rows）"，稳态 pass 成本只随可见行数走；不主张新 UI 功能，BRP scene_tree 共用行语义不养两份，字体图集与绘制半边不受益也不受损（如实记边界）。
