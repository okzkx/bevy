# 7.5 持续监控与性能修复（M6 追加段）

对应[步骤 7 README](../README.md)与[路线图步骤 7 节](../../学习目标实现步骤.md)。

**目的**：用户报告默认 Sponza 场景 FPS 持续走低，而现有观察面只有 0.5s fps 快照与瞬时池读数，抓不到"随时间恶化"的形态——本段把持续监控仪表补齐，再用它在默认场景取证、定位并修复性能缺陷。

**一句话说明**：本段给宿主装上持续的 FPS/内存/显存监控仪表（egui 面板历史曲线 + BRP 无人值守采样通道），用它在默认 Sponza 场景抓取 FPS 恶化证据、定位修复性能缺陷；不主张任何渲染画质与机制特性，修复范围超出小修时独立立账转 7.6。

**当前状态：✅ 施工收官（2026-10-21 当日立案当日施工，判定线五条全过），[施工记录](7.5.1-7.5.4-持续监控与性能修复施工记录：监控仪表、FPS恶化取证与无界账修复.md)。**根因=PerfLedger `derive(Default)` 无界账 + 调试窗逐帧分位数全量排序；修复后全窗口 3 分钟 fps 锁 60.0（修复前 80s 41→27）。
