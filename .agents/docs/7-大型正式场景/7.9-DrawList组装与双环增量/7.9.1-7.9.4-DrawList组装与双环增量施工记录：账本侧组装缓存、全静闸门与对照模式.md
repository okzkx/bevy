## 1. 施工本体

### 7.9.2 组装缓存（账本侧落位）

- **落位（待决 1 钉明）**：`AssemblyCache` 作为 [`InstanceLedger`] 的字段住账本（scene/mechanism/ledger.rs）——变更发现与缓存标记同体（`mark_dirty`/行增删/`set_instance_slot`/材质离容器各变更点顺带 `stale.insert`，不做第二套变更发现）。
- **结构**：`drawable: BTreeMap<Entity, (槽号, 材质身份, alpha<1)>`（Entity 迭代序 = `rows()` 同源 BTreeMap 序，与全量走访产物逐行一致）+ `material_refs` 引用计数表 + `stale` 重估集 + 产物缓存 `slots/materials`（稳定帧零重建，容量复用）。
- **全量重建仅三触发**：首帧播种、`floor_anchor` 翻转、`LodGroups` 登记换代（register 递增换代号，7.9 新增字段）。`pending_rows = 行总数 − 可绘数` 现算，不再单记账。
- **重估闭包注入**：drawlist 提供 `drawability_eval`（槽位 ∧ 锚驻留 ∧ 材质在容器的三态判定，锚解析与 flush 锚腿/tick 需求集同源 `anchor_level`），`assembly_update(&mut InstanceLedger, eval, ...)` 在账本内部维护集合——BTreeMap/HashMap 字段级借用不互斥，避免整账本借用冲突。
- **帧循环借用纪律**：`assemble_update`（&mut 取走重估集）→ 奇偶集 `take_model_dirty/take_lod_dirty` 先取走 → `assembly_view()` 共享借用供环写入与诊断读数全程使用；`write_rings` 签名改共享借用（ledger + AssemblyView + 奇偶集切片）。

### 7.9.3 同族走访门控（residency_tick 全静早退）

- **闸门**：tick 输出的全部决定输入进键（`TickGateKey`：view_proj/屏尺寸/LOD 判据阈值迟滞/预算/半径/fine/floor/gap 模式，浮点按位比较）——键全同 ∧ 账本无脏 ∧ 缺口快照全零 ∧ **冷却表空** → 分组聚合/请求/淘汰/档位需求/位图发布整段早退。
- **首钉（对照实抓）**：冷却表非空禁止早退——"冷却到期 → 重请求 → 资产重驻留"是**时间驱动的可观测状态转移**，静态相机下基准回流依赖它（scene_floor ③ 在 main 过、7.9 首版败的 A/B 定责）；"全静"不是"输出不变"，冷却走账必须每帧跑。
- **参数 16 上限**：tick 原有 16 参数顶满，加相机键历史触顶——只读资源（pool/image_cache/lod_settings/swapchain/snapshot）收拢 `TickResources` SystemParam 束（与 UploadData/FrameInput 同款惯例）。
- **材质环增量化裁决（待决 2 钉明）**：**留全量重写**。实数 rings 0.9ms ≈ CPU 总量（~1.8ms）的一半但占帧墙 <5%；更重要的是材质环全量现读**就是 4.2 材质内容语义的本体**（材质参数/贴图槽变化每帧自动生效）——增量写会把内容变化冻结在旧值，需另开内容变更通道才能补齐，简单性与语义风险权衡后如实留全量。

### 7.9.4 对照模式与一致性验证

- **对照模式产品化（待决 3 钉明）**：**BRP 开关**（`drawlist_verify_set`），非一次性临时代码——开启后帧循环逐帧跑全量参照走访（`assemble_reference`）与增量缓存逐字段比对（槽号列表逐行 / 暂缓数 / 材质集 / alpha 计数），结果进 `draw_stats` 的 verify 块（比对帧数/不一致数/最近不一致摘要）。关闭零成本；红线同 5.2：只进计量不驱动绘制。

## 2. 施工首钉与订正（对照模式实抓两枚）

1. **BRP 内容写入点直标重估**：mutate 落在 RemoteLast，资产事件读侧要隔帧才可读（对照模式实抓：每次 mutate 恰好一帧 `alpha<1 行数不一致`后自愈——全量路径当帧已见新内容，事件驱动的重估晚一帧）。修法 = `mutate_asset` 写入点直接 `rows_with_material` 反查标记重估，同帧 draw_frame 收敛；修后两连 mutate 0 不一致。
2. **冷却表非空禁止闸门早退**：见 §7.9.3——"全静 ≠ 输出不变"的教科书式反例，A/B 对 main 定责（main ③ 过、7.9 首版败），修后 9/9。
3. **bevy 0.20 的 `Entity: Ord` 不是 index 升序**（单测实抓：BTreeMap 迭代序 e3 < e2）——组装缓存与全量走访迭代**同一个** BTreeMap，序一致性天然成立；单元测试改为"对照账本行序"断言而非硬编码 index 序。
4. 段目录新增材料：施工记录 + 流程导读各一篇；`LodGroups` 新增换代号（register 递增）。
