# 7.9 DrawList 组装与双环增量（M6 追加段）

对应[步骤 7 README](../README.md)与[路线图步骤 7 节](../../学习目标实现步骤.md)。

**目的**：`drawlist::assemble` 每帧对全部账本行做一次走访（可绘判定 + 材质去重），zero_day 7159 行规模下 assemble 段实测 7.4ms/帧（perf_stats sections_mean，2026-10-21）——是帧 CPU 临界路径的最大单项。本段按 4.1 增量思想把"每帧全量枚举"收敛为"状态变化才重建"，是组装侧的收尾。

**一句话说明**：本段把 DrawList 组装与材质环/模型环写侧从每帧 O(账本行) 全走访改为脏信号增量——在场环槽位列表与材质去重集只在行增删/换槽/驻留状态变化时重建；不主张任何 GPU 侧行为变化（命令宇宙逐行与全量路径一致是硬验收），可见性仍归 GPU 剔除/LOD（与 CPU 侧组装正交）。

**当前状态：✅ 施工收官（2026-10-21 当日立案当日施工，分支 `goal/7.9`）：zero_day 7159 行 assemble 7.4ms → 0.003ms，对照模式全路径 0 不一致；[施工记录](7.9.1-7.9.4-DrawList组装与双环增量施工记录：账本侧组装缓存、全静闸门与对照模式.md)、[流程导读](DrawList组装流程导读：从账本行到在场环的增量维护.md)。**
