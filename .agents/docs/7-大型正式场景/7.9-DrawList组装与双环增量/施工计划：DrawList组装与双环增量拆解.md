# 施工计划：DrawList组装与双环增量拆解（7.9）

> 2026-10-21 立案。帧治理四段（7.8~7.11）第二段、最大单项（7.4ms）——立案见[路线图步骤 7 节](../../学习目标实现步骤.md)追加说明。

> **一句话说明**：本计划把 DrawList 组装（每帧 O(账本行) 全走访，zero_day 7159 行 7.4ms）改为脏信号增量——在场环与材质去重集只在行状态变化时重建；本计划不主张 GPU 侧任何行为变化（build_indirect/剔除/LOD 全不碰），也不动 BRP 读数口径（walk_rows/pending_rows 语义不变）。

## 0. 现状核实（2026-10-21 立案期）

- **每帧全量走访属实**：`drawlist::assemble`（driver/host/drawlist.rs）逐行遍历 `InstanceLedger` BTreeMap——逐行查实例槽、`pool.resident`、材质容器缺席判定，去重材质身份再组一份 Vec；zero_day 7159 行实测 assemble 段 7.4ms（sections_mean，2026-10-21 运行期）。
- **组装宇宙与相机无关（属实，源码复读）**：assemble 输入 = 账本行 + MeshPool 驻留 + 材质容器 + LOD 组 + floor_anchor 开关——零相机依赖；每帧可见性是 GPU 剔除/LOD/遮挡在"行宇宙"上算出来的。**行状态不变 → 在场环内容不变** 是增量化的合法性前提。
- **双环写侧现状（5.1/6.2 口径）**：模型环增量（脏行）+ 材质环全量（每帧 O(可绘行) 重写，rings 段实测 0.93ms）+ 在场环全量重写（assemble 产物）+ LOD 变体表环脏行增量。两帧奇偶纪律是环写入的 hazard 约束。
- **增量基建现成（属实）**：4.1 对象增量（InstanceLedger 脏集/flush 盘点）、6.2 LOD 变体表环脏行增量写（write_lod_table_ring 就是同款增量先例，含两帧奇偶纪律）、4.4 换槽/停尸房清账路径。
- **读数面在位**：BRP `draw_stats`（walk_rows/pending_rows/zero_instance_count）+ perf_stats sections_mean——前后对照仪器零新增。

## 1. 任务拆解

### 7.9.1 基线取证

- sections_mean 的 assemble/rings 实数（zero_day 7159 行已实测 7.4ms/0.93ms）+ Sponza 103 行对照（行数梯度钉出 O(rows) 曲线形状）。

### 7.9.2 在场环与材质集增量

- 组装状态账：可绘行集合（行→槽号 + 暂缓原因）以脏信号维护——账本入行/清行/换槽、驻留到货/回收、材质容器到货/失效是全部输入（与 4.1 flush 的脏集同源，不做第二套变更发现）。
- 增量维护产物 = 可绘行槽号列表 + 材质身份列表；行宇宙内容不变帧零走访、零 Vec 重建（容量复用）。
- 暂缓行语义保持：未驻留/缺材质行不进在场环，自愈后出现——增量路径的行进出行必须与全量枚举逐帧一致（判定线 2 的对照面）。
- 两帧奇偶纪律保持：在场环/材质环双帧写入的写侧位置不变（draw_frame 的 fence 纪律之后）。

### 7.9.3 双环写侧增量化评估

- 材质环全量重写（0.93ms）按实测占比裁决：占比可观则同款增量（材质记录随材质身份列表变化写），占比小则如实留全量（简单性优先），裁决与实数入施工记录。

### 7.9.4 一致性对照与回归

- 增量 vs 全量：调试模式（或 BRP 开关）下逐帧比对两路径产物（槽号列表 + 材质列表），跑 spawn/despawn/换槽/驻留到货/热重载全路径。
- 九脚本回归 + 库测试 + 零 VUID + exit 0 + clippy 全净。

## 2. 判定线草案

1. **基线证据链**：assemble 段毫秒前后对照——zero_day 稳态 7.4ms → ≈0（sections_mean 读数）；Sponza/zero_day 两档行数梯度曲线随行数解耦。
2. **逐行一致**：增量产物与全量路径在行增删/换槽/驻留到货/热重载全路径下逐帧逐行一致（对照模式取证）。
3. **语义零回退**：暂缓行/换槽重写/停尸房清账/两帧奇偶纪律行为不变；BRP draw_stats 读数语义不变。
4. **回归**：库测试全绿 + 九脚本抽测零回退。
5. **工程闸门**：零 VUID、exit 0、clippy 全净。

## 3. 待决项

- **增量账的落点**：独立结构（组态缓存）还是账本行内标志——施工时按 4.1 账本纪律就近落位，倾向账本侧（避免第二套变更发现）。
- **材质环增量的裁决标准**：实测 rings 占比阈值（如实记，不硬凑）。
- **对照模式的产品化**：一次性调试开关（观测进 5.2 诊断不驱动绘制的红线）还是测试期临时代码用完即撤——施工时钉明。
