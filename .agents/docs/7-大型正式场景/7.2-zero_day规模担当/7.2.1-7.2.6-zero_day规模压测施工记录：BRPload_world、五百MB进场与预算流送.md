## 实际做了什么

**7.2.1 BRP load_world 前置件**：`remote/assets.rs` 增 `load_world_cmd`（params `{path}` → `server.load(GltfAssetLabel::Scene(0).from_asset(path))` + spawn `WorldAssetRoot`），注册进 AshRemotePlugin；brp.py 补 `load-world` 子命令。语义与 Startup 进场组同链（到货后 world_instance_spawner 反射展开）；`from_asset` 收 `AssetPath<'static>`，&str 须 clone 转 owned（load_mesh_rebind 同款钉）。Sponza 保持 Startup 默认，多场景共存走本方法。

**7.2.2 资产获取与清单钉死**：curl 直下 `zero_day_measure_one.glb`（500,069,208 字节，与 release 实测一致）→ `assets/zero_day/`（`.git/info/exclude` 处理，与 sponza 同款）。glb JSON chunk 运行时解析：**primitive 7159 / 材质 166 / 贴图 358 / 场景对角线 6055.9 单位**——清单数进脚本运行时解析，不写死（换 measure 场景自适应）。

**7.2.3 大文件加载与账面实测**：load_world 受理 → 50s 全量到货排空（对照 Sponza 基线 14MB/分钟级以内）：Δrows 7159 与解析清单精确一致；mesh 驻留 293.8MB（顶点 221.9MB/索引 71.9MB，池容量 296.7MB/96.5MB 未触顶）；贴图 396 张 2.08GB 显存（**实载 396 > JSON 358**：KHR_texture_transform 复用展开，口径钉明）；上传单批 1.3GB 过账；GPU 全帧 p50 1.36ms / p95 2.14ms，可见行 5900/7262。

**7.2.4 预算流送压测**：预算 = 全常驻 1/4（73.5MB，scene_stream 自适应口径）+ 半径 diag/3 全覆盖：走廊五站推进全程 used 73.4MB ≤ budget、rows 不掉、command 3159 ≤ 7262（零幽灵）、draw_calls 恒 ≤1；关闭沿回全量 293.8MB/resident 7262。**待决 2 落定：站位由 AABB 现算（走廊长轴五等分），不拍脑袋。**

**7.2.5 6.5/6.6 真实资产复验**：zero_day 无 LOD 变体（glTF 单档资产）——floor_anchor 开档语义 = 保底即基准（锚无变体可迁，读数不回退、rows 7262 不掉，复验过）；gap_mode=Merged 请求有界（requested 0 ≤ rows、gap_stats 全零计数、无当帧等待，复验过）。**待决 4 落定：贴图字节预算列未在本段开档**——6.4 该列约束在 fine_grained 开档时填充，zero_day 无变体开不了细粒度档位；列压力实测顺延 7.3（Poly Haven 单件贴图大）或 7.4。

## 首钉（实抓即修）

1. **glTF 内嵌相机节点**：zero_day glb 带 1 个 camera 节点，load_world 后 World 2 台相机——residency_stats/draw 链的 `cameras.single()` 全崩（BRP 拒答"World 里没有相机"），压测脚本轮询卡死 742s 才等到人工清理解锁。修 = 脚本轮询中遇拒答即清外（保留最早实体=Startup 宿主相机）；**"宿主唯一相机"机制卫兵（进场场景相机不接管取景）立账归 7.4**。组件类型路径钉子：BRP world.query 过滤 Camera 须写全路径 `bevy_camera::camera::Camera`（`bevy_camera::Camera` 是另一类型，空结果）。
2. **压测期望值口径**：rows 是含 Sponza 基线的总量，断言必须用基线差值（首跑 7262 vs 期望 7159 误报 FAIL）；贴图实载可超 JSON 计数（texture transform 复用）。
3. **tools/__pycache__ 进 workspace**：py_compile 产物被根 Cargo.toml 的 `tools/*` member glob 收编，cargo 全线"找不到文件"——删目录 + exclude 收口（不进 .gitignore，与 assets exclude 同层）。
