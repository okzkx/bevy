# 8.4 施工记录：HDR、ToneMapping 与 Bloom

> 2026-10-22 施工（`goal/8.4`，三任务同日垂直切片连做，合并一篇；对应[段施工计划 §1](施工计划：HDR、ToneMapping与Bloom.md)）。

## 实际做了什么

- **Bloom HDR 链**（`render/pipeline/post.rs` + 三 shader）：`BloomTargets`——5 级 dual-Kawase（半分辨率逐级，`ColorTarget` 复用）+ 参数 UBO 帧槽环（strength/enabled/tonemap 三标量）；三全屏 pass（prefilter 软膝阈值 1.0/knee 0.5 → down 13 tap → up tent+对应级直加，shader 内求和零混合状态）；自有采样器（Drop 销毁，不走描述符表账）。`BloomSettings` 资源 + BRP `bloom_set`（enabled/strength/tonemap）+ `tools/brp.py bloom-set`。
- **ToneMapping 接缝**（`present_tonemap.wgsl`，present_blit 退役删除）：present 层读 HDR + up[0] → ACES（Narkowicz 拟合，常量随注释钉出处）→ swapchain；debug 仪器旁路（mode != filament 直出 HDR 内容）+ tonemap 旗标（A/B 面）；layout [帧 UBO, G-buffer 采样集, bloom 参数集]。
- **resize 重建**：`BloomTargets::rebuild`（幂等，照 ClusterTargets 形状；device_wait_idle + 链目标重建 + 描述符重写），挂 draw_frame 闸门③ hiz 之后。
- **输出编码恰好一次**：数学核对——composite 线性（EXPOSURE 后）→ bloom 线性叠加 → ACES 线性域输出 → swapchain SRGB view ROP 唯一编码（3.4 拍板不动；tonemap shader 内零 gamma/编码操作，注释钉明）。

## 实抓钉子（读图/验证层驱动）

1. **bloom_down 采样器 binding 号错**（b1 vs 域常量 SAMPLER=2）——vkCreateGraphicsPipelines VUID 实抓即修；binding 编号随域常量对齐钉入 shader 注释。
2. **BloomPipelines 句柄拷贝陷阱**——FullscreenPipeline 值在 new 结束 Drop 时把管线销毁（Invalid VkPipeline 首跑实抓）；改为持有本体 + 访问器。
3. **up 链目标尺寸建错一级**（up[i] 建在 extents[i+1]）——renderArea 越界 VUID 实抓即修。
4. resize 重建钩子补齐（首版遗漏，闸门③同批）。
