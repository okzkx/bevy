# 8.2.1 施工记录：材质参数面扩容

> [段施工计划 §1 8.2.1](施工计划：Filament%20BRDF%20与%20多光源光照累积.md)的施工记录。2026-10-22，分支 `goal/8.2-filament-ref`。前置：材质参数已全部进 `StandardMaterial`（官方 `standard_material_from_gltf_material` 转换链，`material_hook.rs`），本任务只扩消费面。

## 做了什么

### 材质记录扩列 32B→64B（`instance_table.rs`）

`MaterialRecordLayout` 新列：PBR 三标量（`metallic` @16 / `perceptual_roughness` @20 / `reflectance` @24）+ 四贴图槽（`tex_base_color` @32 / `tex_normal` @36 / `tex_metallic_roughness` @40 / `tex_occlusion` @44）+ 采样器 @48，垫区补齐到 64B。`pack_material_record` 签名随扩，布局单测 `pack_material_record_layout` 逐偏移互证。域语义照 Filament gltfio：roughness 记 **perceptual 域**原值（clamp 与 α=p² 换算归 shader 端），reflectance 原值（介电体 F0=0.16·reflectance² 在消费端换算）。

### 贴图槽哨兵（`NO_TEXTURE_INDEX = u32::MAX`）

normal/metallic_roughness/occlusion 三贴图缺席时槽位字段写哨兵，shader 端分支跳过采样。**不新造 fallback 贴图**（flat-normal/MR 兜底图两条路被否：白图 B 通道会把 metallic 清零、灰图会扰动 normal——哨兵分支最诚实）。base_color 恒在场（沿用 fallback 白图），不适用哨兵。

### G-buffer 新增 matparam 附件（槽位 3，R8G8B8A8_UNORM）

光照累积 pass 的 PBR 入参载体：**r=metallic / g=AO / b=perceptualRoughness / a=1.0 预留**（8.3 shadow 标志/后续扩展位）。

- **钉明（为何不复用 albedo.a / normal.w）**：三标量只省出两个自由通道（albedo.a、normal.w），AO 无家可归；独立标量附件语义干净、对 motion vectors 槽位契约（槽 2 留位不动）零侵入，8bit 量化与 Filament deferred 层同档（roughness/metallic 均走 8bit 打包）。
- 采样集新增 b5 matparam（`gbuffer.rs`），进场屏障/转只读屏障/渲染实例附件面（`frames.rs`）与主管线 color 格式声明（`init.rs`）三处随行；blend 声明面由 GraphicsPipeline 逐格式生成自动扩。

### G-buffer 写入端 PBR 换算（`gbuffer_write.wgsl`）

- **metallic_roughness 贴图**（glTF 语义 G=roughness/B=metallic）乘标量 → `clamp(p, 0.045, 1.0)`（desktop `MIN_PERCEPTUAL_ROUGHNESS`）/ `clamp(m, 0, 1)`——clamp 放在 G-buffer 写入端而非光照端（Filament 在 getStandardPixelParams 做，数值等价，光照累积端直用现值）。
- **normal map**：世界几何法线为底，切线空间扰动进 G-buffer normal。**TBN 取派生余切框架**（Schüler 2015，`dpdx/dpdy` 现算）——钉明：不依赖顶点 TANGENT 属性（glTF 资产不保证带 tangent，bevy loader 也不自动生成；屏幕空间导数全资产可用）。导数要求 uniform 控制流，本 shader 无提前 return，成立。
- **occlusion 贴图**：R 通道 → AO，进 matparam.g。消费语义（直接光乘法）归 8.2.3。
- 顶点输出新增 `world_pos` varying（location 3，TBN 导数锚点）。

### 供料与既有面随行（解冻清单）

材质环扩列触达的全量消费面（对照 5.1.1 解冻清单先例逐项落点）：

| # | 面 | 改动 |
|---|---|---|
| 1 | `instance_table.rs` | 记录布局/pack/常量/单测（上文） |
| 2 | `drawlist.rs` write_material_ring | 消费 StandardMaterial 五字段 + 三可选贴图槽（缺席哨兵） |
| 3 | `render/mod.rs` | 导出 `MATPARAM_FORMAT`/`NO_TEXTURE_INDEX` |

## 遗留与钉子

- 采样器**全记录共享** base_color 槽位（`SamplerKey` 去重后同键槽，glTF 资产全默认线性重复）；差异化采样器需求出现时再扩列。
- 多 UV 通道不取（`metallic_roughness_channel` 等 UvChannel 字段不消费，全贴图共用 uv0——现役资产面均为单 UV）。
- bevy `occlusion_strength` 类标量不消费（glTF strength 因子 bevy 0.20 未入 StandardMaterial，AO 原值直出）。
