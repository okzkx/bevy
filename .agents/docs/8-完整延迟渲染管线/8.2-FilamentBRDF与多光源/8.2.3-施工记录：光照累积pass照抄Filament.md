# 8.2.3 施工记录：光照累积 pass（照抄 Filament surfaceShading）

> [段施工计划 §1 8.2.3](施工计划：Filament%20BRDF%20与%20多光源光照累积.md)的施工记录。2026-10-22，分支 `goal/8.2-filament-ref`。

## 做了什么

### `gbuffer_composite.wgsl` 全面重写：Lambert 合成 → Filament BRDF 光照累积

**照抄口径落地**（参考篇 §0/§3/§4 逐式对照，函数命名保留 Filament 原名）：

- **lobe 函数**：`D_GGX`（k²/π 形态，453.5 上限原样保留）、`V_SmithGGXCorrelated`（Heitz 2014 完整项，PREVENT_DIV0=7.7e-6 原式）、`F_Schlick(f0, f90, VoH)`（f90 = saturate(dot(f0, vec3(50.0×0.33))) = 16.5·Σf0）、`Fd_Lambert()`。`pow5`/`saturate`/`clampNoV`(1e-4) 配套照抄。
- **参数换算链**：`getStandardPixelParams`（perceptual 域现值→α=p²）、`computeDiffuseColor`/`computeF0`（vec4 入参形状同源）；reflectance 从 matparam.a 读取（8.2.1 预留通道转正，`gbuffer_write` 同批写入）。
- **punctual 衰减**：`getSquareFalloffAttenuation`（smooth² 窗，falloff=1/radius²）+ `getDistanceAttenuation`（1/max(d²,1e-4)）；Filament 的 `lightFarAttenuationParams` 远距项缺省 (1,0)=恒等，省略（灯表无此帧常量）。`getAngleAttenuation`（spot 角衰减）公式照抄、type 恒 POINT 本段不触发。
- **surfaceShading 组织**：NoL 折尾部一次乘 `(Fd+Fr)×colorIntensity.rgb×(intensity×attenuation×NoL×occlusion)`；occlusion（AO）乘光源贡献；energyCompensation=1.0（无 IBL）；`NoL≤0 || attenuation≤0` early exit 同 Filament。
- **方向光**（set1 UBO 单光，8.2.2 钉明不进表）：Filament 方向光形状（NoL×colorIntensity，无 attenuation），强度已折进 rgb 故 w 传 1.0。
- **间接光注入项**：`(light_sum + ambient + indirect)` 的 indirect 空接口立位（步骤 9）。
- **透明层同 BRDF**：`transparent_forward.wgsl` 移植同一份 lobe 函数族（WGSL 无 include，逐式同源复制+头部互证注释）——判定线"透明层与不透明累积同光源同 BRDF"的代码面；参数换算 forward 直读材质记录（不透明层经 G-buffer 中转，本层现读记录 + MR/AO 贴图采样）。

### set1 UBO 第三次解冻 192→208B（`descriptors.rs`）

`camera_pos: vec4f` @192——BRDF 的 V 向量取数面（光照累积是全屏 pass，无顶点级 world_pos varying，须由帧常量供相机世界位置）。`FrameUniformsLayout` 静态断言/pack/identity 兜底三处随行；binding 形状与 layout 不动，range 随常量自动扩。相机缺席帧 zeros 兜底（与 view_proj 同源同帧）。

### 合成管线 set2 = cluster 集（`fullscreen_pipeline.rs`/`init.rs`/`frames.rs`）

`CompositePipeline::new` 增 `cluster_layout` 参数——合成 pass 光照累积的取数面（b0 网格参数/b1 光源常驻表/b2 逐 cluster 列表）。init 顺序调整：cluster 资源先于合成管线建（layout 借用序）；`FrameDraw` 增 `cluster_set` 字段，合成绑定三集。

### 验证仪器：`ash_renderer/set_render_mode`（BRP 增补）

debug 面板 RenderMode 的 BRP 通道（lambert/unlit/normal/position）——排查期立起，保留为 G-buffer 验收仪器的无人取证口（BRP 优先定例）。

## 调试历程与三枚钉子（排查期实抓）

冒烟即遇 Sponza 全画面黑/白紊乱，排查链（G-buffer 三原料逐项用 set_render_mode 仪器分流）：

1. **派生 TBN 的 uniform 控制流钉**：`dpdx/dpdy` 初版在 normal 贴图哨兵分支内（非一致控制流）——WGSL 规范导数内建要求一致控制流，分支内 helper invocation 分歧 = 未定义值。TBN 计算提升到分支外（守卫分支只做扰动）。
2. **TBN 退化守卫钉**：uv 导数零区（平铺 UV 整数缝）t=b=0 → `inverseSqrt(0)=inf`、`0×inf=NaN` → NaN 法线 → 紊乱。退化侧 T/B 列落 0，最终 `normalize` 自然回落几何法线。
3. **黑/白紊乱的终局定性（无罪判决）**：品红直出测试证明黑块非透明层所画；unlit/normal/输入探针（NoL/NoV/occl 直出）证明 G-buffer 三原料与光照输入全对。黑 rods/plants/curtains = **8.1 既有语义**（alpha=0 mask 纹理素被不透明覆盖画出，8.1 施工记录已钉明 alpha 语义归后续段）；黑陶罐 = unlit 已证的黑 albedo；白斑 = **20000 lux 方向光高光在无 ToneMapping 前的 HDR 白截断**（8.4 的活，预曝光口径统一也归 8.4）；天空 = 深蓝清屏色。**本 pass 无回归**。

## 验证

- 库测试 39/39、clippy 全净、build.rs shader 闸门全过（composite/transparent_forward 重编译过 naga+spirv-val）。
- **多光源 A/B（BRP 驱动）**：无灯基线 vs 双彩色点光（橙 30000 cd @ (0,3,0)、蓝 40000 cd @ (0,1,2)）读图对照——左墙橙色暖光晕、右侧蓝紫冷光晕清晰可见，diff 有界且集中于光源作用区。**常驻灯表 → cluster 列表 → 光照累积全链打通**。
