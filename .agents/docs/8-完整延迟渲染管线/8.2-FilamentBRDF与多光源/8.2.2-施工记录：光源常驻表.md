# 8.2.2 施工记录：光源常驻表

> [段施工计划 §1 8.2.2](施工计划：Filament%20BRDF%20与%20多光源光照累积.md)的施工记录。2026-10-22，分支 `goal/8.2-filament-ref`。

## 做了什么

### LightTable（新模块 `render/shading/light_table.rs`）

punctual 光源的常驻 storage 表（用户拍板驻留形态，段施工计划 §0；`render/shading/` 落点按步骤级施工计划 §5 提案形状首次开目录）：

- **帧槽双缓冲 + fence 纪律**：HOST_VISIBLE storage ×`MAX_FRAMES_IN_FLIGHT`，脏行增量重写在 `wait_for_slot` 之后（与模型环同一条 fence 证据——宿主写与 GPU 读不落同一份物理内存）。
- **增量账本**：脏行账 `(槽号, 剩余帧槽写次数)`，新脏 = 2、每帧槽写一次减一、归零出账（环切后另一槽还留旧内容）；稳态零上传（`write_dirty` 空账直接返回）。
- **槽位稳定性**：cluster 逐 tile 列表存的槽号 = 跨帧稳定身份；free list 优先 + bump 兜底；**回收槽立即清零**（`radius=0` 死灯语义，cluster 求交与着色双侧 `r > 0` 门卫跳过）。**停尸房不设**（钉明）：对象表级 graveyard 机器防的是"悬空读"，灯的 1 帧内旧列表引用已换内容的槽最坏产生一次视觉闪变，内容恒有效，灯量级（百以内）不值得。
- **记录 64B**：`pos_radius`（xyz+半径米）@0、`color_intensity`（rgb 线性 + 强度 candela 域）@16、`flags` @32（bit0 = shadow 8.3 预留；bits 8..15 = type，POINT=0 已实现 / SPOT=1 形状预留）。**首钉（冒烟实抓）**：WGSL `vec3<u32>` 垫的成员对齐把记录步长从 48 撑到 64（pad 落 @48）——Rust 侧 48B 步长 pack 导致 GPU 侧错位读数、census 全盘 mismatch；改 64B 同布局后收敛（Filament 每灯 mat4 64B 同档）。
- 容量 256 槽（`LIGHT_TABLE_CAPACITY`），用尽报错不截断（表族同纪律）。

### 方向光归属钉明（§3 待决第一项）

**方向光不进表，set1 UBO 单方向光保留**：方向光是全局量语义（bevy GPU 现役链同款，`dir_to_light`/`light_color` 帧常量），表只装 punctual；8.2.3 的 Filament surfaceShading 在光照累积端两路都吃（方向光走 UBO 常量、punctual 走表遍历）。

### BRP 灯方法族（`remote/cluster.rs` 重写）

`cluster_lights`（整表重写注入口）退役，换 4 方法（槽号账本语义，4.1 先例）：

| 方法 | 语义 |
|---|---|
| `light_spawn` | spawn 点光 → 返回槽号（稳定身份）；pos/color 必填，radius/intensity/shadow 可选 |
| `light_update` | 原位改参（逐项可选合并，槽号不变 = cluster 列表引用稳定的"改内容不换槽"语义） |
| `light_remove` | 回收（槽清零入 free list，下帧 cluster 不再命中） |
| `light_stats` | 读数（在场槽/记录镜像/脏行账/写累计）——census 前置核对与判定线②对照源 |

`cluster_census` 的 CPU 参照切表取数（按槽号铺满遍历域，空槽 = 死灯记录，与 GPU 门卫同式）；`tools/brp.py` 新增 `light-spawn`/`light-update`/`light-remove`/`light-stats` 四子命令。

### 8.1 光源环切表接线

- `ClusterTargets` 不再持有光源环：`lights_rings` 字段退役，b1 描述符改绑 LightTable 帧槽环（构造/rebuild 都收 `&[vk::Buffer]`——表本体住 LightTable，cluster 资源只持引用；resize 重建域不含灯表，容量与尺寸无关）。
- `TestPointLights`/`PointLightGpu`/`POINT_LIGHT_STRIDE`/`MAX_CLUSTER_LIGHTS` 全族退役；`draw_frame` 的"每帧全量打包光源环"换成 `light_table.write_dirty(slot)`（稳态零写）；`cluster_uniform.light_count` = 表 high-water。
- WGSL：`cluster_build.wgsl`/`transparent_forward.wgsl` 的 `PointLight`（32B）换 `LightRecord`（64B）+ 死灯门卫。

## 遗留与钉子

- spot 类型只落记录形状（type 域 + flags 契约），锥体簇求交与 `getAngleAttenuation` 消费归后续段（8.2.3 照抄公式进 shader，type 恒 POINT）。
- 灯强度域记 candela 原值，曝光换算归消费端（8.2.3 与 Filament 预曝光口径对齐时统一）。
