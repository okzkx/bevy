# 8.6 功能流程导读：色调映射三态曲线通道——从 BRP 请求到 swapchain 写出

面向下一个读代码的人，走读 8.6 引入的"曲线选型 + 亮度增益"数据流与 present 色调映射链全貌。

## 各级账面全景

本段之前，present 链的开关账只有三个标量（strength/enabled/tonemap）；本段扩成五个，新增的两枚走同一条"资源 → 帧槽 UBO → shader 分支"通道：

```
BloomSettings（Resource，BRP/面板直写）
    └─ draw_frame 每帧（driver/host/frame.rs 4a-0-2）
        pack_bloom_params：strength/enabled/tonemap/curve/gain 五 f32 → 32B UBO（帧槽环）
            └─ present_tonemap.wgsl set2 b3（BloomParams）
                curve<0.5 → aces_narkowicz（8.4 基线）
                curve≥0.5 → sRGB→Rec2020 → ACES(color, gain) → Rec2020→sRGB
```

## 新文件分工表（一层一句话）

- `shaders/present_tonemap.wgsl`——十步 ACES 照抄区（矩阵/glow/红修正/Hill 拟合/暗包围）+ 三态分支入口；本段唯一的着色面改动。
- `render/pipeline/post.rs`——BloomParams 32B 布局 + TonemapCurve 枚举 + BloomSettings 默认值（curve=filament，gain=1.667）。
- `driver/host/frame.rs`——每帧照资源打包 UBO（只多了两个字段赋值）。
- `remote/bloom.rs`——BRP `bloom_set` 扩 curve/gain 字段（字符串枚举 + 正有限校验）。
- `overlay/windows/pipeline_window.rs`——曲线 radio + 增益滑杆（与 BRP 同源写同一资源）。

## 逐时刻走读（一帧 tonemap）

1. **BRP/面板写资源**：`bloom_set` 把 curve/gain 写进 `BloomSettings`——账面变更即刻生效，无 Vulkan 操作。
2. **draw_frame 打包**：下一帧 4a-0-2 步把资源五标量写进当前帧槽 UBO（帧槽环与主 UBO 同 fence 证据，在飞帧读旧槽不撕裂）。
3. **present tonemap pass**：HDR 中间目标 + bloom up0 叠加 → 按 curve 分支——Narkowicz 直接逐通道拟合；filament 先 sRGB→Rec2020（契约域），过完整版 aces::ACES（gain 乘在 AP1 上），再 Rec2020→sRGB 回显示域。
4. **写出**：shader 全程线性，swapchain SRGB view 在 ROP 做唯一一次编码（3.4 拍板不破）。

## 失败与稳态路径

- **tonemap 关**（tonemap<0.5）与 **debug 仪器模式**（frame.mode≠0）：HDR 内容原样直出，A/B 的 B 面与仪器旁路面不受曲线影响。
- **gain 非法值**：BRP 侧正有限校验拒绝（-32602），资源不被污染；UBO 里永远是上一次合法值。
- **curve 换档**：纯 shader 分支切换，无管线/描述符重建——resize 闸门重建清单不受影响（8.5 缺陷面不复现）。
