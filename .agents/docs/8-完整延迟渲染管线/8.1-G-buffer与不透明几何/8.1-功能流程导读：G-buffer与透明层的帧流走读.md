# 8.1 功能流程导读：G-buffer 延迟管线与透明层的帧流走读

> 面向下一个读代码的人：8.1 之后帧循环从"单 pass 直出 swapchain"变成"compute 半边 → G-buffer → 合成 → 透明 → Hi-Z → present blit + UI"的多 pass 形态。本文按一帧的时间序走读整条链，文末附代码改动账。判定线与验收数字归各施工记录，不在此重复。

## 二、两级账面（每帧谁写谁读）

| 账面 | 写者（时机） | 读者 | 生命周期 |
|---|---|---|---|
| set1 帧 UBO（192B：view_proj+灯光+mode+inv_view_proj） | draw_frame（帧首宿主写） | G-buffer VS / 合成 / 透明 VS | 帧槽环 |
| cluster 均匀数据（160B） | draw_frame（帧首宿主写） | cluster_build / collect / 透明 FS | 帧槽环 |
| 光源环（64×32B） | draw_frame ← TestPointLights（BRP 注入） | cluster_build / 透明 FS | 帧槽环 |
| G-buffer 附件（albedo/normal/深度） | G-buffer pass（GPU） | 合成（采样）+ 透明（深度测试）+ Hi-Z | 帧槽，每帧覆写 |
| HDR 中间目标 | 合成 + 透明 pass | present blit | 帧槽，每帧覆写 |
| cluster 索引表 + 计数 | cluster_build（GPU） | 透明 FS（索引）/ BRP census（计数） | 帧槽，每帧覆写 |
| 透明索引/键/命令环/计数 | collect（atomicAdd 紧凑）/ sort / gather（GPU）；键帧首 -inf fill、计数宿主清零 | 透明绘制（indirect）/ sort_check（回读） | 帧槽，每帧覆写 |

宿主每帧对透明层的写纪律：cluster uniform、光源环、t_count（先读 prev 后清零）都发生在 `wait_for_slot` 的 fence 之后——与帧 UBO 同一条安全证据。

## 三、一帧的逐时刻走读（record_frame，frames.rs）

1. **进场屏障 ×3**：swapchain 颜色（blit 段才用，提前就位）；深度 UNDEFINED→ATTACHMENT；G-buffer albedo/normal/**HDR** 三张 UNDEFINED→COLOR_ATTACHMENT（UNDEFINED 进场丢弃上一轮 SHADER_READ_ONLY 内容——loadOp CLEAR 覆写全像素）。
2. **帧首 GPU fill**：透明键 buffer ← 0xFF800000（-inf 位型），TRANSFER→COMPUTE 屏障——bitonic 全容量排序的 padding 基线（8.1.4）。
3. **compute 半边**（渲染进场之前，序即依赖链）：cull（标记）→ occlusion（合并）→ lod（档位）→ indirect（**不透明**命令环；材质 alpha<1 行 instanceCount=0）→ 透明三件：cluster_build（光源列表）→ transparent_collect（alpha<1 行 atomicAdd 紧凑 + 深度键）→ **bitonic 排序**（prev 透明计数>0 才录；105 派发逐派发屏障）→ transparent_gather（升序数组**尾部反向**→ 20B 命令环，最远先画）。
4. **G-buffer pass**（多 color 首跑）：albedo+normal 双 CLEAR + 深度 CLEAR 0（reverse-Z）；场景一次 `cmd_draw_indexed_indirect`；UI 不在此。
5. **附件转只读**：albedo/normal → SHADER_READ_ONLY；深度 → DEPTH_READ_ONLY（合成要采样世界位置）。
6. **合成 pass**（全屏、无深度）：读 albedo/normal/depth；背景 = depth≤1e-6 → 清屏色；mode 三分支 + position 重建；输出 HDR 目标（CLEAR）。
7. **透明 pass**（有在场行才录）：深度 READ_ONLY→ATTACHMENT（loadOp LOAD 只测不写）；HDR 目标原地继续写（COLOR_ATTACHMENT 布局不变，loadOp LOAD 混合）；一次 indirect 消费透明命令环；收口后深度 ATTACHMENT→READ_ONLY。
8. **HDR 转只读 + Hi-Z 归约**：hdr COLOR→SHADER_READ（blit 采样）；深度已在 READ_ONLY，金字塔逐级重写本帧槽。
9. **present blit + UI**（swapchain，loadOp DONT_CARE）：全屏采样 HDR 目标直出（线性域，SRGB view 的 ROP 编码恰好一次）；UI 同实例接画（raster order 盖顶）。
10. **出场 + 提交**：swapchain → PRESENT_SRC；计时 T0..T6 七位；queue_submit 等 acquire 信号量 + 上传票据。

**布局流转一句话**：G-buffer 三附件 UNDEFINED→COLOR→SHADER_READ（→下帧 UNDEFINED）；深度 UNDEFINED→ATTACHMENT→READ_ONLY→ATTACHMENT→READ_ONLY（透明重绑一来一回）；HDR UNDEFINED→COLOR→SHADER_READ（→下帧 UNDEFINED）。

## 四、失败与稳态路径

- **空场**（在场行 0）：透明三件 + 排序 + 透明绘制整段跳过（transparent=None）；合成/blit 照跑（画面 = 清屏色 + UI）。
- **透明行 0**（如纯不透明场景）：collect/gather 照录（count=0 空转）但 bitonic 空排让路（prev 计数为 0 → sort=None）——105 派发只在真有透明行的帧出现。
- **resize/最小化**：闸门③重建 swapchain → 深度 → Hi-Z → **G-buffer 附件 → cluster 表**（全部幂等，device_wait_idle 纪律）；最小化闸门②整帧让路。
- **相机缺席**：view_proj/inv_view_proj identity 兜底（画面不可读不崩帧循环）。
- **诊断直读的陈旧性**：cluster 计数 / 透明计数 / 排序回读都是帧槽直读 = 两帧前输出（fence 纪律）；BRP 对照前提 = 相机与数据自产生以来未变。
