# 8.1.3 施工记录：透明 Clustered Forward 层

> 2026-10-22 施工（提交 b68a84742）。任务对应[段施工计划 §1 8.1.3](施工计划：G-buffer与透明层拆解.md)。

## 实际做了什么

### 资源与管线（`render/pipeline/cluster.rs`，新）

- **ClusterTargets**：×2 帧槽——cluster 均匀数据（160B：view_proj + inv_view_proj + near/far/tiles/slices/light_count/extent，HOST_VISIBLE 每帧写）、光源环（64×32B 每帧环）、cluster 光源索引表（DEVICE_LOCAL，68B/cluster：count+16 索引）、逐 cluster 计数（HOST_VISIBLE——BRP 对照读数面）、透明命令链（索引列表/键/命令环/计数，容量 16384）。独立小集 b0..b7（hiz 先例：不进 set2，set2 零解冻）。
- **三个 compute + 一个图形管线**：cluster_build（单集）/ transparent_collect + transparent_gather（[set2, cluster_set] 双集 + 4B push）/ TransparentPipeline（HDR SRC_ALPHA 混合 + 深度重绑只测不写 + 常驻三集 + cluster 小集第 4 集）。
- **TestPointLights**（Resource）：测试光源注入载体——场景无点光源实体，BRP 注入驱动判定线②；8.2 光源驻留形态（常驻表 vs 每帧环）裁决前不预设，本环只喂透明层。

### 数据流（全 GPU 决策，红线不碰）

1. `cluster_build`：视锥按 32px tile × 32 深度片（指数分片 0.1~200m）分 3D cluster（**开工即 3D**，用户 2026-10-20 拍板）；逐 cluster 世界 AABB（tile×深度片 8 角点经 inv_view_proj 反投影，片深→NDC z 用 view_proj 轴点投影，与 CPU 参照同式）与点光球求交，写索引表 + 计数。
2. `transparent_collect`：在场环筛材质 alpha<1 行，atomicAdd 紧凑成（索引, 深度键=包围盒中心视图深度）列表——键是 8.1.4 排序输入，本段只入账。
3. `transparent_gather`：索引列表 → 20B 命令环（LOD 引脚选择同 build_indirect 语义，instanceCount 取剔除标记）。
4. 透明绘制：`cmd_draw_indexed_indirect`（count=在场行数上界，非透明行 instanceCount=0），blend 落 HDR 目标。

### 三枚施工钉明（§3 待决落定）

- **透明层深度来源 = 附件重绑**：透明 rendering 实例把 G-buffer 深度再挂回 depth attachment（READ_ONLY→ATTACHMENT→READ_ONLY，loadOp LOAD 只测不写）——6.1 已实证深度附件不可采样，取数通道要多一张取数目标+拷贝，重绑免拷贝零带宽。两道重绑屏障的 srcAccess 含深度写访问位（syncval WRITE_AFTER_WRITE 执法：布局迁移本身是写，须覆盖 G-buffer pass 的深度 store——首轮实抓）。
- **光源列表数据源 = 每帧环**（8.2 裁决前测试载体，见上）。
- **build_indirect 加 alpha 门控**：透明行在不透明环 instanceCount=0（材质环驱动、GPU 决策），gap 缺口证据照写全部在场行（流送不因分层断供）。

### BRP 方法族（remote/cluster.rs，新）

- `ash_renderer/cluster_lights`：注入测试点光源（≤64，空数组清回纯方向光）。
- `ash_renderer/cluster_census`：GPU 逐 cluster 计数 vs `cluster_reference` 纯函数（同公式 + 单测随 8.1.4 补）对照——判定线②读数口。

### 验证

clippy 全净、库测试 34/34、零 VUID；4 光源注入 + census 对照：46400 clusters，GPU/CPU 总指派 144416=144416、逐 cluster 零 mismatch；透明行（BRP mutate alpha 0.35）读图（`.temp/8.1/8.1.3_transparent3.png`）：不透明蓝柱（Lambert 正确）vs 半透明红柱（alpha 混合明显透底且同光照）。

## 遗留

- census 对照粒度 = 逐 cluster 计数 + 总数（索引集合顺序不承诺——GPU 并发写顺序无关判定）；索引集合级对照需 DEVICE_LOCAL 读回，随 8.2 光源驻留形态一并评估。
- 超过 MAX_PER_CLUSTER(16) 的 cluster 照增计数（诊断可见）但索引截断——学习项目规模不预期触顶。
