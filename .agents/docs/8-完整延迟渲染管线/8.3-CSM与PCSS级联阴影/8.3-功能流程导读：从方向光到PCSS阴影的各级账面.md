# 8.3 功能流程导读：从方向光到 PCSS 阴影的各级账面

> 面向下一个读代码的人：8.3 的数据流走读。对应[段施工计划](施工计划：CSM级联阴影与PCSS软阴影.md)与各任务施工记录；文末附代码改动解析。

## 逐时刻走读（一帧内）

**① 帧侧宿主（draw_frame，CPU）**
1. 相机/灯光取数与帧 UBO 同源：`view_proj`/`inv_view_proj`/`dir_to_light`（= 灯实体 back()）+ 投影 near。
2. `cascade_matrices`：4 级 log 分割（0.5→80m 常量表）→ 每级切片 8 角点 inv_view_proj 反投影 → 光空间（手写 look_at + D3D 正交 + 反 Z 偏置）取 AABB 收紧正交盒 → `cascade_view_proj[4]`。
3. `pack_shadow_uniforms`（704B）：4×矩阵 + 24 平面（Gribb-Hartmann，cull 与 CPU 参照同源）+ splits + 相机基 + map_size/enabled → 写 shadow UBO 帧槽（wait_for_slot fence 纪律内）。

**② compute 区间（GPU）**
4. `cull.wgsl`：主视锥标记照旧 + **内联四 cascade 标记**（同一世界保守盒 × shadow UBO 平面，写 [槽][cascade] 交错标记环）。A/B 关 = host 全可见填充。
5. `shadow_build.wgsl`：逐在场行 × 每 cascade 出一条命令——引脚 = 主 LOD 档 +1 再粗一档（哨兵回退），instanceCount = shadow 标记 ∧ 非透明；**遮挡不参与**（Hi-Z 是主相机语义）。

**③ shadow depth 区间（GPU）**
6. 四级联各一个小 render pass：D32 clear 0 + GREATER（与主链同向）→ 一次 indirect draw（4B push = cascade 索引）→ 出场转 SHADER_READ_ONLY。进出屏障恒录（composite 描述符恒绑定，布局恒合法）。

**④ 光照累积（composite FS）**
7. 世界位置（深度重建）→ 视深选 cascade（dot(world−cam, forward) vs splits）→ cascade 矩阵投影 → uv → **PCSS**：法线偏移抬采样点 → blocker search 3×3（遮挡 = d > own+bias，reverse-Z 近=大）→ 半影半径（比值放大 1~8 texel）→ PCF 5×5。方向光项乘可见性；开关旗标（UBO）关 = 恒 1。

## 新文件分工

| 文件 | 一层职责 |
|---|---|
| `render/shading/shadow.rs` | 级联数学/UBO 打包/开关与诊断账面（纯宿主） |
| `render/pipeline/shadow.rs` | 深度图+UBO+标记/命令环+描述符 + depth-only 管线 |
| `render/gpu/shadow_build.rs` | shadow 命令组装 compute 半边 |
| `shaders/shadow_write.wgsl` | shadow depth 顶点变换直出 |
| `shaders/shadow_build.wgsl` | 命令组装（LOD+1 / 遮挡不参与两钉的执行面） |
| `remote/shadow.rs` | BRP shadow_set/shadow_stats |

既有文件触点：`cull.wgsl`（内联四标记）、`gbuffer_composite.wgsl`（@group(3) + PCSS）、`frames.rs`（四级联录制 + T2 计时段）、`frame.rs`（UBO 写 + 填充/诊断/装配）、`perf.rs`（8 位时间戳）、`fullscreen_pipeline.rs`（合成 layout 第四集）、`init.rs`/`host/mod.rs`（建链/插资源/反序拆除）。

## 失败与稳态路径

- 空场/关闭：cull 不派（host 填全可见保读数语义）、shadow_build/pass 整段跳过、composite 旗标旁路——画面恒回 8.2 基线。
- 相机缺席：级联矩阵 identity 兜底（画面不可读属预期，与帧 UBO 同口径）。
- 排空纪律：shadow 家族 Drop 不等 GPU——teardown 的 device_wait_idle 先行（拆除序：ShadowBuildPass/ShadowPipeline → ShadowTargets → InstanceTables）。

## 代码改动解析（git 实数见提交 stat）

- **新增**（4 文件 + 3 shader）：shading/shadow.rs（宿主数学面）、pipeline/shadow.rs（资源+管线）、gpu/shadow_build.rs（dispatch 半边）、remote/shadow.rs（BRP）；shadow_write/shadow_build.wgsl + cull/composite 扩展。
- **扩展**：frames.rs（四级联录制 + 恒录屏障 + T2 段界）、frame.rs（UBO 写 + 装配）、perf.rs（8 位时间戳 + gpu_shadow_ms）、fullscreen_pipeline/init/host mod（接线）。
- **取舍**：shadow 域 binding 全收独立 set（instance set2 冻结表零解冻——不动 4.x 契约）；标记单份交错（省 4 倍 buffer，直址 slot*4+c）；命令环 ×4 独立（build_indirect 不并——职责分家照 cull/occlusion 先例）。
