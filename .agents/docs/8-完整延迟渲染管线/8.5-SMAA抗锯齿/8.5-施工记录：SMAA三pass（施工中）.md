## 实际做了什么

- **三 pass shader**（源 = bevy_anti_alias `smaa.wesl` @ 0.20-dev，MIT 官方移植，拆分器 `.temp/8.5/split_smaa.py` 行号提取 + 条件编译展开——HIGH 档、corner/diag 全开、无 predication/reprojection；实抓钉：@elif/@else 链、`} @else {` 同行块拆分、helpers 必须在 entry 之前、源段尾行 off-by-one）。绑定重排为 set0 共享（b0 输入纹理 / b1 SmaaInfo / b2 采样器 / b3+b4 LUT 或 blend）；neighborhood 加 flags.x 开关直通。
- **LUT 预生成纹理**（立案"官方预生成 texture"路线）：bevy_anti_alias 内置 ktx2（zstd 压缩）→ PNG 转档嵌入（`_smaa_area_lut.png` 160×560 / `_smaa_search_lut.png` 64×16），`Image::from_buffer` 解码 → upload 直传 GpuImage。
- **`render/pipeline/smaa.rs`**：SmaaTargets（LDR/edges/blend 三目标 ×帧槽环 + 两 LUT + SmaaInfo UBO（rt_metrics + flags）帧槽环 + 三组描述符集）+ SmaaPipelines（三全屏管线）+ rebuild（随 swapchain 闸门③）。
- **链路重构**：tonemap 落点从 swapchain 改 LDR 目标（UNORM 线性存储，编码仍在 swapchain SRGB view 恰好一次）→ edge → blend → neighborhood（swapchain + UI 接画）；BRP `smaa_set` + `tools/brp.py smaa-set`。

## 主线程栈溢出钉（环境级，已修）

8.5 构建稳定 `has overflowed its stack`（基线 0/2、8.5 2/2），文件探针定位 Context::new surface→physical_device 段——主线程栈余量临界（MSVC 默认 1MB）被 init 主链 + 后处理段帧增量压破。修复 = build.rs `/STACK:16777216`（主线程栈保留 16MB；子线程不受影响）。init 链深度治理另立账。
