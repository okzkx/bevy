# 10.2.1 目标与管线骨架

目标：在 G-buffer 与合成之间立起一条独立的半分辨率 AO 支路骨架——两张 AO 图、两套描述符集、两条 compute 管线、一套关档用的 1×1 白 dummy，并把它接进 init / resize / 帧录制束 / 布局登记，使整条渲染链可编译、可跑、关档逐字节不变；算法内容留给 10.2.2。

## 新增文件与分工

| 文件 | 职责 |
|---|---|
| `ash_renderer/src/render/passes/ambient/mod.rs` | 模块出口与 `SsaoSettings`（`enabled / radius_m / bias / intensity / steps / full_res / freeze_rotation`） |
| `ash_renderer/src/render/passes/ambient/ssao_targets.rs` | `SsaoTargets`：每帧槽半/全分辨率 `R32_SFLOAT` 图、视图、storage/sample 两套集、1×1 dummy、`ensure` 重建、`mark_written` |

| `ash_renderer/shaders/scene/ambient/ssao_upsample.wgsl` | 半→全上采样（骨架先最近邻，10.2.3 换双边） |

## 描述符集与格式决定

- AO 图格式 `R32_SFLOAT`：WGSL storage 纹理没有 8 位 unorm，`r32float` 无量化，关档时乘 1.0 才能逐字节恒等（R2）。
- `SSAO_STORAGE_SET_DESC`：b0 半分辨率 StorageImage、b1 全分辨率 StorageImage（COMPUTE）；`SSAO_SAMPLE_SET_DESC`：b0 全分辨率 SampledImage（FRAGMENT）。上采样把半分辨率图声明成 `texture_storage_2d<r32float, read>`，与 storage 集一致，不需要采样器。
- 每帧槽两套 storage 集 + 两套 sample 集（共 4 张图），另加 1×1 dummy（`SAMPLED|TRANSFER_DST`，一次 `UNDEFINED→GENERAL` + `cmd_clear_color_image` 清到 1.0），关档时合成绑 dummy 集。
- 布局进程级只建一次、resize 不重建；`ensure(ctx, extent)` 尺寸相同且非空即快速返回，否则 `device_wait_idle → drop_transition_pool → drop_targets → 建图/视图/写集 → transition_images`（一提交 + wait_idle，失败保留池，仿 SCGI `screen_gather.rs`）。
