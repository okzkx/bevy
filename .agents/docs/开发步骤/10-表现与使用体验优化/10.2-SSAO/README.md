# 10.2 屏幕空间环境光遮蔽（SSAO）

> 开工日期：2026-11-27；收官日期：2026-11-27（判定线 7 条：6 条通过、第 4 条口径未达）。分支 `goal/10.2`，起点 `0198cbbd8`，立案提交 `59b63d201`；施工依据[施工计划：SSAO](施工计划：SSAO.md)。口径同步：[步骤 README](../README.md)、[学习目标实现步骤](../../学习目标实现步骤.md)。

**一句话**：用当帧深度与法线做半分辨率半球采样 AO，深度感知上采样后只乘环境项（IBL 漫反射 + 常量 ambient），补墙角/柱础/拱底的接触阴影；为 10.5 画质档预留开关，不做光追 AO、时域累积/TAA，不乘 SCGI 与直射。

**当前状态：✅ 收官（2026-11-27）**。判定线 1/2/3/5/6/7 通过；第 4 条（半 vs 全分辨率 diff p99 ≤0.05）数值未达，已证低于帧间噪声底，按「未达 + 口径问题」记录。代码、取证、feat 提交完成；docs 提交见收尾报告。
