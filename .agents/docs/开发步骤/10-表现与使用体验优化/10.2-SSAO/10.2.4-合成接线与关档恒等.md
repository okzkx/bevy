# 10.2.4 合成接线与关档恒等

目标：把 AO 贴图接到合成 shader 的环境项上，同时保证关档与基线逐字节一致——这是整段最容易伤到既有画面的地方。

## 接线

- `GBUFFER_COMPOSITE_PIPELINE.sets` 末尾追加第 7 集 `SSAO_SAMPLE_SET_DESC`（b0 SampledImage，FRAGMENT），合成 shader 用 `@group(6) @binding(0) var ssao_ao: texture_2d<f32>;`；不动共享 G-buffer 集（`@group(1) b0/b1/b3/b4/b5/b6` 一个都不动）。
- `RenderFeatures` 加 `ssao: Option<SsaoFrameDraw>` 与 `ssao_set: DescSet`；`record.rs` 在 `mark(SurfaceCache)` 之后、G-buffer→合成之前录制 SSAO 并 `mark(TimestampPoint::Ssao)`，合成 sets 数组末加 `feature.ssao_set`。
- 关档：不录 dispatch，`ssao_set` 换成 1×1 白 dummy 集，合成侧恒乘 AO（乘 1.0 在 IEEE 下精确恒等），不需要改 `FrameUniforms`。

## 乘在哪：只乘环境项

`gbuffer_composite.wgsl` 的改动（行号为改动后）：

```
let ao = textureLoad(ssao_ao, ao_coord, 0).r;
var scgi_diffuse = ibl.diffuse * ao;
...
scgi_diffuse = mix(ibl.diffuse * ao, replacement, clamp(irr.a, 0.0, 1.0));
let ambient = albedo.rgb * frame.ambient_color.rgb * ao;
```

即 AO 只乘 IBL 漫反射与常量环境项；SCGI 替换项、IBL 镜面、直射光、材质 AO（`matparam.g`，仍只乘直射）、自发光都不乘（R1：改材质 AO 作用域会漂移 8 段标定并破 9.10 锚点）。

## 踩坑：textureLoad 越界返回 0

关档绑 1×1 dummy 时，`textureLoad(ssao_ao, 像素坐标, 0)` 在坐标 ≥1 时返回 **0**（不是钳边采样），整屏环境项被乘成 0，画面全黑。修法是先取尺寸再钳制：

```
let ao_size = vec2i(vec2u(textureDimensions(ssao_ao)));
let ao_coord = clamp(vec2i(i32(in.clip.x), i32(in.clip.y)), vec2i(0), ao_size - vec2i(1));
let ao = textureLoad(ssao_ao, ao_coord, 0).r;
```

全分辨率 AO 上这个钳制是恒等操作，不影响正常路径。
