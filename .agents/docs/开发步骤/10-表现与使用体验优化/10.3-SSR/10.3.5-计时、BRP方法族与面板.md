# 10.3.5 帧计时、BRP 方法族与面板小节

**目的**：让 `ssr_ms` 成为可判定的一等读数，并把开关/调参暴露给面板与 BRP。

## 交付
- `ash_renderer/src/render/stats/perf.rs`：`QUERIES_PER_FRAME` 13 → **15**；`TimestampPoint` 末尾追加 `Composite = 13`、`Ssr = 14`（数值追加、不重排既有索引）；`fetch` 返回 `[f32; 11]`，末尾加 `seg(Composite, Ssr)`；`FrameSample.gpu_ssr_ms`。
- `ash_renderer/src/driver/host/frame/stopwatch.rs`：`gpu_sections` 10 → **11**（`[10] = ssr`），两处 `[0.0; 11]`。
- `ash_renderer/src/remote/census/perf.rs`：汇总与逐样本两处加 `gpu_ssr_ms`。
- `ash_renderer/src/remote/features/ssr.rs`：`ssr_set`（enabled/steps/max_distance_m/thickness_m/roughness_cutoff/edge_fade/intensity，先全校验再落值）、`ssr_stats`（回读反射图的 `hit_ratio`/`mean_w`，关档不打回读、返回 `enabled=false` 与 `null`）。
- 面板：`overlay/tool_window/ibl.rs` 加「屏幕空间反射（SSR，10.3）」小节（开关 + 六个滑杆 + BRP 提示 + 语义说明），`mod.rs` 加 `reflection_settings` 与 `IblPage { ibl, reflection }`。

## 关键口径
- 只有单独一个 `Composite` 抽点，才能把 SSR 从「合成段」里拆出来；`Ssr` 抽点落在反射合成之后、透明层之前。
- 回读走 `readback_image_region`（GENERAL 布局、8 B/texel、`sample_stride ≈ 4` 抽样），`rect` 越界裁到画面内、裁空返回 `null` 而不是回退整帧。
- 关档不回读是硬口径：读数不应该替设置方开 GPU 段。

## 验证
- `layout_contract` 55/32；`ssr_set {"steps":0}` → `-32602 steps 越界 [1, 256]`；`ssr_set {}` → `-32602 params 缺失`；`ssr_stats {"rect":[3000,3000,10,10]}` → `hit_ratio: null` 且 `region` 被裁。
- 连续开关 12 次 + 连续回读 12 次：日志零 VUID。
- `ssr_ms`：纯开档窗口 p50 0.21–0.33 ms、p95 0.87 ms；**混合窗口（含关档帧）p50 会被拉到 0.001 ms**，读 p50 时必须取纯开档窗口。

## 遗留
- `ssr_ms` 的 p50 受窗口内关档帧影响，尚未加「只统计开档帧」的口径；面板帧统计页也没有 SSR 分位列（10.2 的 SSAO 同样未加）。
