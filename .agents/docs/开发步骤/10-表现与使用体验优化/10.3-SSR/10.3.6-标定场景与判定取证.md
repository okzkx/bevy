# 10.3.6 标定场景、判定取证与已知局限

**目的**：把「反射对不对」从观感变成可复现的图像与数字。

## 交付与现场
- `.temp/10.3/scene.sh`：X=+300 空旷处布置金属球（metallic 1.0 / roughness 0.05）、红蓝两根自发光条（emissive 1.5）、镜面地砖（metallic 0.9 / roughness 0.06，顶面 y=0.024）、背墙（判定 4 的离屏反射物）。落在 X=+300 是为了避开默认 glTF 测试场景。
- 三机位（`capture.sh`）：P1 `target 300 1.1 0 / yaw 0 / pitch -6 / radius 4.5`；P2 `300 1.0 -0.4 / 28 / -10 / 5.0`；P3 `300 1.4 -1.2 / -18 / -8 / 7.5`。
- 证据目录（不入库）：`.temp/10.3/before/`（立案基线）、`final/`、`logs/`、`scene.sh`、`capture.sh`、`measure2.sh`。

## 已知局限（写进段 README）
1. 薄物体漏检：发光条 0.28 m 厚，在 64 步 / 16 m 线性步进下被跨过，倒影不可见。
2. 偏轴机位命中率归零：`yaw ≠ 0` 时 `hit_ratio` 掉到 0，原因未锁定（`yaw 180` 反而正常，怀疑与投影/法线口径的边界条件有关）。
3. 半分辨率边界块状、亮度偏弱（`mean_w` 0.002–0.04）。
