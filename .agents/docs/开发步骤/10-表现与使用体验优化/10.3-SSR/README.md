## 已知局限（本段不主张解决）
1. 薄物体仍会漏检：对数步进把 0.28 m 发光条的覆盖改善到可命中，但倒影仍偏弱（`mean_w` 0.002–0.04）。
2. 偏轴机位命中率对取景与射程高度敏感：标定场景 yaw 4 在 16 m 射程下 0 命中、24 m 下 3.8%；P2/P3 机位在 24–60 m 射程下仍为 0（可反射几何不在屏幕内/不在射线上），因此判定 7 的对比只取 P1。
3. 屏幕空间固有缺失：离屏物体、透明层、屏幕边缘外的反射不可得，回退到 IBL 环境反射。
4. `ssr_ms` 的 p50 若混入关档帧会被拉到 0.001 ms，读数必须取纯开档窗口。
