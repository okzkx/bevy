# 10.3.3 步进核心（半分辨率世界空间 march）

**目的**：在半分辨率上沿反射方向找第一个屏幕内可见的表面，输出 `rgb = 命中色`、`a = 置信度 w`；找不到就写 0，交给 IBL 兜底。

## 交付
- `ash_renderer/shaders/scene/reflection/ssr.wgsl`：`@workgroup_size(8,8)` 的 `cs_main`，push 48 B（`PushSsr { full_w, full_h, half_w, half_h, steps, _pad0, max_t, thickness, roughness_cutoff, edge_fade, intensity, _pad1 }`），输出 `texture_storage_2d<rgba16float, write>`。
- `ash_renderer/src/render/passes/reflection/ssr_pass.rs`：`SSR_PIPELINE`（`cs_main`、三集 `frame / gbuffer_sampled / reflection_storage`、push 48、无颜色附件）、`SsrPipelines`、`SsrFrameDraw::record`（`Handoff::ComputeFragmentRead`）。
- `ash_renderer/src/driver/host/frame/reflection.rs`：`prepare_reflection`（关档 / 非 Lambert / 尺寸零 → `None`）+ `reflection_push`（`to_ne_bytes` 打包 48 B，参数落地前 clamp）。

## 关键口径
- **世界空间**步进：`P(t) = world + n·0.02 + dir·t`，用 `frame.view_proj` 投影取 `uv`、用 `clip.w` 与视深比大小（frame UBO 无视图矩阵，本段不改 352 B 契约）。
- 命中三条件：①射线点在场景之后（`delta > 0`）②深度差在**绝对**厚度容差内（`delta < thickness`）③命中面朝向来向（`dot(hit_n, dir) < -0.05`）。命中后再 4 次二分收敛。
- `w = clamp(gate_roughness · gate_distance · edge · intensity, 0, 1)`；天空与 `perceptual_roughness > roughness_cutoff` 直接写 0。
- 期间修掉两个真 bug：把**步长**当容差（按 32 步跨 24 m 时容差被放大到 0.75 m，掠射地砖整片假命中、整屏发亮）；缺**朝向判定**导致自反射/掠射自命中。两项修复后掠射不再出现整片白块。

## 验证
- 零 VUID；`steps` 32→96、`max_distance_m` 24→16 的实测：P1 机位 `hit_ratio` 由 2.8% 增至 5.4%，`ssr_ms` 仍在 0.2–0.3 ms。
- 关闭时三段全跳（`Option = None`），不建 dummy、不留屏障。

## 遗留（计入段 README 的已知局限）
- 偏轴机位（`yaw ≠ 0`）`hit_ratio` 归零，原因未锁定。
- 薄物体（红/蓝发光条 0.28 m 厚）在 64 步 / 16 m 下漏检，倒影不可见。
