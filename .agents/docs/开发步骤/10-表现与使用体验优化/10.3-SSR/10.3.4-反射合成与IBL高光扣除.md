# 10.3.4 反射合成与 IBL 高光扣除

**目的**：把反射图按 `w` 混回 HDR，并扣掉该像素**原本**的 IBL 高光——否则反射是「叠加」，画面会整体变亮。

## 交付
- `ash_renderer/shaders/common/ibl.wgsl`：新增 `fn ibl_specular_from(env, samp, dfg, n, v, no_v, p_ibl, f0, intensity) -> vec3f`（= `ibl_specular(...) * intensity`）。法线翻正 `ibl_normal` 与粗糙度撑开 `ibl_roughness` **留在调用方**，保证 `dpdx/dpdy` 求导位置不变。
- `ash_renderer/shaders/scene/gbuffer/gbuffer_composite.wgsl`：`ibl_environmental` 的 `terms.specular` 改为调用该函数（逐字节同式）。
- `ash_renderer/shaders/scene/reflection/reflection_composite.wgsl` + `composite_pipeline.rs`：全分辨率合成（sets `frame / gbuffer_sampled / ibl / reflection_sample`）。

## 关键口径
- `out = hdr_copy + w · (L_hit − ibl_spec · EXPOSURE)`；`w = 0` 时加 0 恒等（未命中/关档逐像素不变）；IBL 关时 `ibl_spec = 0`。
- 合成必须是**全分辨率片元**：`ibl_roughness` 依赖 `dpdx/dpdy`，半分辨率会把高光形状算错。
- 反射图停在 GENERAL 布局（compute 写），不能配 sampler → 上采样手写四邻域双线性（`textureLoad` + `mix`）。
- 顺序：合成 → 拷贝 → march → **反射合成** → 透明层 LOAD → `color_to_sampled` → Bloom/tonemap。反射合成必须在透明层之前，且结束后 HDR 处于 `COLOR_ATTACHMENT_OPTIMAL` 正好接透明层。

## 验证
- 判定 1（关档逐字节）与判定 1b（`mode 10` 也就是 IBL 高光视图，抽取前后逐字节一致）均通过——说明抽取没有改变既有的 IBL 高光口径。
- 开档 P1 机位出现球体在镜面地砖上的倒影与球面亮弧；`hit_ratio` 1.3%–5.4%、`mean_w` 0.002–0.04。

## 遗留
- 反射边界块状（半分辨率边界量化），亮度偏弱（`mean_w` 低）。
- 计划里「先只加不扣、再抽取扣除」的两步走被合并成一步完成，A/B 证据只有判定 1b 的逐字节对比。
