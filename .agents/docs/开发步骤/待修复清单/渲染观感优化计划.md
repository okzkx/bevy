## 背景（本次巡场结论）

- 无全局光：常量环境项只有直射的约 4%（`scene/content/lights.rs:26`），暗部死黑、玻璃无环境反射——9.2 规划内，本批不碰。
- 近级阴影：cascade 0/1 上出现规则网纹/碎片（公交车漆面与车窗最明显），关阴影即消失；远处同资产干净——归 F29/F30 方向。
- "平面穿插"：实为源资产残留的 Unreal GroundPlane（`WorldGridMaterial` 棋盘占位材质 + 与 Floor 同高共面的双四边形 + 法线朝下），墙根暗棋盘条带与阴影白梯子光漏均来自它。
- 其余：采样器全局未开各向异性（掠射角摩尔纹）；`emissive` 贴图与因子完全未被消费（材质记录只有 4 个贴图槽）。

## 边界

- 不碰 9.x 规划内容（天空盒、IBL、SCGI、ao/occlusion 语义）。
- 不改 Bistro 资产的 alpha 语义（`Paris_Table_cloth_01` 直方图假阳性未处理），本批资产改动只覆盖 Emerald Day / Dusk。

## 任务 D：近级阴影质量（F29 / F30）

落点：`shaders/scene/gbuffer/gbuffer_composite.wgsl`（`shadow_pcss` / `shadow_visibility`），必要时 `render/passes/shadow/cascades.rs`。

做法：

1. **采样核去网格化**：5×5 规则网格 → 每像素旋转/抖动的核（hash 旋转或螺旋盘），消除规则网纹。
2. **bias / 法线抬升复评**：以公交漆面固定机位 A/B 调到网纹消失或明显减轻，同时接触影（停车牌、垃圾桶、消防栓底部）不脱离、不变薄。
3. **级联淡出**：分割带附近按视深线性混合相邻两级可见性，消除硬切（F30）。

验收：

- 固定机位（用户截图视角 + 公交贴脸视角）前后截图：近处网纹消失/明显减轻；接触影不劣化；远处公交（2/3 级）无回退。
- 跨分割带逐距离截图无可见跳变；零 VUID。
- 复现证据补进 `待修复清单.md` 的 F29/F30 行（状态仍留 ⬜，等用户复验后再关闭）。

提交：代码 + 清单证据。

施工结果（2026-11-23）：

- 采样核去网格化（`shaders/scene/gbuffer/gbuffer_composite.wgsl`）：blocker 搜索 3×3（步长 2 texel，9 tap）与 PCF 5×5（25 tap）两段固定网格全部换成 16 tap 黄金角螺旋盘（半径 `sqrt((i+0.5)/16)`，盘内面积均匀；blocker 盘外圈 2 texel，与原 ±2 texel 覆盖同域；PCF 盘外圈 = 半影半径）。逐像素相位 = 世界坐标哈希角（`shadow_rotation`，sin 哈希钉在世界坐标上——相机移动时相位不漂移，避免无 TAA 时半影像素"沸腾"），blocker 与 PCF 共用同一相位；螺旋用复数增量旋转推进，每次调用只有一对 sin/cos，采样数 34 → 32，成本与原核可比。tap 的 `tap_bias` 仍按 `bias_m + slope_m·|off|` 随 tap 距离缩放，与原实现一致。
- bias / 法线抬升：未改（`bias_m = texel_world·(1+tan_t) + 0.01`、法线抬升 `texel_world·(1+2(1−no_l))` 原样保留）。依据：换成旋转盘后近级网纹已消失/明显减轻，接触影区域前后逐像素完全一致（见下）；此时再加 bias 只会让接触影变薄，故不动。
- 级联淡出（F30）：`shadow_visibility` 选级后，若视深落在"本级覆盖范围末段 10% 带宽"（`SHADOW_FADE_FRACTION = 0.10`，带宽 = (far−near)×0.10；首级 near 取 `SHADOW_NEAR_DISTANCE = 0.5`，镜像宿主常量）内，则再采下一级并按 `smoothstep` 权重混合；权重在本级远端到 1，与带外"下一级单选"连续。出盒退级语义保持：点在本级盒外时 `used > start` 且视深不落在本级末段，`fade = 0`，不参与混合；下一级投影点出盒（margin 7 texel）时也不混合。
