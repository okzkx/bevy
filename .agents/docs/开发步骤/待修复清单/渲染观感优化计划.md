# 渲染观感优化计划（2026-11-23）

> 来源：2026-11-23 漫游 Emerald Day 的取证（BRP `set_camera` / `set_render_mode` / `shadow_set` / `sun_set` + 截图 A/B）。本批只做四项已确认可修的优化，**不含 9.x**（天空盒、IBL、GlobalProbe、SCGI、AO 语义）。
>
> 执行方式：每项一个 SubAgent 施工，串行推进；每项验证通过后由主会话单独提交一个 commit（中文 Conventional Commits，不推送）。施工结果回填在本文件各小节与[glTF 资产变更记录](glTF资产变更记录.md)。

## 背景（本次巡场结论）

- 无全局光：常量环境项只有直射的约 4%（`scene/content/lights.rs:26`），暗部死黑、玻璃无环境反射——9.2 规划内，本批不碰。
- 近级阴影：cascade 0/1 上出现规则网纹/碎片（公交车漆面与车窗最明显），关阴影即消失；远处同资产干净——归 F29/F30 方向。
- "平面穿插"：实为源资产残留的 Unreal GroundPlane（`WorldGridMaterial` 棋盘占位材质 + 与 Floor 同高共面的双四边形 + 法线朝下），墙根暗棋盘条带与阴影白梯子光漏均来自它。
- 其余：采样器全局未开各向异性（掠射角摩尔纹）；`emissive` 贴图与因子完全未被消费（材质记录只有 4 个贴图槽）。

## 边界

- 不碰 9.x 规划内容（天空盒、IBL、SCGI、ao/occlusion 语义）。
- 不改 Bistro 资产的 alpha 语义（`Paris_Table_cloth_01` 直方图假阳性未处理），本批资产改动只覆盖 Emerald Day / Dusk。
- 不改渲染架构与资源格式；不引入新 crate。

## 任务 A：Emerald 场景资产调整（占位地面 + 玻璃半透明）

内容：

1. 删除 Day / Dusk 各 3 个 `WorldGridMaterial*` 占位 primitive（Day mesh 22/101/133，Dusk mesh 43/98/130）。同一 mesh 的 `Floor`/`Floor1`/`Floor2` 四边形与占位 quad 完全同高同尺寸，删后同位置兜底，不会露洞。
2. 玻璃材质改 `alphaMode: BLEND` 并给 `baseColorFactor.a` 半透明参数（材质清单与数值见资产变更记录）。

工具：新增 `ash_renderer/tools/fbx_to_gltf/fix_gltf_look.py`（`drop-placeholders` / `glass-blend` 两个子命令，幂等、写盘前备份到 `.temp/gltf_look_backup/`），接进 `fbx2gltf.py convert` 的后处理链；README 同步。

验收：

- glTF JSON：`WorldGrid*` primitive = 0；玻璃材质 `alphaMode=BLEND` 且 `baseColorFactor.a` 在 0.3~0.5；其余材质不变；备份存在、脚本二次运行为 0 处。
- 运行（Emerald Day）：`ring_census` 中玻璃行 `alpha_mode=BLEND`；`transparent_sort_check` 透明行数 > 0；截图里墙根棋盘条带消失、窗户呈半透明；日志零 VUID。
- 全部改动写入[glTF 资产变更记录](glTF资产变更记录.md)（含备份路径与回滚方法）。

提交：工具脚本 + README + 资产变更记录（计划文件单独先提交）。

## 任务 B：采样器各向异性过滤

落点：

- `render/core/device/context.rs:489`：`base_features` 增加 `.sampler_anisotropy(true)`，读取 `limits.max_sampler_anisotropy`。
- `render/resident/sampler.rs`：`create_sampler` 打开 `anisotropyEnable`、`maxAnisotropy = clamp(8, 1, 设备上限)`；注释同步订正。
- 所有 `create_sampler` 调用点（后处理 pass 也在用）。

验收：

- 固定机位（`target [-14.65,1.537,-7.8166]`、yaw 146.8、pitch 15、radius 10）前后截图：格栅/路面掠射角摩尔纹明显减轻。
- 零 VUID；`perf_stats` p50 无明显回退。

提交：代码。

施工结果（2026-11-23）：

- 代码：`Context` 建设备时查 `samplerAnisotropy` 支持并按支持与否显式启用，同时缓存生效上限（本机 RTX 2060：支持，上限 16×），经 `Context::max_sampler_anisotropy()` 下发；`SamplerKey::create_sampler` 统一走 `anisotropy_settings`：目标 8× 与设备上限取小，上限 ≤1（feature 不支持，按 VUID-VkSamplerCreateInfo-anisotropyEnable-01070 必须关闭）时关闭，最近邻过滤保持关闭（点采样无收益，属策略选择）。bindless 表（材质 + fallback）、G-buffer 深度采样器、Bloom/SMAA 自有采样器都拿同一上限；采样器去重键不变，运行中仍只有 2 种采样器槽。
- 截图：同机位改前 `.temp/taskB_before.png`、改后 `.temp/taskB_after.png`，对比条 `.temp/taskB_compare_cross.png`（远景斑马线 3× 上下拼接）。读图：斑马线/车道线边缘从糊边变清晰、条纹宽度稳定，前景铺装与沥青在掠射角细节更实；无明显过模糊、无新增闪烁纹理，树叶边缘基本不变。
- 校验：改前/改后日志 `VUID`、`Validation Error`、`VK-ERROR` 计数均 0。`perf_stats`：改前环形窗混入约 45% 启动零帧（各 `gpu_*` 均值约为改后稳态的 0.55×），折算后 GPU 分段基本一致；`frame_wall_ms.p50` 16.98 → 17.46（改后稳态，+0.48ms，在 ±1ms 内），p95 18.71 → 19.33。

## 任务 D：近级阴影质量（F29 / F30）

落点：`shaders/scene/gbuffer/gbuffer_composite.wgsl`（`shadow_pcss` / `shadow_visibility`），必要时 `render/passes/shadow/cascades.rs`。

做法：

1. **采样核去网格化**：5×5 规则网格 → 每像素旋转/抖动的核（hash 旋转或螺旋盘），消除规则网纹。
2. **bias / 法线抬升复评**：以公交漆面固定机位 A/B 调到网纹消失或明显减轻，同时接触影（停车牌、垃圾桶、消防栓底部）不脱离、不变薄。
3. **级联淡出**：分割带附近按视深线性混合相邻两级可见性，消除硬切（F30）。

验收：

- 固定机位（用户截图视角 + 公交贴脸视角）前后截图：近处网纹消失/明显减轻；接触影不劣化；远处公交（2/3 级）无回退。
- 跨分割带逐距离截图无可见跳变；零 VUID。
- 复现证据补进 `待修复清单.md` 的 F29/F30 行（状态仍留 ⬜，等用户复验后再关闭）。

提交：代码 + 清单证据。

## 执行与提交纪律

- 顺序 A → B → C → D，串行（共用 `target/` 与工作区，避免并发构建与改动互踩）。
- SubAgent 只改本项范围内文件；完成后报告 `git status` 与验证结果，**不自己 commit、不 push**。
- 主会话逐项核对 diff、跑必要检查后单独提交；每项提交前工作区只应含该项改动。
- 运行验证统一：`target/debug/ash_renderer.exe --scene emerald/emerald_square_day/EmeraldSquare_Day.gltf`，BRP 127.0.0.1:15702，截图用 `.temp/6.1/cap.ps1 -ProcId <PID>`；证据图落 `.temp/`，不入库。
- 构建前先停掉运行中的渲染器实例（否则链接 `os error 5`）。

## 风险

- BLEND 玻璃不写深度、双面绘制，叠色/排序观感需实拍确认；`AlphaMode::Blend` 行不进 shadow pass（玻璃不再投影）。
- 材质记录扩容牵动所有环、对账与布局门，必须一次同改并靠编译期断言兜底。
- 阴影去网格化引入逐像素抖动，无 TAА 时可能呈静态噪点，需读图确认可接受。
- 资产改动本地排除、不进 git；回滚靠 `.temp/gltf_look_backup/` 备份。
