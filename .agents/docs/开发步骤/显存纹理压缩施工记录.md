# 显存纹理压缩施工记录（分支 goal/bcn）

> BCn 运行时惰性烘焙 + 磁盘缓存的施工收口。知识机制见[显存纹理压缩](../笔记/渲染/显存纹理压缩.md)；本篇只记改动面、选型与实测数据，不承编号段判定线责任。

## 做了什么

贴图加载处加一道惰性烘焙：flush 上传时按材质五槽登记贴图角色，有压缩角色的贴图先查 `assets/bcn_cache/` 磁盘缓存（键 = 哈希(烘焙版本 + 角色 + 高 + 解码后 mip0 字节)），命中直读块数据，未命中 CPU 现烤并写回。主流程不变：无角色/不压缩角色的贴图照走 RGBA8 现行路径（fallback 天然保留，egui 图集、SMAA 查找表、fallback 白图不受影响）。

### 改动面

| 位置 | 内容 |
|---|---|
| `resident/assets/bcn.rs`（新） | 角色→格式表、alpha 探测、RGBA8 边缘扩展补 4 倍数、box-filter CPU mip 链、逐级块编码 |
| `resident/assets/bcn_cache.rs`（新） | 内容哈希键、缓存文件读写（temp+rename 防半截文件）、损坏按缺失重烤 |
| `resident/assets/image_spec.rs` | srgb_role 扩展 BC1/BC3/BC7 SRGB 变体 |
| `resident/assets/images.rs` | GpuImage::create 对块压缩格式旁路 blit 能力降级（mip 全链照建） |
| `transfer/types.rs` | StagingImageCopy 增 format 字段；block_bytes/level_bytes 正本（BC1/BC4=8B、其余=16B，`ceil(w/4)×ceil(h/4)` 块） |
| `transfer/uploader/image.rs` | 块压缩图 transfer 段内逐级 `cmd_copy_buffer_to_image` + 全链布局屏障；不进 blit 续批（`vkCmdBlitImage` 不支持压缩格式） |
| `driver/upload.rs` | 材质五槽点时顺带登记角色（同图多角色取优先者）；bcn_direct 查缓存/现烤；排批 BCn 全链连排（offset 对齐块字节）；批次日志加 BCn 直通计数 |
| `context.rs` | 启用 `textureCompressionBC` 特性位 |
| `shaders/.../gbuffer_write.wgsl` | 法线采样改 XY 重建 Z：`z = sqrt(max(0, 1-dot(xy,xy)))`（BC5 双通道；RGBA8 归一化切线法线 z≥0 时同值，故无条件重建、格式不进 shader） |
| `Cargo.toml` | texpresso 2.0.2（BC1~BC5  Rust，rayon）；`[profile.dev.package.texpresso] opt-level=3`（Workspace 根） |

### 角色选型（与笔记正本一致，受编码库能力约束）

| 角色 | 格式 | 说明 |
|---|---|---|
| baseColor / emissive 无 alpha | BC1_RGB_SRGB | 主力 |
| baseColor 有 alpha | BC3_SRGB | 运行时 alpha 扫描决定 |
| normal | BC5_UNORM | texpresso Bc5 编 R/G，正对 glTF 法线 XY |
| occlusion | BC4_UNORM | 编 R，正对 glTF occlusion 读 R |
| metallicRoughness | 不压缩 | 保 G/B 通道语义需 BC7，texpresso 未实现；留 RGBA8 路径 |

编码算法 RangeFit（快拟合档）：实测 1024² 单张 16ms，ClusterFit 高质量档 2.8s——运行时烘焙承受不了离线档的时长；质量即 stb_dxt 档，为行业基线。主角材质渐变条带风险的根治是 BC7（恢复条件：引入 intel_tex_2 或升级编码库）。

## 实测数据

- **emerald_square_day**（RTX 2060）：225 张贴图全部 BCn 直通（BC1×95 + BC3×16 + BC5×97），`image_resident_bytes` 从 4.6GB（RGBA8 全驻留）降到 **0.96GB**，与笔记预估 0.8~1.1GB 一致。首跑烘焙 208 张共 4.4 分钟（含 PNG 解码批间耗时，单张最大 1.5s）；二次运行零烘焙全缓存命中。帧 wall p50 16.9ms（60fps）——改造前同场景因 4.6GB 显存触顶全 PC 卡顿掉到 24fps。
- **sponza**：69 张全 BCn（缓存命中秒级加载），截图读图石墙织毯细节与光照形态正常。
- **零告警**：fmt / clippy --all-targets / 测试 91 项全绿；运行零 panic。
- emerald + sponza 截图读图验收通过（`.temp/bcn_emerald_shot1.png`、`.temp/bcn_sponza_shot.png`；截图属临时取证不留档）。

## 边界与遗留

- **metallicRoughness 仍 RGBA8**：等 BC7 编码能力（外置拓展候选）。
- **zero_day（glb 内嵌）未实测**：缓存键不依赖路径，机制上自动覆盖；未跑验收。
- **烘焙阻塞在加载窗口**：逐张粒度（单张秒级），黑屏时长内完成，不新增稳态卡顿；首跑时长随场景贴图量线性。
- **缓存目录 `assets/bcn_cache/` 已 gitignore**；删目录即全量重烤。
- **load_world VRAM 预检缺陷**（诊断期立案项）与与本功能独立，未处理。
