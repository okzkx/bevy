# 9.3.5 判定线与计量

**做什么**：按施工计划 §2 的七条判定线逐项取证，记录 A/B 结论、回归矩阵与未测项。

## 取证环境

- 构建：debug（`target/debug/ash_renderer.exe`），BRP 端口 15703。release 实例被用户进程
  占用（同一 exe 无法覆盖链接），release 面用 `cargo check --release` 验编译；功能判定线
  与五脚本回归用的都是 debug 构建。
- 场景：zero_day（7159 primitive）、FlightHelmet（6 primitive，1 条透明行）。
- **桌面会话锁屏/遮挡**：`capture_window.py`（PrintWindow）整幅白图、屏幕抓图只有桌面底色，
  所以画面证据改走新增的 BRP `frame_dump`（LDR 后链目标 → PPM，见 9.3.4）。帧图与数值
  读数落在 `.temp/9.3/`。

## 判定线逐条

### 1. 方向映射正确 ✅

- CPU 单测 4/4：六轴落桶 11/8/14/2/10/15（与 Unity 同式手算）、512 方向球↔方往返
  （点积 > 0.99999）、方向→桶→中心夹角 ≤ 55°、求值式等价。
- shader 侧：mode 11 帧取证 `dump_buckets.ppm` 采样点颜色与 CPU 桶中心表逐位对上：
  - 地板（+Y）`[168,248,127]` ≈ 桶 14 `[168,248,128]`；
  - 侧墙（+X）`[248,168,127]` = 桶 11；
  - 立面（+X/−Y 向）`[248,87,127]` = 桶 7；
  - 台阶（−X/+Y 向）`[7,87,127]` = 桶 4。
- `ibl_census probe`：16 桶、64 个 float 有限、16 条中心方向与 CPU 镜像一致。

### 2. 常量天空自检 ✅

- `sky_uniform {"enabled":true,"color":[800,800,800]}` → `ibl_stats.probe16.center_energy`
  16 桶全部 `2513.2742`（`π·800 = 2513.2741`），最大相对误差 < 1e-6。
- 同帧 L2 自检仍健康：`l0_rel_error = 1.37e-7`、`normal_max_rel_error = 5.3e-4`。
- 半球采样用分层中点后，l0 与 L1 两项的离散偏差互相抵消，桶中心 E 是解析值，不是"接近"。
- 六个轴向方向（`directions`）在常量天空下 E 偏 −2.3%～−9.6% —— 这是桶内偏离中心处的
  L1 各向异性，不是能量错误；判据只看 `center_energy`。

### 3. 查询方向正确 ✅

- 物理天空、太阳 az 90°/elev 25°、sky intensity 3：
  - `probe16.directions`：+X `[4447,4607,4633]` vs −X `[3460,3582,3534]`；
    +Y `[2201,3122,4284]` vs −Y `[5471,4758,3478]`；
  - 16 桶中心能量范围 `2180.7 ～ 5771.2`（2.6 倍），法线/方向转向亮侧时 E 变大。
- mode 11 与 IBL 漫反射 A/B 图无镜像/错位；桶边界是预期内的硬切换（下一条的差异图呈
  平滑梯度，无条带）。

### 4. A/B 有数据 ✅，结论 = 默认保留 SH-L2

- zero_day（物理天空，强度 3）：
  - 完整着色：mean |Δ| = **1.254/255**、max 22、319538 像素（22%）Δ>2；
  - IBL 漫反射直出：mean |Δ| = 0.904/255、max 16、`p99` = 7；
  - 差异集中在受 IBL 影响的表面，天空/清屏背景为 0。
- 读图：`probe16` 全图（`dump_bright_probe16.png`）平滑，无接缝/块状伪影；×8 差异图
  （`ab_diff_x8.png`）是表面上的平滑梯度，不是格子状条带。
- **结论**：本场景下 16 桶没有可量化收益，也没有明显接缝；默认保留 SH-L2（与计划 §0.5
  一致），16 桶作为 9.7 Volume 外兜底通路（与 patch 同格式）。
- 成本：probe 与捕获同批（同 `sky_hash`/节流），本次 debug 捕获窗最大
  `gpu_ibl_capture_ms = 4.11ms`（含 capture+SH+probe+prefilter，9.2 release 基线 0.78～
  0.89ms，构建/进程环境不可直接比）；probe 本体 16 线程 × 512 次采样，**未单独计时**。

### 5. 兜底通路可用 ✅

- `ibl_mode=1` 在不透明（zero_day）与透明（FlightHelmet，`transparent_rows_cpu=1`）都能跑；
  透明镜片正常渲染，镜头区域 A/B 有差异（sky intensity 6：7247 像素 Δ>2、max 18）。
- 9.7 的 Volume 外回退只需换查询函数：数据格式与 patch 同为 RGBL1，接口已在
  `probe16_eval`/`octahedral.wgsl` 固定。

### 6. 更新跟随 ✅

- 静止 3 秒：`capture.count` 3 → 3（不重烘）。
- `sky_set {"sun_gain":2.0}` 后：3 → 4（0.1s 节流窗口内重算）。
- `sky_uniform` 开关也进 `sky_hash`：开启后 capture count 从 1 → 2，probe 随之变成
  常量天空值。

### 7. 回归 ✅

- 五脚本（脚本自启 debug 宿主、零 VUID、exit 0）：
  - `hiz_test` 7/7、`scene_lod` 7/7、`scene_stream` 8/8、`scene_fine` 8/8、
    `scene_sponza` 10/10（日志 `.temp/9.3/reg_*.log`）。
- `cargo test -p ash_renderer --lib` **97 passed**（9.2 的 93 + 本段 4 条八面体单测）。
- `cargo clippy -p ash_renderer --all-targets` 零告警；`cargo fmt --check` 全绿。
- 本段所有自启宿主（zero_day / DamagedHelmet / FlightHelmet / 五脚本）日志 VUID/VK_ERROR
  命中 0；WM_CLOSE 退出码 0。
- `cargo check -p ash_renderer --release` 过（release 面编译验证）。
