# 9.3.2 16 桶 L1 投影与烘焙链接入

**做什么**：新增 `global_probe.wgsl`，从 9.2 的 mip0 环境 cubemap 生成 16 条 RGBL1，并把
probe 缓冲、描述符集、管线与 dispatch 接进 9.2 的捕获脏标记链。

## 算法（`shaders/scene/ibl/global_probe.wgsl`，新）

- 16 个桶 = `direction_to_bucket_index` 的 4×4 方格；每桶以桶中心为极轴做**均匀半球采样**
  （对立体角密度 `1/(2π)`：cosθ 均匀、φ 均匀），32 个样本。
- 采样点用**分层中点**：`ξ.x = (i+0.5)/32`、`ξ.y = radical_inverse_vdc(i)`。直接用
  `i/32` 会让 cosθ 均值偏到 0.484，常量天空下 E 低约 1.6%；中点让均值恰为 1/2。
- 累积三项：`l0 = ΣL`、`l1 = ΣL·ω`（x/y/z 三个 vec3）。
- 反权重 × 余弦卷积 × 基函数常数一次折进存储：
  - `weight0 = (2π/N)·A0·Y00²`（A0 = π，Y00 = 0.28209479）
  - `weight1 = (2π/N)·A1·Y1²`（A1 = 2π/3，Y1 = 0.48860251）
  - 存储系数已含"投影端一次基函数 + 求值端一次基函数"，所以查询式只剩 `l0 + l1·n`。
  - 推导：`c00 = (2π/N)ΣL·Y00`，`E = A0·c00·Y00 = raw0·A0·Y00²`；L1 同理。
- 写 16×4 vec4（每桶 `l0/l1x/l1y/l1z`，w 未用）= 1KB。
- 线程形状：`@workgroup_size(16)`、一次 dispatch，一桶一线程、桶内 32 样本串行。Unity 原形
  是每桶一个 workgroup + groupshared 归约；512 次采样成本可忽略，本工程按计划 §0.2 的简化项
  落地，避免引入 workgroup 内存（9.2 两条 SH 管线也没有用）。

## 资源与录制接入（`environment.rs`）

- `IBL_PROBE_RESOLUTION = 4`、`IBL_PROBE_BUCKETS = 16`、`IBL_PROBE_BUFFER_SIZE = 1KB`；
  缓冲 `BufferRole::DeviceStorage`（角色自带 `TRANSFER_SRC`，BRP 可读回）。
- 新 set 布局 `IBL_GLOBAL_PROBE_SET_DESC`：b0 = mip0 cube 采样、b1 = 采样器、b2 = probe buffer；
  新管线 `GLOBAL_PROBE_PIPELINE`（`shader_abi::GLOBAL_PROBE`，build.rs 自动生成）。
- 内部池：`pool_sizes` 加一份、`max_sets` 从 `+4` 改 `+5`；描述符池容量与实际集数（2 帧槽
  capture + project/reduce/check/probe + 8 级 prefilter + dfg = 15）对齐。
- 初始化（一辈子一次）：probe buffer 与 SH/stats 一起 `cmd_fill_buffer 0`，后续同一内存屏障
  覆盖 `TRANSFER → SHADER_READ|WRITE`。
- 烘焙链：`sky_capture → sh_project → sh_reduce → sh_check → **global_probe** → prefilter`；
  probe dispatch 后 `Handoff::ComputeRead`，写→片元读由链尾的全局屏障与 cube 全子资源迁移收口。
- 帧集加 b4 绑 probe buffer（合成/透明前向共用）。
- 布局登记：`layout_registry.rs` 的 `ALL_PIPELINES` / `ALL_SETS` 各加一条，契约测试
  `every_shader_entry_has_a_pipeline` 依赖它。

## 验证

- `cargo check --all-targets` 过（build.rs 编译 + naga/SPIR-V 校验通过，ABI 反射出
  `GLOBAL_PROBE` 的 b0/b1/b2）。
- 宿主起 zero_day、`ibl_set enabled=true` 后：`ibl_stats.capture.count=1`，`ibl_census probe`
  回 16 桶 × 4 vec4（64 个 float）全有限、`centers` 16 条。
- 常量天空 `sky_uniform {color:[800,800,800]}`：16 桶的**桶中心**能量全部
  `2513.2742`（`π·800 = 2513.2741`），相对误差 < 1e-6 — 见 9.3.5 判定线 2。

## 钉子

- 基函数常数只在权重里乘一次（投影与求值各一次、都折进存储），查询端不再乘。
- 采样方向以桶中心为极轴，用 `ibl.wgsl` 的 `tangent_frame`；桶中心永不与 ±X 重合（最近
  0.949），cross 不会退化。
- probe 与 SH-L2/预滤波共用 `sky_hash` 与 0.1s 节流：天空/太阳/海拔变化才重算，静止零成本。
- 常量天空的解析锚点只在**桶中心方向**成立：`±X/±Y/±Z` 落在桶内非中心处，L1 各向异性会让
  E 偏约 −2.3%～−9.6%（实测），不能拿来当能量判据。
