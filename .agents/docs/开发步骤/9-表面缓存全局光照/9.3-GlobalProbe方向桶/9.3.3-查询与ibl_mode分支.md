# 9.3.3 查询与 ibl_mode 分支

**做什么**：把 probe 查询接进不透明合成与透明前向的漫反射项，用帧 UBO 的 `ibl_mode`
在 SH-L2（0）与 GlobalProbe 16 桶（1）之间二选一；高光路径不动。

## 着色器改动

- `shaders/common/ibl.wgsl`：加 `#import octahedral` 与
  `probe16_eval(n, l0, l1x, l1y, l1z)`（值参数；storage 数组不能按值传参，桶索引留在调用方）。
- `gbuffer_composite.wgsl`：
  - IBL 集 b4 = `array<vec4f, 64>`；
  - `ibl_environmental` 里 `var irradiance = sh_irradiance(n, sh_coeffs)`，`ibl_mode == 1`
    时改成 `probe16_eval(n, probe[bucket]..probe[bucket+3])`，再乘 `Fd_Lambert · ibl_intensity`；
  - 桶选择用 9.2.8 翻转后的 `n`（`ibl_normal(n_in, v)`）——与 SH-L2 同一个法线，否则双面
    几何上 A/B 比的是两条法线。
  - 调试视图 9/10（IBL 漫反射/高光）走同一个求值函数，自动跟随 `ibl_mode`。
  - 新增 mode 11 = `probe_buckets`：法线选桶 → 输出桶中心方向 RGB 编码
    （`center*0.5+0.5`），用于映射取证。
- `transparent_forward.wgsl`：b4 同上；透明分支同样按 `ibl_mode` 换 E 的来源，法线用
  `n_ibl`（视向侧翻转）；高光与透明 alpha 不变。

## 宿主侧

- `IBL_SET_DESC` 加 b4（StorageBuffer，FS）；帧集写入 probe buffer；布局注册与两条管线
  配方通过 `SetLayoutDesc` 自动带入新 binding，`SetLayouts` 登记无需改签名。
- `FRAME_MODE_PROBE_BUCKETS = 11`；`RenderMode::ProbeBuckets`（label `probe_buckets`，
  `ALL` 11→12）；模式只在 BRP/名称表，不加 egui 单选组（9.2 的 9/10 同类）。

## 验证

- `ibl_mode` 两档都能渲染：zero_day 全场景（7159 primitive）与 FlightHelmet（1 条透明行）
  下切换无 VUID、无 panic。
- A/B 数字（zero_day，太阳 az 90°/elev 25°、sky intensity 3）：
  - 完整着色：mean |Δ| = 1.254/255、max 22、319538 像素（22%）Δ>2；
  - IBL 漫反射直出：mean |Δ| = 0.904、max 16；
  - 差异集中在受 IBL 影响的表面，背景（清屏/天空）为 0。
- mode 11 取证：采样点颜色与 CPU 桶中心表逐位对上——地板（+Y）`[168,248,127]` = 桶 14
  `[168,248,128]`；侧墙（+X）`[248,168,127]` = 桶 11；台阶（−X/+Y）`[7,87,127]` = 桶 4。
- 透明路径：FlightHelmet 玻璃镜片在 `probe16` 下正常渲染，镜头区域 A/B 有差异
  （sky intensity 6：7247 像素 Δ>2、max 18），零 VUID。

## 钉子

- 两档必须共用同一个翻转后的法线；桶选择在翻转之后。
- `ibl_mode` 只是求值分支：两份数据都常存（SH 144B、probe 1KB），逐帧切回不需要重烘。
- 背景在调试模式下保持清屏色（既有语义），不参与 `ibl_mode` 分支。
- mode 11 的色值经过后链 tonemap，但调试模式不走曝光乘算，量化后与桶中心表仅 ±1 舍入差。
