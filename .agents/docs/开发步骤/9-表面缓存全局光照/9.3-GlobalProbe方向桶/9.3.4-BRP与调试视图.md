# 9.3.4 BRP 与调试视图

**做什么**：给 9.3 的两条运行面加读数与取证口：`ibl_set` 的 `diffuse_mode`、`ibl_stats` 的
16 桶摘要、`ibl_census` 的桶全量回读、mode 11 桶可视化；另补一个不依赖桌面会话的帧取证
通道（锁屏环境下 PrintWindow 会拿到白图）。

## `ibl_set`：漫反射编码

- 入参加 `{"diffuse_mode": "sh_l2" | "probe16"}`，字符串映射 `IBL_MODE_*`（校验形状照
  `set_render_mode` 的 `RenderMode::from_name`）；错误回 INVALID_PARAMS，不 panic。
- 回显 `current` 加 `diffuse_mode` 字符串（`mode` 数值保留）。

## `ibl_stats`：16 桶摘要

- 读回 probe 缓冲 1KB（与 SH 读回同款的一次性拷贝 + fence）。
- 输出 `probe16`：
  - `directions`：±X/±Y/±Z 六个方向的桶号与 `E`（诊断用，能直接看方向性）；
  - `center_energy`：16 个桶在**桶中心方向**的 `E`（能量自检的唯一正确采样点）。
- 采样点踩过的坑：`±X/±Y/±Z` 落在桶内非中心处，L1 各向异性让常量天空的 E 偏 −2.3%～
  −9.6%；把中心能量单独列出来之后，常量天空 16 条全部落在 `πL` 上（<1e-6 相对误差）。

## `ibl_census`：桶全量取证

- 加 `probe: true`：回 `buckets`/`resolution`/64 个 float 的 `values` 与 16 条 `centers`。
- 与 `ibl_stats` 共用同一读回缓冲；`lut`/`row` 与 `mip` 语义不变。

## mode 11：桶可视化

- `FRAME_MODE_PROBE_BUCKETS = 11`；`RenderMode::ProbeBuckets`；`gbuffer_composite` 里
  输出桶中心方向颜色。用来肉眼核对方向映射/接缝——本次判定线 1 的 shader 侧证据就是它的
  帧取证（见 9.3.5）。

## 测试基建增补：`frame_dump`

**起因**：本次运行环境的桌面会话处于锁屏/遮挡态——`capture_window.py`（PrintWindow）整幅
白图，屏幕抓图只能拿到桌面底色，画面类判定线拿不到证据。

**做法**（按《测试规范与方式》"优先扩 BRP 方法族"）：

- `ColorTarget` 建图 usage 加 `TRANSFER_SRC`（只加用途旗标，不改绘制行为）；
- `SmaaTargets::readback_ldr(ctx, slot)`：从 LDR 后链目标（tonemap 后、SMAA 前，RGBA8）
  一次性拷贝 + fence 读回，前后布局在 `SHADER_READ_ONLY ↔ TRANSFER_SRC` 间迁移；
- 新 BRP `ash_renderer/frame_dump`：`{"path": "...ppm", "slot": 0|1?}`，写 PPM（P6），
  回宽高/字节数。帧内容 = 当前着色模式/漫反射编码下的完整画面，≤1 帧陈旧。

它是诊断通道，不进取景/绘制热路径；后续画面取证可以直接复用（不再依赖窗口是否可见）。

## 验证

- `ibl_set` 三字段回显正确；非法 `diffuse_mode` 回
  `-32602 diffuse_mode 只收 sh_l2/probe16，收到 "bogus"`。
- `ibl_census probe`：16 桶、64 float 有限、16 条中心方向。
- mode 11 帧取证的颜色与 CPU 桶中心表吻合（±1 舍入），见 9.3.5 判定线 1。
- `frame_dump` 在 zero_day 与 FlightHelmet 上都成功（1600×900、4320016 字节）。

## 钉子

- 能量自检只认桶中心方向；六方向摘要是"方向性"观测，不是能量判据。
- `frame_dump` 的前提是目标帧槽已渲染过至少一帧（LDR 停在 SHADER_READ_ONLY）；首帧前调用
  会因 UNDEFINED 布局报验证错误，属诊断口约定。
- PPM 只写 RGB、丢 alpha；LDR 是 UNORM 线性存储，sRGB 编码在写 swapchain 的 SRGB view 时
  完成，dump 出来的是线性值（与 9.2 的现有后链口径一致）。
