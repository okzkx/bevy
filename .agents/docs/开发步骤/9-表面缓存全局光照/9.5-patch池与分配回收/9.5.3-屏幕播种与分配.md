# 9.5.3 屏幕播种与分配

> 2026-11-24。计划 [§0.3 / §0.4 / §0.5 / §9.5.3](施工计划：patch池与分配回收.md)。落点
> `shaders/scene/gi/patch_alloc.wgsl`、`src/render/passes/gi/allocation.rs`。

## 做了什么

`patch_alloc.wgsl`（compute，1/4 网格）每线程：

1. 低分辨率像素序**按帧号轮转**（`(tid + frame·2654435761) % total`，双射），池将满时"哪些 cell
   先拿预算"不固定偏向屏幕一角。
2. 子像素轮转：4×4 块内取 `(frame·7 % 16)/4, %4` 的子位置（16 帧走遍全分辨率），越界像素跳过。
3. `textureLoad` 深度（**不用线性过滤**）→ `world_from_depth`（帧 UBO 的 `inv_view_proj`）→
   平面法线（4 邻域深度差分，5% 相对深度门限；法线来源 A/B：`push.normal_source=1` 时改读
   G-buffer 着色法线）。
4. 级联/桶/cell（`gi_cell` 同一组函数）→ 解析 patch：
   - **已有 patch**：刷新几何/法线、heartbeat、rank 清零（`state & ~0xFF`），**辐照度保留**；
   - **新 cell**：`cell_marks` 的**帧号纪元标签**仲裁（`atomicExchange(marks, frame|1)`，旧值等于
     本帧标签 = 同帧已有赢家）；赢家从 ring 追加 slot（CAS 循环 `count<capacity → count+1`，池满
     只计 `counters.failed`、归还标签允许后续帧重试）。
5. 新 patch 写几何/两份辐照度（种子）/统计（mean=l0、state=0、update_count=0、heartbeat），
   最后发布 `patch_cell[slot]` 与 `cell_patch[cell]`，`active` 原子加一并刷新 `watermark`。

**种子 = IBL 基线**：`ibl_mode=1` 直接取该方向桶的 RGBL1（与 patch 同格式）；`ibl_mode=0` 从
SH-L2 只取 l=0/l=1 带换成 RGBL1（`l0=C0·0.28209479`、`l1x=C3·0.48860251`…，乘 `ibl_intensity`；
高阶不折进 l0）。IBL 关/播种关 = 全 0。理由：9.5 还没有低分辨率辐照度生产者，先验等价于
"缓存没数据 = 环境光"，与 9.7 的 Volume 外回退同口径；9.6 首轮收敛不从全黑起步。

**motion vectors 本体未做**（计划 §0.4 允许的降级）：本段种子是常量，无低分辨率辐照度可
重投影；`prev_view_proj` 字段与"另一帧槽模型环 = 上一帧变换"的结论已留。

## 裁决与坑

- **`textureLoad` 而非 `textureSampleLevel`**：D32 的线性过滤不可依赖，平均后的深度反投影是错的
  几何；全分辨率整数坐标直接 `textureLoad`。
- **1/4 像素中心 +0.5**：`uv = (px + 0.5) / full`；把整数坐标当 uv 会偏半像素（计划 §9.5.3 坑）。
- **marks 用纪元标签**：计划写法是 `InterlockedExchange(…,1,old)` 拿旧值 0；每帧给 2M 个 cell
  清 0 要 8 MiB/帧写。改成标签 = `frame|1`（非 0），旧值 == 本帧标签才判同帧重复，无需清零；
  `frame` 回绕时极端情况只可能误判"本帧已分配"一次，下一次访问即自愈。
- **同帧竞写**：两个像素命中同一新 cell 时，输家看到 `marks` 已是本帧标签直接返回；赢家发布
  `cell_patch` 后，同帧其他像素可能看到新 patch 并刷新几何——两边写同一 patch 的位置/法线，
  差值是同一体素内的采样抖动（与 Unity 同级的良性竞态），记录在案，不做额外同步。
- **环追加 CAS 循环**：naga 对 `loop { continue }` 的返回分析会误判缺少返回（"return expression
  None does not match declared return type"）；改 `var slot = INVALID; loop { … break } return slot`。
- **种子 vec4 类型**：`sh_coeffs[i].rgb * 标量` 是 `vec3f`，赋给 `vec4f` 字段要显式 `vec4f(…, 0.0)`
  （naga IR 校验当场报类型不匹配）。
- **屏障**：分配写缓存表 → 同帧视图（片元）读，`Handoff::ComputeFragmentRead` 在
  `GiFrameDraw::record` 末尾恒录一条（见 9.5.5）。

## 录制输入

`GiAllocDraw`：`pass`（`PATCH_ALLOC_PIPELINE`）、32B push（low_w/low_h/full_w/full_h/frame/
normal_source/pad×2）、组数 = `ceil(低分辨率像素 / 64)`、四集（帧 UBO / G-buffer 采样集 / IBL 集 /
GI 集）。`GiSettings.seed=false` 或 GI 关/无相机时不产出（`None`，整段不录）。

## 证据

`gi_test` ①：Sponza 中庭 patches=3320、`failed=0`、覆盖图绿 97.1%/红 0.0%/蓝 2.9%；桶着色 15 色
（平坦面没有被着色法线贴图细节拆碎）；`gi_census` 16/16 位置在体素内、法线在桶内。`allocation.rs`
的 `grid_and_group_counts_round_up` / `alloc_push_offsets` 两个单测钉组数与 push 偏移。
