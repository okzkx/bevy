# 9.5.1 Volume 与格子系统

> 2026-11-24。计划 [§0.1 / §9.5.1](../施工计划：patch池与分配回收.md)。本段所有算术的两份真身：
> GPU `shaders/common/gi_cell.wgsl`、CPU `src/render/passes/gi/volume.rs`，改一处必须同步另一处。

## 做了什么

- **`shaders/common/gi_cell.wgsl`（公共片段，不声明绑定）**：`pos_mod`（有符号正模）、`voxel_size`
  （`voxel_min·2^cascade`）、`is_inside_cascade`（球判据）、`resolve_cascade`（从最细级起第一个满足
  的级）、`volume_position`（`int(p/v − offset + res/2)` 再 clamp）、`volume_to_storage`
  （`(pv + offset) mod res`）、`storage_to_volume`、`volume_world_center`、`cell_index` /
  `cell_cascade` / `cell_storage` / `cell_bucket`、`heartbeat_age`（16 位模距离）、`world_from_depth`
  （与合成 shader 同一反投影式）、`depth_neighbor_ok` / `flat_normal`（深度一阶差分，5% 相对深度
  门限剔除不连续邻居，法线翻转朝视向侧）、视图调色（`hash_color` / `bucket_color` / `cascade_color`
  / `age_color` / `coverage_color` / `deviation_color` / `view_color` / `display_encode`），以及
  跨端记录结构 `PatchGeometry`(32B) / `PatchIrradiance`(64B) / `PatchStatistics`(48B) / `GiUniforms`(256B)。
- **CPU 镜像 `volume.rs`**：同一组公式 + `SurfaceCacheConfig`（默认 Res 32 / 4 级 / Size 128 m /
  池 65536；`from_size`/`size` 互逆；`problems()` 自检）+ `cascade_offsets(focus)`
  （`floor(p/v + 0.5)`，按整个体素对齐）+ 单测 8 项。
- **GI UBO**（`SurfaceCacheUniformsData` + `pack_surface_cache_uniforms`，256B，偏移静态断言）：
  `prev_view_proj` 64B（9.6 用）、`target_pos`、`volume`（voxel_min / res / cascades / capacity）、
  `cascade_offsets: [vec4i; 8]`、`ring`（defrag 波数 / 法线来源 / 播种开关 / 保留）、
  `frame`（帧号 / 淘汰门限 / bounce / updateMax）。

## 裁决与坑

- **两条公式派生一处**：`Size` 只从 `voxel_min·res·2^(C−1)` 派生（`SurfaceCacheConfig::size`），
  宿主与 shader 都不另写 0.5。单测钉 `size()==128` 与 `from_size(128)≈0.5` 互逆。
- **有符号正模**：WGSL `%` 对负数保留符号，存储槽必须落在 `[0,res)`；`pos_mod` 在两边同式，
  单测遍历 −100..100。
- **偏移只取整数**：`cascade_offsets` 用 `floor(p/v + 0.5)`，相机在体素内部游移不改变偏移；单测
  钉"0.4 m 步进每次变化 ≤1 体素、不倒退"。
- **不重复 `inv_view_proj`**：播种/视图要反投影，但帧 UBO（set0，336B）已有 `inv_view_proj` 且
  stage 含 COMPUTE，直接把帧集绑给播种当 set0——GI UBO 里只放会变的 Volume 参数与 9.6 的
  `prev_view_proj`（计划 §9.5.1 标 ≈224B，加 ring/frame 两槽后 256B，记录在案）。
- **走查样本对账**：讲解里的具体样本（相机 `(10.3,1.7,−4.2)`、样本 `(10.6,1.7,−4.0)`、法线朝上）
  在单测里逐项复算：`offset=(21,3,−8)`、`pv=(16,16,16)`、`storage=(5,19,8)`、桶 14、cell 91,790。
- **存储槽与相机无关**：单测把同一世界点在三种相机偏移下换算，槽不变（`offset` 在代数上被消掉）。
- **设计器坑**：WGSL 保留字 `target`、`patch`、`active`、`shared` 都不能当标识符（编译期报
  "reserved keyword"），`gi_cell` 的参数改叫 `center` / `patch_index`。
