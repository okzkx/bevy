## 视图（两种形态，同一 `patch_view.wgsl` 模块）

- **形态 A 覆盖图（主）** `vs_main`（import `common/fullscreen.wgsl`）+ `fs_cover`：全屏三角形，
  每个像素按自己的深度与平面法线算 `级联 → 体素 → 桶 → cell → patch`，把缓存数据**直接铺在可见
  网格表面**上。与播种/9.7 共用 `gi_cell` 的同一组函数。DONT_CARE 进场（整屏都写满）。
  - 子视图：1 覆盖（有 patch 绿 / 无 patch 红 / 出 Volume 蓝）、2 级联、3 桶、4 rank、5 心跳年龄、
    6 池水位与失败计数（顶部 5% 条：左 90% 池占用、右 10% 本帧 failed / 256）、7 位置偏离、
    8 cell 归属（随机色分区）。
  - **0 = 关**（计划 §9.5.6 的显式双门 `gi_enabled && view > 0`）。计划 §0.7 把 cell 归属记作 0，
    与门冲突，这里顺延到 8。
- **形态 B 方片** `vs_marker` + `fs_marker`：一次实例化 draw（6 顶点 × 池容量），每槽一个小方片
  （位置取 patch、朝向取法线、边长 = 该级体素 × 0.12），未用/陈旧槽输出退化三角形。
  - 人工深度测试：片段窗口深度 vs `textureLoad` 的场景深度（reverse-Z 大 = 近），比场景小 = 被遮挡
    `discard`；方片沿法线朝相机一侧偏移半个体素避免与表面 z-fighting。
  - 颜色 = 子视图色混 80% 暖白：方片压在覆盖图上，若与 cell 同色就看不见了。
- **位置偏离（视图 7）** = patch 位置到当前表面**切平面**的垂直距离 / 体素（绿 < 0.1、黄 < 0.5、
  红更大）。不用欧氏距离：一个 cell 覆盖整个体素，当前像素与存的位置切向可差一整格，欧氏天然超阈；
  离面距离才是"贴不贴表面"。
- **画在哪**：⑧ 段 LDR 后链目标，SMAA edge/blend 之后、neighborhood 与 UI 之前；视图关 = 零命令。
  画进 LDR 让 `gi_dump` 复用 `frame_dump` 的 LDR→PPM 通道，零新增读回；也不塞进合成 shader
  （保护"GI 关 = 9.3 逐位一致"）。
- **只读**：不刷心跳、不分配（不照抄 Unity `Debug.compute` 的 `UpdateHeartbeat` 副作用）。

## egui 面板

`工具窗口 → 渲染 → 表面缓存 GI`（`src/overlay/tool_window/gi.rs`）：总开关（勾上时若
`view == 0` 自动切到覆盖图 1，否则开了看不到变化）、视图下拉（0～8 带名称）、形态三选
（覆盖图 / 覆盖图+方片 / 只方片）、法线来源（平面/着色）、播种开关、整理波数滑杆、Volume/池
规格只读行。控件就地写 `GiSettings`，`draw_frame` 下一帧照资源执行，与 BRP `gi_set` 同源；
规格改动仍只走 BRP（只允许关态）。

## BRP 四口

| 方法 | 内容 |
|---|---|
| `gi_set` | `{enabled?, view?, form?, normal_source?, seed?, defrag_waves?, size?, res?, cascades?, capacity?}`；规格四件只在关态改（开态回 INVALID_PARAMS），改后 `device_wait_idle` + 换表；返回生效值 |
| `gi_stats` | 池（active/watermark/capacity/ring_start/ring_count/flip）、本槽计数、`cell_occupancy`、显存三组、`gi_ms`、设置快照；关态回 `enabled:false`（不报错） |
| `gi_dump` | 复用 `census::frame_dump::dump_ldr_frame` 写 PPM；视图关（`view==0` 或 GI 关）拒绝 |
| `gi_census` | `device_wait_idle` 取一致快照；抽检 ring 前 N 条：`cell↔patch` 双向一致、patch 位置到所属体素中心距离 ≤ 体素、`direction_to_bucket(normal)` = 所属桶；返回逐条 rows + summary |

`tools/brp.py` 新增 `gi-set` / `gi-stats` / `gi-dump` / `gi-census` 四个子命令。

## 裁决与坑

- **形态 B 的实例颜色**：第一版直接输出 `view_color`，与覆盖图同色 → 完全看不见；混暖白后可见
  （`gi_test` 用暖白像素占比 > 0.2% 判定）。
- **方片边长**：0.25 体素在粗级联（2～4 m）是 1 m 方块，铺满屏幕；取 0.12 体素后在覆盖图上呈
  可分辨的小块。
- **`gi_census` 的读法**：`GpuBuffer::read` 支持任意偏移小段读，逐条 4B/32B/48B 取；先
  `device_wait_idle` 保证双表一致（诊断低频）。逐条数上限 64。
- **`gi_stats` 的 gi_ms 新鲜度**：读当前帧槽（与 `ray_tracing_stats` 同款），当前槽提交刚录完时
  可能 NOT_READY → 回 0；稳态下取到上一轮读数。
- **顶部条画在覆盖图里**：view=6 时整屏 = 顶部条 + 25% 暗度 cell 归属底，条外不画别的视图。

## 证据

`gi_test` ①：覆盖图绿 97.1%/红 0.0%/蓝 2.9%；位置偏离红 1.0%；桶着色 15 色；cell 归属 513 色；
方片暖白像素 33.1%；`gi_census` 16/16 全一致。⑥：关态 `gi_dump` 被拒、`gi_census` 回 enabled:false。
取证图：`.temp/gi_view1.ppm`、`gi_view7.ppm`、`gi_test_view3.ppm`、`gi_test_view8.ppm`、
`gi_test_markers.ppm`（本机，不入库）。
