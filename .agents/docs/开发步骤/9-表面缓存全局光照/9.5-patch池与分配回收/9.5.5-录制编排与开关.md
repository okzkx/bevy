# 9.5.5 录制编排与开关

> 2026-11-24。计划 [§9.5.5](施工计划：patch池与分配回收.md)。落点
> `src/render/frame/{render_features,record}.rs`、`src/render/passes/post/post_chain.rs`、
> `src/render/stats/perf.rs`、`src/driver/host/{frame.rs,frame/gi.rs,frame/stopwatch.rs,init.rs}`。

## 做了什么

- **④.5 段**：`record.rs` 在 ④ G-buffer 的只读屏障（四色 → `SHADER_READ_ONLY`（dst 含 COMPUTE）、
  深度 → `DEPTH_STENCIL_READ_ONLY`）之后、⑤ 合成之前录 `feature.gi.record()`：
  `scrolling → eviction → defrag×waves → alloc`，末尾恒录一条
  `Handoff::ComputeFragmentRead`（缓存表 compute 写 → ⑧ 段视图/9.7 片元读）。
  GI 关 = `feature.gi = None`，整段不录、零屏障。
- **`GiFrameDraw`**（`passes/gi/mod.rs`）：`Option<scrolling>` + 组数、eviction、defrag 波数、
  `Option<GiAllocDraw>`、`gi_set`、`Option<GiViewDraw>`。
- **`GiSettings`**（默认 `enabled:false`，BRP `gi_set` 写）：开关、视图号、形态、法线来源、播种开关、
  整理波数、Volume 规格。
- **宿主 `prepare_gi`**（`driver/host/frame/gi.rs`）：读设置 → 无相机返回 None → 按相机位置算各级
  整数体素偏移 → 与上一帧偏移比较（**重开首帧强制滚动一次**）→ 写 GI UBO + 清本槽计数 →
  组装四件 dispatch 与视图束。`GiFrameLocal` 跨帧存 `prev_view_proj` / `prev_offsets` / `frame_index`
  / `was_enabled`。
- **时间戳**：`QUERIES_PER_FRAME` 11→12，`TimestampPoint::SurfaceCache = 5`（插在 GBuffer 与
  Lighting 之间，后续点位顺延），`GpuTimer::fetch_gi` 单读 GBuffer→SurfaceCache 一段，
  `FrameSample.gpu_gi_ms` + `perf_stats.gpu_gi_ms` + `gi_stats.gi_ms`（GI 关的帧两 mark 相邻 ≈0）。
- **后链拆分**：`PostChainDraw::record` 拆成 `record_to_ldr`（Bloom → tonemap → SMAA edge/blend）
  与 `record_neighborhood`（LDR + blend → swapchain，开渲染不关给 UI）；中间插入 ⑧ 段视图。
  命令序列与拆前逐条相同，GI 关时完全等价。
- **init 链**：`GiSetLayout` → `SurfaceCacheTables` → `GiPipelines` → `GiSettings`，全部注册在
  `InitChain`（拆除序：管线 → 表 → 布局）；GI 集布局登记进 `SetLayouts`；六条管线进
  `layout_registry`。

## 裁决与坑

- **段的插入位置是硬约束**：② 段读不到本帧 G-buffer；本段必须排在 ④ 的只读屏障之后才能
  `textureLoad` 深度/法线与采样四色附件。⑤ 之后才轮到 9.7 的屏幕注入。
- **关闭态逐位一致**：不建视图、不录 dispatch、不绑集；时间戳点照录。`gi_test` ⑥ 用
  "GI 开 view=0" vs "GI 关" 的 LDR 帧逐字节一致取证（tonemap 之后的 LDR，UI 不在内）。
- **重开幂等**：表不重建、ring 配置保留；只有关态改容量/分辨率才重建（见 9.5.2 的布局解耦）。
  池在关态冻结，`gi_stats` 仍报出保留的 active——测试口径按"冻结保留"而不是"清零"。
- **上传票据快照**：`UploadWait::snapshot` 在 overlay 图集整传之后取（既有纪律），GI 的
  `prepare_gi` 在其之前，不新增上传。
- **后链拆分的调用边界**：`Feature.post.record_to_ldr(...)` / `record_neighborhood(...)`；视图束在
  两者之间用 `feature.gi.as_ref().and_then(|g| g.view.as_ref())` 取，不可变借用当场结束，UI 段
  不受影响。

## 证据

`gi_test` ⑥：GI 开（view=0）→关的 LDR 帧逐字节一致、关态 `gi_stats` enabled:false、`gi_dump`
被拒、`gi_census` 回 enabled:false；④：`gi_ms` 0.54～0.88（GBuffer→SurfaceCache 段）。全测试零
VUID/VK-ERROR。
