# 9.5.4 回收三件

> 2026-11-24。计划 [§0.6 / §9.5.4](../施工计划：patch池与分配回收.md)。落点
> `shaders/scene/gi/{scrolling,eviction,defrag}.wgsl`。

## 做了什么

帧内顺序固定 **scrolling → eviction → defrag × waves → alloc**（先腾空间再分配，同帧释放的槽
本帧播种即可复用），每个 dispatch 后 `Handoff::ComputeReadWrite`（compute→compute 屏障）。

- **scrollin g**（`scrolling.wgsl`，线程 = 级联数 × res³，每线程循环 16 桶）：只在级联偏移变化的
  帧录。把存储槽换回体积坐标（`storage_to_volume`）→ 世界位置（`volume_world_center`）→ 球判据，
  出界就释放该体素下 16 个桶的 cell：`cell_patch`/`patch_cell` 双清、`active` 原子减、`freed` 计数。
  数据不搬运——`volume_to_storage` 里 offset 消掉，存储是世界对齐的环形瓦片。
- **eviction**（`eviction.wgsl`，线程 = 池容量，先判槽在用）：心跳距离 = `(frame − heartbeat) & 0xFFFF`，
  超 240 帧淘汰；bounce 分支（`frame.z != 0` 且 rank 0 → 降 rank 1）已实现但本段恒 0。
- **defrag**（`defrag.wgsl`，256 线程/组、每波 512 条、每帧 `GiSettings.defrag_waves` 次）：
  - 读相位：两条源记录（几何 + 两份辐照度 + 统计）读进私有存储；`workgroupBarrier + storageBarrier`
    之后才落笔。
  - 写相位：存活条目 `atomicAdd(ring[write].count, 1)` 领目标偏移，搬到 `(start + offset) % capacity`，
    四表同搬、`patch_cell`/`cell_patch` 双表改写、`defrag_moved` 计数。
  - 游标：`scan` 每波 +512，到 `count` 末尾把写配置转正（flip `ring[0]`）、旧读配置清空成下一周期
    的写配置；全池走完 ≈64 帧（1024 条/帧）。
- 存活判定 = 双表互指（`patch_cell[slot] != INVALID && cell_patch[cell] == slot`）：整理搬走后
  旧槽的 `patch_cell` 不主动清，后续判定按死项忽略；eviction/scrolling 命中陈旧指针时只清自己
  一侧，绝不误清整理后的活 patch。

## 裁决与坑

- **workgroup 前缀和被 spirv-val 拒**：naga 30 给 `<workgroup>` 聚合类型发 Offset/ArrayStride，
  触发 `VUID-StandaloneSpirv-None-10684`（Workgroup 不得有显式布局），项目构建门的补丁只处理
  描述符索引，不为它开路。改用**原子取号压缩**：顺序随调度、存活集合确定（ring 顺序无外部语义），
  目标偏移恒 ≤ 源偏移，动点性质不变。
- **同波读写竞争**：目标偏移可能落回本波的源范围（例如存活数接近 512 时），所以源记录先读进
  私有存储、屏障后才写；跨波安全由"本波写偏移 < 下一波读起点"保证（存活数 ≤ 处理条数）。
- **心跳 16 位模距离**：直接相减会在约 18 分钟处把全场同时判超龄（计划 §9.5.4 坑）。
- **整理与分配同帧写表**：每段各自 `ComputeReadWrite` 屏障；ring 的读/写两份配置都走原子
  （`array<atomic<u32>, 12>`），flip 在下一 dispatch 的屏障后可见。
- **空区间**：`count=0` 时每波 `scan>=count` 直接翻转，无害（只是配置对调）。
- **eviction 线程数 = 容量而非活跃数**：先判 `patch_cell[slot]`，否则会"淘汰"从未分配过的槽。

## 证据

`gi_test` ③：独享墙体进视野 3320→3461 条，移出视野 7 秒（>240 帧淘汰窗）回到 3320，census
无悬空；④：静止 active 3320→3320、failed 0、watermark 3590 不涨、defrag 后 census 全过；⑤：
大世界档 4253 条游历、failed 0、水位不涨。运行日志零 VUID（含 compute→compute 屏障链）。
