# 程序化天空：从参数到背景像素

> 功能流程导读（段内无序号前缀，2026-10-10 定例）。面向下一个读代码的人：天空参数从哪里来、每帧经过哪些账面、背景像素怎么算出来、关掉/失败时走哪条路。验收复述与实测读数见 [9.1.5](9.1.5-判定线与计量.md)。
>
> 分工：本篇讲**参数链路**（面板/BRP → 资源 → UBO → 像素）；颜色公式的原理见[算法原理](程序化天空盒算法原理.md)，帧内位置与 GPU 侧读写形状见[渲染流程](程序化天空盒渲染流程.md)。

## 一句话

一个资源（`SkySettings`）→ 每帧帧槽 UBO（304B，set1 b0）→ 合成 pass 的背景分支做 16 步大气散射积分 → HDR → 后链。整段没有新 pass、没有新描述符集、没有新同步对象、没有新纹理。

## 账面全景

| 账面 | 住址 | 内容 | 寿命 |
|---|---|---|---|
| `SkySettings` | `src/render/passes/sky/mod.rs`（`AshHostPlugin` 插入） | 天空全部参数，唯一真源 | 进程级 |
| 帧 UBO | `src/render/resident/tables/frame_uniform_table.rs` + `shaders/common/frame.wgsl` | 每帧槽一份 304B；`sky_enabled`/`sky_intensity` + 六个 `sky_*` vec4（三介质/行星/地面/太阳） | 帧槽级（2 组轮转） |
| 背景像素 | `shaders/scene/gbuffer/gbuffer_composite.wgsl` | `CLEAR_COLOR` 或 `sky_radiance(dir) * EXPOSURE` | 每帧 |
| 天空函数 | `shaders/common/sky.wgsl` | 纯函数，无绑定、无状态 | — |
| BRP 面 | `src/remote/features/sky.rs` | `sky_set` / `sky_stats`，读写上面的资源 | 进程级 |
| 面板页 | `src/overlay/tool_window/sky.rs` | 控件就地写同一份资源 | 进程级 |

## 文件分工（一层一句话）

- `src/render/passes/sky/mod.rs`：`SkySettings` 参数形状 + 默认梯度；9.2 起在此扩捕获与 SH 投影。
- `shaders/common/sky.wgsl`：`sky_radiance(dir, include_sun)`，单次散射积分 + 地面 + 太阳圆盘；不声明绑定，导入方须有 `frame: FrameUniforms`。
- `shaders/scene/gbuffer/gbuffer_composite.wgsl`：背景判定与求值（唯一调用点）。
- `src/render/resident/tables/frame_uniform_table.rs`：UBO 布局镜像（`offset_of!` 断言）、打包、每帧槽 UBO。
- `src/driver/host/frame/scene.rs`：`write_frame_ubo` 把 `SkySettings` 铺进 `FrameUniformsData`；`SceneInput` 取资源。
- `src/driver/host/frame.rs`：`draw_frame` 的"帧槽 UBO 与环写入"段调一次。
- `src/remote/features/sky.rs`：BRP 读写通道（校验 + 回显）。
- `src/overlay/tool_window/sky.rs`：天空面板页（控件写资源）。

## 逐时刻走读

### 1) 参数进来（每帧之前，随时）

- 面板：`ToolWindowParams` 里的 `ResMut<SkySettings>`，控件就地写字段。
- BRP：`sky_set` 校验后写同一份资源，回 `{applied, current}`；`sky_stats` 只读回显。
- 两者都不碰 GPU，也不发任何通知——`draw_frame` 每帧无条件重读资源。

### 2) 帧首准备（`draw_frame` → `frame/scene.rs`）

1. `FrameView::from_camera` 取 `view_proj` / `inv_view_proj` / `camera_pos`。
2. `FrameLight::gather` 取 `dir_to_light`（= 方向光 `back()`，表面指向太阳）与 `light_color`（线性色 × illuminance）。
3. `write_frame_ubo(slot, &view, &light, render_mode, &scene.sky)`：一次整块重写本帧槽的 304B。
   - 六个 `sky_*` 行：瑞利（xyz 系数 + w 标高）、米氏（系数/标高/g）、臭氧（xyz 系数）、行星几何（半径/大气顶/臭氧中心/臭氧全宽）、地面反照率、太阳（增益/角半径）。`atmosphere_height` 在这里现算成大气顶半径。
   - 发生在 `wait_for_slot` 的 fence 之后，与在飞 draw 不重叠。

### 3) 合成 pass（⑤ 段，全屏一次）

对每个像素：

1. 采样 G-buffer 深度；`depth.r <= 1e-6`（reverse-Z 远平面）= 背景。
2. 背景分支：
   - `sky_enabled == 0` 或 `mode != Shading` → 返回 `CLEAR_COLOR`（与原步骤 8 完全同一表达式）。
   - 否则用近平面点减相机位置求方向（`world_from_depth(uv, 1.0) - camera_pos`，退化时兜底 `(0,1,0)`）。
   - `sky_radiance(dir, true)`：大气/行星求交 → 16 步单次散射积分（Chapman 解析透射率）→ 地平线以下加地面 Lambert 项 → 太阳圆盘（按角度 smoothstep 软化）→ 整体系 `sky_intensity`，再乘 `EXPOSURE` 写进 HDR。
3. 非背景像素走原光照分支（本段未改）。

### 4) 后链

合成写 HDR → 透明层混合（背景已带天空色，天然叠在其上）→ Bloom → tonemap → SMAA → present。天空像素与其他 HDR 像素同路，所以会被 tonemap 的肩部压缩影响观感（默认梯度就是按这个反推的）。

## 失败与稳态路径

| 情形 | 行为 |
|---|---|
| `sky_enabled = false` | 背景返回 `CLEAR_COLOR`，与步骤 8 客户端逐像素一致（硬线实测 0 差异） |
| 调试模式（mode 1～8） | 背景保持清屏色，天空只在 Shading 画；该模式不过 tonemap，显示原始清屏色 |
| 无方向光 | `light_color` 全零 → 积分源项为零，天空全黑（物理行为，旧渐变的恒定底色没有了） |
| 相机缺席 | `camera_pos = 0`、`inv_view_proj = identity`（既有兜底）；背景方向仍有有限值，画面是"站在原点看天空"，不崩 |
| 相机在远平面附近 | 方向走 `dot(v,v) > 1e-12` 判空兜底 `(0,1,0)`，不出 NaN |
| 参数非法（BRP） | 回 `INVALID_PARAMS`，资源保持原值，画面不变 |
| 参数合法但极端（如强度 0） | 天空变黑，属用户意图，不做拦截 |
