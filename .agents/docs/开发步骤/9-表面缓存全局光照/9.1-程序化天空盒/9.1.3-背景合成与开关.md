# 9.1.3 背景合成与开关

> 施工记录。对应[段施工计划 §0.2/§1 9.1.3](施工计划：程序化天空盒.md)、[八段拆解 §2 9.1](../施工计划：天空盒、IBL 与表面缓存全局光照八段拆解.md)。

## 做了什么

只改 `shaders/scene/gbuffer/gbuffer_composite.wgsl` 的背景分支，不新开 pass、不新开管线：

```wgsl
if (depth.r <= 1e-6) {                                  // reverse-Z 远平面 = 背景
    if (frame.sky_enabled == 0u || frame.mode != MODE_SHADING) {
        return vec4f(CLEAR_COLOR, 1.0);                 // 与原返回逐位一致
    }
    let v = world_from_depth(in.uv, 1.0) - frame.camera_pos.xyz;
    let dir = select(vec3f(0.0, 1.0, 0.0), normalize(v), dot(v, v) > 1e-12);
    return vec4f(sky_radiance(dir, true) * EXPOSURE, 1.0);
}
```

- 调试模式（mode 1～8）背景保持清屏色：仪器视图不被天空污染。
- `sky_enabled = false` 原样返回 `CLEAR_COLOR`（不乘曝光、不做等价变形）——这是"与步骤 8 逐位一致"的硬线前提。
- 天空乘 `EXPOSURE`：与直接光同域，否则 tonemap 后亮度差一个数量级。
- 透明层不动：背景像素在合成里已有天空色，透明混合天然叠在其上。

## 关键坑：远平面反投影是 w=0 的无穷远点

段施工计划 §0.2 原写"背景方向由 `world_from_depth(uv, 0)` 反投影减 `camera_pos` 得到"。**实测这条路在本工程的投影下是坏的**：

- 投影是 reverse-Z + 无限远平面，`ndc.z = 0` 对应 `clip.w = 0`；`inv_view_proj * vec4(ndc, 1)` 得到的是 w=0 的无穷远点，`xyz/w` 出 `NaN/±Inf`。
- 症状：`saturate(NaN) = 0` → `up = down = 0` → 天空退化成**整片地平线色**。实测全屏均匀 `(154,160,169)`；把 `zenith/horizon/ground` 临时设成红/绿/蓝，整片仍是绿色（horizon），由此定位到"方向恒为 y=0"。
- 对策：用 `ndc.z = 1`（reverse-Z 近平面，反投影有限且离相机仅一个 near）的点减相机位置，透视下就是该像素的射线方向；再乘 `dot(v,v)` 判退化，给 `(0,1,0)` 兜底。

## 验证

- `sky_enabled=false` 与改动前二进制**客户端区逐位一致**（差异仅窗口标题栏文字，属窗口 chrome）——见 [9.1.5](9.1.5-判定线与计量.md) 判定线②。
- sky 开/关只改背景：几何像素零变化，背景像素全变（关掉 bloom/SMAA 排除邻域后处理串色）——判定线③。
- 调试模式 `mode=normal` 背景实测原始清屏色 `(38,69,105)`（未经 tonemap 编码的 sRGB 值），与步骤 8 同路径。
