## BRP 测试配方（本段实测用过）

```bash
python tools/brp.py raw --method ash_renderer/sky_stats
python tools/brp.py raw --method ash_renderer/sky_set --params-json '{"enabled":false}'
python tools/brp.py raw --method ash_renderer/sky_set --params-json '{"zenith":[0.9,0.1,0.1],"horizon":[0.95,0.85,0.2],"intensity":1500}'
python tools/brp.py raw --method ash_renderer/set_camera --params-json '{"yaw_deg":90,"pitch_deg":10,"radius":6,"target":[0,3,0]}'
python tools/brp.py raw --method ash_renderer/sun_set --params-json '{"azimuth_deg":-90,"elevation_deg":5}'
python tools/brp.py raw --method ash_renderer/set_transform --params-json '{"entity":"<光实体>","rotation_euler_deg":[0,90,0]}'   # 太阳压到地平线下
python tools/brp.py raw --method ash_renderer/set_render_mode --params-json '{"mode":"normal"}'
```

## 测试方法上的两个坑（后续段会复用）

1. **跨进程逐位比对必须先钉机位**。首轮拿"改动前的默认机位基线"直接比，差出 44 万像素；根因不是渲染差异，而是相机控制"首次接管"会把俯仰从进场值 0.088 rad 改成轨道值 0.2 rad（`相机控制首次接管：yaw 1.585 / pitch 0.200` 日志可见），是否接管取决于当次有没有输入事件。用 BRP `set_camera` 显式钉机位后两边完全一致。
2. **"只改背景"要关掉邻域后处理再比**。bloom 会把天空溢到几何轮廓上、SMAA 会在边界混色——这是物理必然，不关掉就无法区分"天空误入光照分支"和"后处理串色"。半透明 UI 叠加层同理，比对时按矩形排除。
