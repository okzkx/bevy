# 9.1.6 物理天空模型与参数面

> 施工记录。对应[施工计划：物理天空（9.1 追加）](施工计划：物理天空（9.1追加）.md)与[八段拆解 §2 9.1](../施工计划：天空盒、IBL 与表面缓存全局光照八段拆解.md)。这轮把 9.1 的渐变天空换成物理天空，档位 A（单次散射、无 LUT、无新绑定）。

## 做了什么

1. **重写 `ash_renderer/shaders/common/sky.wgsl`**（约 250 行），口径照 Unity HDRP Physically Based Sky：
   - 球求交（稳健形式 `d = (Rs/r)² − (1−cos²χ)`）+ 行星/大气双壳；
   - 三介质剖面：瑞利 `exp(−h/8000)`、米氏 `exp(−h/1200)`、臭氧三角剖面（20–40 km）；
   - 相函数：瑞利 `3/(16π)(1+cos²θ)`、米氏 Cornette-Shanks（g=0.8，含前向峰）；
   - 透射率：Chapman 解析近似（瑞利/米氏）+ 臭氧沿射线 2 样本积分（HDRP 同式）；
   - 主视线 **16 步**二次分布积分，段内解析积分 `(S − S·T_seg)/σ_e`；
   - 射线打中行星：地面 Lambert（反照率 × 阳光透过率）；
   - 太阳圆盘：沿用 9.1 的解析圆盘（角度软化 + `sun_gain`），不进积分。
2. **参数面换新**（`src/render/passes/sky/mod.rs`）：`SkySettings` 换成大气参数集，默认值照抄 HDRP Earth（瑞利 5.8/13.5/33.1e-6、标高 8000；米氏 10e-6、标高 1200、g 0.8；臭氧 0.65/1.88/0.08e-6、30±10 km）。
3. **帧 UBO 272 → 304B**：`sky_rayleigh`(208) / `sky_mie`(224) / `sky_ozone`(240) / `sky_geo`(256) / `sky_ground`(272) / `sky_sun`(288)，连同 `sky_enabled`(116)/`sky_intensity`(120)。三方同步（WGSL / `offset_of!` 断言 / 打包）一次改齐；`scene.rs` 的映射把 `atmosphere_height` 现算成大气顶半径、`sun_radius` 塞进 `sky_sun.y`。
4. **BRP 换参**（`src/remote/features/sky.rs`）：字段名与 `SkySettings` 同名（`rayleigh`/`mie`/`ozone`/`ground_albedo`/…），单位原始 SI（1/米、米、弧度）；校验按新参数（标高/宽度为正、`mie_anisotropy ∈ (−1,1)`、`sun_radius ∈ (0, π/2)` 等）。
5. **天空面板重排**（`src/overlay/tool_window/sky.rs`）：分「亮度 / 大气·瑞利 / 大气·米氏 / 大气·臭氧 / 行星 / 太阳」六节；散射与吸收系数按 ×1e-6 显示、写回还原，臭氧层高度按公里显示。

## 与 HDRP 的三处差异（都是有意为之）

| 差异 | HDRP | 本工程 | 理由 |
|---|---|---|---|
| 多次散射 | 32×32 LUT（参数变化时重算） | 无 | A 档边界：零新资源、零新绑定；背光/暮光偏暗是已知代价 |
| 地面反照率默认 | 0.12/0.10/0.09（地球土色） | 0.25 中性灰 | 本工程场景地面是灰色，土色会在地平线以下画一条褐色带；反照率是场景属性不是物理常数 |
| `intensity` 默认 | 1.0（配自动曝光） | 2.0 | 我们的曝光锚定 2 万 lux 直射，物理天空在此口径下比旧渐变暗数倍，需要标到同一显示区间 |

## 亮度标定过程（首轮 3.0 的教训）

第一版 `intensity = 3.0` + HDRP 土色地面：默认机位下天顶 `(81,120,157)` 尚可，但太阳升到 45° 时天顶变成 `(153,175,195)`——亮部挤进 ACES 肩部，蓝色被压成灰白；同轮地面是一条亮褐色带（`(173,167,153)`），与灰色场景地面完全不协调。

改为 `intensity = 2.0` + 灰色地面后的同一视角：天顶 `(120,146,172)`，地面 `(173,167,153)→` 与场景地面的灰色接近，过渡自然。标定判据是"天顶在 ACES 线性段内、地面与场景地面不成两条色带"，不是某个固定数字。

## 坑

1. **相函数的双重取负**：HDRP 的 `AirPhase(-dot(L,V))` / `AerosolPhase(-dot(L,V))` 两层函数体内各自再取负，净效果是 `P(dot(dir, sun_dir))`（正对太阳 → 前向峰）。照抄时如果只取一层符号，米氏峰会长到背光侧。
2. **臭氧剖面不是指数**：不能用 Chapman；沿射线裁到臭氧层两球壳之间取 2 样本（HDRP 的 `ComputeOzoneOpticalDepth`），乘 0.6。
3. **光晕参数消失**：`glow_intensity`/`glow_falloff` 删除，太阳周围的亮区现在来自米氏前向峰；面板/BRP 里再调"光晕"就改 `mie_scattering` 与 `mie_anisotropy`。
4. **无方向光 = 黑天**：`light_color` 全零 → 积分源项为零。这是物理行为，不是 bug；旧渐变的"恒定底色"没有了。
5. **`intensity` 乘全局**：连地面和太阳圆盘一起乘（与 HDRP 的 `_IntensityMultiplier` 一致）。所以调亮度也会放大地面色带。
