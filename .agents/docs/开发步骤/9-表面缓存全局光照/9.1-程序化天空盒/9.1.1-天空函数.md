# 9.1.1 天空函数

> 施工记录。对应[段施工计划 §0.1/§1 9.1.1](施工计划：程序化天空盒.md)与[八段拆解 §2 9.1](../施工计划：天空盒、IBL 与表面缓存全局光照八段拆解.md)。

## 做了什么

- 新增 `ash_renderer/shaders/common/sky.wgsl`：`sky_radiance(dir, include_sun)`。
  - 垂直渐变：`mix(horizon, zenith, pow(saturate(dir.y), 0.5))` 再 `mix(…, ground, pow(saturate(-dir.y), 1.5))`；两个幂都在 `dir.y = 0` 处退到 horizon 色，地平线两侧连续。
  - 太阳圆盘：按**角度**软化边缘（`acos(dot)` → `1 - smoothstep(0.8r, r, θ)`），颜色 `light_color.rgb * sun_gain`。
  - 光晕：`light_color.rgb * glow_intensity * pow(saturate(dot(dir, sun_dir)), glow_falloff)`。
  - `include_sun = false` 只返回渐变，供 9.2 的环境 cubemap 捕获排除太阳圆盘。
- 新增 `ash_renderer/src/render/passes/sky/mod.rs`：`SkySettings`（`Resource`）+ `Default` 默认梯度，9.2 起同目录扩捕获与 SH 投影。

## 接口约定

- 片段**不声明绑定**：头注写明导入方须声明全局 `frame: FrameUniforms`；片段自身 `// #import frame` 与 `// #import brdf`（后者只为复用 `saturate` 与 `safe_light_dir`）。build.rs 的展开按片段名去重，和入口里已有的同名导入不冲突。
- **返回值是 pre-exposure 辐亮度**，曝光乘算在调用方（合成 pass 末尾统一 `* EXPOSURE`），与直接光同域。
- 方向参数假定已归一化（调用方负责），函数内不再 `normalize`。

## 默认梯度与两轮调优

| 字段 | 终值 | 说明 |
|---|---|---|
| `zenith` | `[0.06, 0.14, 0.42]` | 天顶色（线性系数） |
| `horizon` | `[0.40, 0.50, 0.72]` | 地平线色 |
| `ground` | `[0.08, 0.075, 0.07]` | 地面色 |
| `intensity` | `2000.0` | 辐亮度缩放（pre-exposure 域） |
| `horizon_exponent` / `ground_exponent` | `0.5` / `1.5` | 两个过渡幂 |
| `sun_radius` | `0.01` rad（≈0.57°） | 角半径 |
| `sun_gain` | `1.5` | 圆盘增益 |
| `glow_intensity` | `0.02` | 光晕强度 |
| `glow_falloff` | `6.0` | 光晕衰减幂 |

首版默认（`horizon 0.62 / intensity 2500 / glow 0.15`）实测两处偏差，当轮改掉：

1. **地平线发灰**：0.62×2500×`EXPOSURE`≈0.25 已进 ACES 肩部，受光面大面积去饱和。降到 0.40×2000≈0.128 后回落线性段，天顶—地平线色差拉开。
2. **光晕把整片天空刷白**：`glow_intensity` 的单位是 `light_color`（≈illuminance 量级 2×10⁴），0.15 相当于 3000 的附加辐亮度，远高于天空本体 ~800。改 0.02（≈400）后只在太阳附近 10° 内可见。**这个单位约定是后续调参的坑**，面板与 BRP 的滑杆范围已按它收窄。

## 验证

- 渐变、太阳圆盘、太阳落到地平线以下圆盘消失、参数即时生效的实测证据见[9.1.5 判定线与计量](9.1.5-判定线与计量.md)。
- naga/spirv-val 编译零告警（build.rs 只对缺 `spirv-val` 的情况打 warning）。
