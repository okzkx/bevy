## 0. 选型裁决

1. **模型**：沿视线积分大气单次散射（HDRP Physically Based Sky 的口径，照抄其公式与默认常数，不自己发明）：
   - 三介质：瑞利（空气分子，∝1/λ⁴）、米氏（气溶胶，前向峰）、臭氧（吸收带）。
   - 行星几何：球形行星 + 大气壳，地平线由求交得到；地平线以下是受阳光照亮的球面（地面反照率）。
   - 透射率用 **Chapman 解析近似**（HDRP 同款），不做透射率 LUT，也不做嵌套 march。
   - 主视线积分 **16 步**、二次分布采样（HDRP `GetSample` 同式），段内用指数积分的解析形式。
   - **不做多次散射**（A 档边界）：估计会偏暗偏艳，用真实截图判定是否值得补 32×32 LUT（B 档）。
2. **太阳盘**：沿用现有解析圆盘（角度软化 + `sun_gain`），不进散射积分；原 `glow_*` 删除，太阳附近的亮区由米氏前向峰自然给出。
3. **替换而非双轨**：渐变实现留在 git 历史，工程里只保留物理模型；A/B 用旧二进制对照。
4. **不新增 GPU 资源**：没有 LUT、没有 compute pass、没有新描述符绑定；天空仍是合成 pass 背景分支里的纯函数（`sky.wgsl` 不声明绑定，参数来自帧 UBO）。这也是选 A 档的核心理由。

## 3. 判定线

1. **物理特征可见**：太阳能高度从 60° 降到 2°，地平线色由淡蓝转向橙红（波长相关散射的直接证据），天顶色变暗；整片天空亮度随太阳高度连续变化。
2. **地平线由几何产生**：地平线是一条随相机高度变化的锐利分界（不是两个 pow 的接缝）；地平线以下看到被阳光照亮的地面（反照率可调）。
3. **`sky_enabled=false` 与 9.1 基线逐位一致**（硬线）：仍走 `CLEAR_COLOR` 分支，客户区 diff = 0（旧二进制 + 钉机位对照）。
4. **参数即时生效**：改三介质密度/臭氧/地面反照率/太阳，下一帧可见；`sky_stats` 回显一致。
5. **性能可接受**：固定机位（含大面积天空）sky 开/关的帧时间差记录在案；背景像素 16 步积分的成本给读数，不设卡点但如实记录。
6. **回归**：hiz/lod/stream/fine/sponza 五脚本、库测试、零 VUID、clippy/fmt、WM_CLOSE exit 0。

## 4. 风险与坑

1. **亮度标定**：物理天空在 2 万 lux 输入下比旧渐变暗数倍（估算 HDR 0.05–0.15 vs 旧 0.23），`intensity` 默认要按新后链重新标定，不能沿用 1.0。9.2 的 IBL 亮度也会随之变化，属 9.2 的标定问题，本段只记录。
2. **f32 精度**：行星半径 6.4e6 在 f32 下 ulp ≈ 0.5 m，高度用 `r − R` 计算误差 <1 m，密度相对误差 ~1e-4，可接受；但要避免在两个大数之间做多余减法（照 HDRP 的 `IntersectSphere` 稳健形式）。
3. **地面接缝**：天空的"行星地面"和场景真实地面是两套几何。零日场景地板在 y=0、相机 3 m，天际线在 ~6 km；地板边界之外可能出现两条"地面"的交界。地面反照率可调，必要时给"关掉天空地面"的开关（本段先不做，留判定线记录）。
4. **`include_sun` 语义**：物理天空下它只排除**圆盘**，米氏前向峰（太阳附近的亮区）仍进 IBL 捕获——与 HDRP 的 cubemap 烘焙同口径；9.2 的"太阳不双计"判定线要按此写。
5. **积分退化**：视线贴近地平线时路径极长，`(S − S·Tseg)/σE` 在 σE→0 时要兜底（`max(σE, 1e-12)`）；地面求交与大气出交的先后顺序要先判，避免把地面内部当空气积分。
6. **相机海拔假设**：本段取 `camera_pos.y` 为海拔（海平面 = y=0），室外大世界沿用；室内/负高度场景会看到"地下"，文档写清。

## 5. 边界

- **不产生**：多次散射 LUT、SkyView LUT、地面辐照度 LUT、大气透视/体积雾、云、星空、行星纹理、时间系统。
- **不改**：合成 pass 的绑定与描述符布局、透明层、阴影链、后处理链、G-buffer、GPU-driven 闭环、光源常驻表。
- **不主张**：物理正确的一天（太阳 13 万 lux）；曝光锚点保持 2 万 lux 直射口径，天空亮度用 `intensity` 标定。
