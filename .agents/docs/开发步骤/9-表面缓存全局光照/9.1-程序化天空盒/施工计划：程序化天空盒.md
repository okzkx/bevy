## 0. 立案期裁决（施工可推翻但须记录）

### 0.1 天空模型：解析渐变 + 可见太阳圆盘，不做大气散射

第一版不引入 Preetham/Hosek，也不引入云层。模型只要求三件事：

1. **垂直渐变**：天顶色 → 地平线色 → 地面色，两个 `pow(saturate(±dir.y))` 控制过渡宽度；
2. **太阳圆盘**：方向取 `frame.dir_to_light.xyz`（表面指向太阳），颜色取 `frame.light_color.rgb`，角半径与增益可调；
3. **可选光晕**：太阳附近一个低阶 `pow(saturate(dot(dir, sun_dir)))` 项，用来让地平线附近有方向感。

```
sky_radiance(dir, include_sun):
    up   = saturate(dir.y)
    down = saturate(-dir.y)
    c = mix(horizon, zenith, pow(up, horizon_exponent))
    c = mix(c, ground, pow(down, ground_exponent))
    c *= intensity
    if include_sun:
        c += sun_color * sun_gain * smoothstep(cos_radius - edge, cos_radius, dot(dir, sun_dir))
        c += sun_color * glow_intensity * pow(saturate(dot(dir, sun_dir)), glow_falloff)
    return c
```

- `include_sun` 是给 9.2 的捕获留的开关：可见天空传 `true`，IBL 捕获传 `false`（太阳圆盘是高频亮斑，进 SH/预滤波会污染低频项；Unity 的 `_SUNDISK_NONE` 同目的）。
- 模型接口保持 `sky_radiance(dir, include_sun)`；以后换 Preetham/加云只换实现，不改调用方。
- 天空辐亮度与直接光同域（**pre-exposure**）：合成 pass 末尾统一乘 `EXPOSURE`，天空函数内部不乘曝光。

### 0.2 可见天空的落点：合成 pass 的背景分支

`gbuffer_composite.wgsl` 已经有背景判定：reverse-Z 深度清 0 = 远平面。当前该分支返回 `CLEAR_COLOR`（`gbuffer_composite.wgsl:155-158`）。本段把它改成：

```
if depth.r <= 1e-6 {
    // 只在 Shading（mode 0）画天空；调试模式保持清屏色，避免污染仪器视图
    if (!sky_enabled || frame.mode != MODE_SHADING) { return vec4f(CLEAR_COLOR, 1.0); }
    dir = normalize(world_from_depth(in.uv, depth.r) - frame.camera_pos.xyz)
    return vec4f(sky_radiance(dir, true) * EXPOSURE, 1.0)
}
```

- 不新开 sky pass、不新开管线：背景像素本来就在这个全屏 pass 里，天空函数只是替换返回值。
- `dir` 由已有的 `world_from_depth` 反投影得到；reverse-Z 下 `depth = 0` 就是远平面，方向正确。
- 透明层在合成之后绘制，背景像素已有天空色，透明混合天然叠在天空上；本段不动透明 pass。
- `sky_enabled = false` 时**必须原样返回 `CLEAR_COLOR`**（不乘曝光、不做任何等价变形），保证与步骤 8 的背景逐位一致。

### 0.3 数据载体：帧 UBO 扩 64B（208 → 272B）

天空参数是每帧常量，走帧 UBO 的成熟纪律（每帧槽一份、fence 保护、整块重写），不新开 set。

| offset | 字段 | 类型 | 说明 |
|---|---|---|---|
| 0 | `view_proj` | mat4 | 不变 |
| 64 | `dir_to_light` | vec4 | 不变；太阳方向直接复用 |
| 80 | `ambient_color` | vec4 | 不变（9.2 的 IBL 关路径仍用） |
| 96 | `light_color` | vec4 | 不变；太阳圆盘颜色复用 |
| 112 | `mode` | u32 | 不变 |
| 116 | `sky_enabled` | u32 | 0 关 / 1 开（新增，占原对齐垫） |
| 120 | `sky_intensity` | f32 | 天空整体强度（新增，占原对齐垫） |
| 124 | `_pad` | u32 | 对齐垫 |
| 128 | `inv_view_proj` | mat4 | 不变 |
| 192 | `camera_pos` | vec4 | 不变 |
| 208 | `sky_zenith` | vec3 + 4B | xyz = 天顶色；w = `horizon_exponent` |
| 224 | `sky_horizon` | vec3 + 4B | xyz = 地平线色；w = `ground_exponent` |
| 240 | `sky_ground` | vec3 + 4B | xyz = 地面色；w = `sun_angular_radius` |
| 256 | `sky_sun` | vec4 | x = `sun_gain`、y = `glow_intensity`、z = `glow_falloff`、w = 0 |
| — | **总长** | **272** | `FRAME_UBO_SIZE` 208 → 272 |

坑：WGSL uniform 里 `vec3f` 成员按 16B 对齐，四个分量各占一个 vec4 槽（尾部 4B 写 0），不能按 12B 紧凑算偏移；Rust 侧 `FrameUniformTableLayout` 的 `offset_of!` 断言是三方同步的唯一闸门（WGSL / 布局镜像 / `pack_frame_uniforms`）。

### 0.4 太阳：方向与颜色都复用现有灯光，不新增光源

- 方向 = `frame.dir_to_light.xyz`（已经是"表面指向光源"的单位向量；天空里要的是"从原点指向太阳"，同向）。
- 颜色 = `frame.light_color.rgb`（linear × illuminance）；圆盘亮度再乘 `sun_gain`，让"可见圆盘"和"直接光照强度"解耦，便于单独校准。
- 太阳圆盘只进可见天空，不进 9.2 的 IBL 捕获；9.2 的 cubemap 里太阳由直接光负责，避免高光双计。
- 无方向光时 `dir_to_light` 是占位方向、`light_color` 全零，太阳圆盘自然消失，不需要额外分支。

### 0.5 TOD：本段只暴露参数，不接 TOD 驱动

- 天空参数每帧从 `SkySettings` 写进 UBO，BRP 改参下一帧生效。
- `sky_enabled` 默认开（默认梯度是新的可见基线）；`sky_set {"enabled": false}` 回清屏色，供回归/A-B。
- 以后接 TOD 时，驱动方只改 `SkySettings`（或直接改 `FrameUniformsData.sky_*`）；9.1 不引入时间系统、不做参数关键帧。
- 9.2 的 cubemap 捕获脏标记以本段参数为输入；所以本段的参数形状就是 9.2 的"天空状态"接口，命名一旦定下，9.2 不再改。

### 0.6 BRP 与面板（施工时偏离：原"egui 不接"）

新增 `sky_set`（写 `enabled`、六色/强度/指数/太阳参数，缺省字段不动）与 `sky_stats`（只读回显当前值）。

- 参数校验：颜色数组长度 3、有限值；`intensity ≥ 0`；`sun_angular_radius` 落在 `(0, π/2)`；指数 `> 0`。
- 错误回 `BrpError`，不 panic（系统错误处理规范）。
- **施工期用户追加要求**：天空面板也接（工具窗口"渲染"组新增"程序化天空盒"页，控件与 BRP 写同一份 `SkySettings`）。理由：以后要在面板里调天光。详见 [9.1.4 施工记录](9.1.4-设置资源BRP与天空面板.md)。

## 2. 判定线（照八段拆解 §2 9.1 细化）

1. **天空可见且方向正确**：默认参数下背景出现天顶—地平线—地面渐变；移动方向光（或 BRP 改 `sun` 相关参数）时太阳圆盘沿 `dir_to_light` 移动；太阳在地平线以下时圆盘消失。
2. **sky 关 = 步骤 8 逐位一致（硬线）**：段开工前用当前 HEAD 抓基线截图（固定场景/机位/光照）；实现后 `sky_set {"enabled": false}` 同机位重抓，像素差为零（允许截图通道噪声，不接受画面结构差异）。证据入施工记录。
3. **sky 开只改背景**：Shading 模式下 sky 开/关同机位对照，几何像素（深度非远的区域）逐像素一致；只有背景区域变化。调试模式（mode 1～8）的背景保持清屏色。这条验证天空函数没有误入光照分支。
4. **参数即时反映**：`sky_set` 改天顶/地平线/地面色、强度、指数、太阳角半径后下一帧生效；`sky_stats` 回显与画面同步。
5. **TOD 接口就位**：连续改太阳方向/颜色（模拟 TOD 的两个关键量）时天空渐变与圆盘连续变化，无跳变/NaN；本段不要求自动 TOD。
6. **回归**：既有判定线零回退（按 8.2.5 口径跑 hiz/lod/stream/fine/sponza 五脚本）、库测试、零 VUID、`clippy` 全净、`fmt --check` 全绿、WM_CLOSE exit 0。

## 4. 风险与坑

1. **UBO 三方同步**：`shaders/common/frame.wgsl`、`FrameUniformTableLayout`（`offset_of!` 断言）、`pack_frame_uniforms` 必须同改；`FRAME_UBO_SIZE` 208→272 后还要改 `frame.wgsl` 头注、`gbuffer_write.wgsl` 的 208B 注释。
2. **背景方向重建**：`world_from_depth(uv, 0.0)` 在 reverse-Z 下是远平面点；必须减去 `camera_pos` 再归一化，不能直接用远平面坐标当方向。相机在远平面附近时做退化保护。
3. **天空与曝光域**：合成 pass 的光照分支末尾乘 `EXPOSURE`，背景分支原来不乘；天空必须乘 `EXPOSURE`，否则 tonemap 后亮度差一个数量级。`CLEAR_COLOR` 回退分支保持原样不乘。
4. **vec3 在 uniform 的对齐**：`sky_zenith/horizon/ground` 各占 16B 槽（208/224/240），Rust 侧用 `[f32;4]` 行；`put_vec4(..., w=...)` 落位，别用 12B 步长。
5. **地平线接缝**：`up/down` 两个 `pow` 在地平线处要连续；用 `mix(horizon, ...)` 保证 `dir.y=0` 时两侧都退到 horizon 色，避免一条亮线。
6. **太阳圆盘走样**：低分辨率下硬边圆盘会闪；用 `smoothstep` 软化边缘，角半径不要小于一个像素覆盖的角度；光晕项是可选的低频补丁，不要用高频噪声。
7. **BRP 参数校验**：数组长度 3、有限值、`intensity ≥ 0`、`sun_radius ∈ (0, π/2)`、指数 `> 0`；错误回 `BrpError` 不 panic。
8. **运行实例锁 exe**：运行中的旧实例会让 `cargo build` 链接失败（os error 5）；改动前先 WM_CLOSE，确认退出码为 0。
9. **透明层顺序**：背景天空在合成里写，透明层在合成后混合；不要把天空挪到透明之后画，否则透明会先和清屏色混合。

## 5. 边界

- **不产生**：环境 cubemap、SH、GlobalProbe、IBL、材质环境光改动、世界空间缓存、射线、Volume（9.2～9.8）。
- **不做**：Preetham/Hosek 大气散射、云层、星空、镜头光晕、自动曝光、TOD 时间系统、egui 面板。
- **不改**：透明层着色、阴影链、后处理链、G-buffer 布局、GPU-driven 闭环、光源常驻表、环境光项。
- **不主张**：天空遮挡（室内漏光）、天空高光反射、IBL 能量校准；这些归 9.2。
