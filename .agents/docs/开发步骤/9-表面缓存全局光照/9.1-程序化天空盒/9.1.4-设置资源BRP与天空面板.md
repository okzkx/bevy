# 9.1.4 设置资源、BRP 与天空面板

> 施工记录。对应[段施工计划 §0.5/§0.6/§1 9.1.4](施工计划：程序化天空盒.md)。**偏离计划一处**：§0.6 原写"BRP 先行，egui 不接"，用户当轮追加要求"要在面板里配置成可开关/单独出一个程序化天空盒面板，方便以后调天光"，本段改为 **BRP 与面板双通道写同一份 `SkySettings`**。

## 做了什么

1. **资源**：`SkySettings`（`src/render/passes/sky/mod.rs`）由 `AshHostPlugin` `init_resource`，是天空参数的唯一真源；`draw_frame` 每帧照它写帧 UBO，改参下一帧生效。
2. **BRP**（`src/remote/features/sky.rs`，注册在 `src/remote/mod.rs`）：
   - `ash_renderer/sky_set`：`{enabled, zenith[3], horizon[3], ground[3], intensity, horizon_exponent, ground_exponent, sun_radius, sun_gain, glow_intensity, glow_falloff}`，缺省字段不动；回 `{applied, current}`。
   - `ash_renderer/sky_stats`：当前值只读回显。
   - 校验：颜色长度 3 且非负有限；`intensity` 非负；两个过渡幂与 `glow_falloff` 为正；`sun_radius ∈ (0, π/2)`；`sun_gain`/`glow_intensity` 非负。错误一律 `BrpError`（`invalid_params`），不 panic。
3. **天空面板**（`src/overlay/tool_window/sky.rs` + `tool_window/mod.rs`）：工具窗口导航"渲染"组新增 **程序化天空盒** 页。
   - 开关 + BRP 通道提示行；渐变三色拾色器、强度、两个过渡幂；太阳圆盘半径（界面按度数、存弧度）、圆盘增益、光晕强度、光晕衰减幂。
   - 控件就地写 `SkySettings`（`ToolWindowParams` 加 `sky_settings: ResMut<SkySettings>`），与 BRP 写同一份资源，互不冲突。
4. `overlay/mod.rs` 与 `remote/mod.rs` 的模块表补条目。

## 分工与语义

- `sky_set`/`sky_stats`/面板三方**只写资源**，不碰 GPU；UBO 写入仍归 `draw_frame` 的 `write_frame_ubo`，与其他每帧常量同纪律（帧槽一份 + fence 保护）。
- 面板不新增状态资源：`SkySettings` 本身就是面板状态，窗口折叠态仍由 egui 自己管。

## 验证

- BRP：`sky_stats` 回显默认值正确；`sky_set` 改三色/强度即时生效（采样像素 `(109,122,150) → (160,130,90)`，见 [9.1.5](9.1.5-判定线与计量.md) 判定线④）；非法值回 `INVALID_PARAMS`（代码路径，未逐条实测错误串）。
- 面板：见下方"面板验证方式"。截图 `.temp/9.1/panel_sky_page.png`——导航高亮"程序化天空盒"，页面含开关、三色块、四根滑杆与两组数值，读数与 `SkySettings` 默认值一致（强度 2000 / 天顶幂 0.50 / 地面幂 1.50 / 圆盘半径 0.57° / 增益 1.50 / 光晕 0.02 / 衰减 6.0）。

## 面板验证方式（测试手段记录）

- 面板默认折叠（`default_open(false)`），本会话不允许真实鼠标注入，先试了 BRP 虚拟鼠标（`ash_renderer/mouse_move` / `mouse_button`）：指针位置与按键事件确实进了应用（`ash_renderer/mouse_status` 读到 `(70,26)`、相机控制也响应了同一批事件），但 egui **没有**响应标题栏点击（窗口未展开，悬停也无高亮）。
- 改走测试规范允许的**临时默认值**路线：临时把 `default_open(true)` + 默认页设为天空页，构建截图验证页面渲染，**验后已还原**（还原点已重编并复跑判定线②）。
- 遗留观察（不阻塞本段）：虚拟鼠标注入 → egui 点击链路本次未打通（真实鼠标路径未受影响，面板日常使用即该路径）。若后续要用 BRP 驱动 egui 自动调参，需先查清该链路。
