# 9.7 屏幕 gather 与最终注入（任务面板）

> 2026-11-24 开工。施工依据：[施工计划：屏幕 gather 与最终注入](施工计划：屏幕gather与最终注入.md)（2026-11-24 立案）；
> 屏幕侧四级滤波的 Unity 依据见 [Unity SCGI 实现](../../../笔记/光照与材质/Unity%20SCGI%20实现.md)，注入公式与覆盖范围见
> [SCGI 间接光注入端](../../../笔记/光照与材质/SCGI间接光注入端.md)。
> 本目录记录"实际做了什么"；计划文档只流转状态，不回写实现细节。

**一句话**：每帧在 1/4 分辨率把像素反投影成世界位置、查 Volume 内 rank 0 的 patch，先做 patch 级空间/时域滤波，
再把查表结果压成 L0+L1 去噪并做全分辨率双边上采样，最后由合成 pass 用这张全分辨率辐照度替换 Volume 内不透明像素的
IBL 漫反射——这是"缓存被着色消费"的唯一入口；本段不做动态收敛验证与压测（归 9.8），不改射线侧与分配侧，
不碰透明层与高光。

**状态：✅ 主体收官（2026-11-24，分支 `goal/9.7`）。** 七篇施工记录 + [流程导读](屏幕侧gather到注入流程.md) 齐；判定线 ①②③④⑥⑧⑨ 闭环、⑤⑦ 部分；视图 14/15 与 `scgi_stats` 已落，**16/17 与 `scgi_ms` 按 §5 待决顺延**（拒绝率要扩 `GI_COUNTER_WORDS`、计时点位 `TimestampPoint` 0..11 已满）。
