# 9.7.4 1/4 屏幕查表与 L1 压缩

> 2026-11-24 施工。依据 [施工计划](施工计划：屏幕gather与最终注入.md) §9.7.4。本文件记录"实际做了什么"。

**一句话**：每线程一个 1/4 像素（= 全分辨率 4×4 块），按 9.7.1 的网格口径在块内落三个样本点
（本帧播种点 / 对角 / 块心），各自反投影 + 取法线 + 查 Volume 内 patch，按 Unity 的样本规则
（中心样本权重 0.01 且不查 rank，其余只收 rank 0）加权合成，压成 L0（RGBA16F，物理单位 + 覆盖率 a）
与 L1（RGBA8，三轴方向比值）两张 1/4 目标——**这是缓存第一次被屏幕侧真正读到**。

## 做了什么

### 1. 两张 1/4 目标与常驻描述符集（`screen_gather.rs` 新文件）

| 项 | 内容 |
|---|---|
| `scgi_l0` | 1/4、`R16G16B16A16_SFLOAT`、双缓冲；rgb = L0 辐照度（物理单位），a = 覆盖率 |
| `scgi_l1` | 1/4、`R8G8B8A8_UNORM`、双缓冲；rgb = 三轴方向比值编码，a = 备用 |
| 显存 | 1080p 时 480×270×(16+4)B×2 ≈ 5.1 MiB（`mem` 账进 `SurfaceCacheMemory` 之外的独立读数） |
| 布局 | `scgi_targets` 集：b0/b1 = A 组、b2/b3 = B 组，四个 `StorageImage` |
| 生命周期 | 布局与描述符池 **只建一次**（`new`），图随 swapchain 尺寸在 `ensure` 里重建并重写同一张集 |

### 2. `shaders/scene/gi/screen_gather.wgsl`（新）

- 逐像素：`low_to_full` 取三个块内样本 → `textureLoad` 深度（D32 不可过滤，绝不用采样器）→
  `world_from_depth` 反投影 → 法线按 `normal_source` 取平面差分或 G-buffer 着色法线 →
  `lookup_cell_key`（9.7.1 的只读链）→ `cell_patch` → `filtered_irradiance1`（**读时域输出 B**）。
- 样本规则：`i == 0`（本帧播种点）权重 0.01、**不查 rank**；其余只接受 `rank 0 且 update_count ≥ 1`。
- `a` = 命中 rank 0 的样本权重 / 尝试过的样本权重（Volume 外、无命中 = 0）→ 合成端据此回 IBL。
- 写了 `gi_compression.wgsl`：`l1_encode_axis` / `l1_decode_ratio` / `l1_decode_axis` / `scgi_evaluate`。

### 3. 录制与登记

`SCREEN_GATHER_PIPELINE`（set0 帧 UBO / set1 GI / set2 G-buffer 采样集 / set3 `scgi_targets`，32B push）
恒建、进 `ALL_PIPELINES`；`scgi_targets` 进 `ALL_SETS` 并在 `init.rs` 里随 `SetLayouts` 登记。
`GiFrameDraw.screen_gather` 排在时域滤波之后录。参数面 `lookup_samples`（1..3）进 `gi_set` 与面板。

## 钉明（相对计划的裁决）

1. **L1 存"三轴方向比值"而不是全彩 RGBL1**。计划 §0.4 给的公式 `l1 × √3/(4·l0) + 0.5` 只有三个
   通道，而 patch 的 L1 是"三轴 × RGB"九个标量，RGBA8 装不下。本段取"方向保真、颜色跟随 L0"：
   每轴取 RGB 均值编码成比值，解码时比值乘回 **L0 的颜色**（`E(n) = l0·(1 + Σ ratio·n)`）。
   **代价：间接光的色向性被抹平**（红墙对绿面的色渗方向差异看不出来）。若 9.7.5 读图判定不够，
   换 RGBA16F 存三轴 RGB 即可（多 ≈2.8 MiB）——已列入 9.7.5 的待决。
2. **图必须 `initialLayout = UNDEFINED` 创建**。原先写的是 `GENERAL`（以为能省掉迁移），现场核验
   抓到 `VUID-VkImageCreateInfo` 一类的校验错误（8 行），改为 UNDEFINED + 首帧一道
   UNDEFINED→GENERAL 屏障，之后恒 GENERAL。这条修正**正是** 9.7.4 现场核验的价值。
3. **目标集要进 `SetLayouts` 登记**，不能只 `SetLayoutDesc::create` 自建：管线按声明 `get` 取用，
   未登记会在启动期直接失败（"描述符集布局 scgi_targets 没有登记"）。`ScgiTargets::new` 因此建在
   `layouts` 之前，并把 `set_layout()` 交给 `SetLayouts`；拆除顺序排在 `GiSetLayout` 之后
   （管线先拆、布局后拆）。
4. **读 B 不读 A**：`filtered_irradiance1`（时域输出）才是屏幕链的正式输入；A 只是滤波链中间态。
5. **不做方向抖动**：计划§9.7.4 提到"方向在 `cos = 0.9` 锥内抖动"，本段只在**位置**上按块内网格
   取三点，方向抖动留到 9.7.5 的上采样（两级都抖会叠出双重噪声）。这条与计划有出入，记录在案。
