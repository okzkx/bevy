# 9.7.7 场景验收、判定线与调档

> 2026-11-24 施工。依据 [施工计划](施工计划：屏幕gather与最终注入.md) §9.7.7 与用户定下的通过标准：
> **必须开测试场景、跑各种机位与各种灯光，肉眼确认效果符合预期**，不能只靠开关回归与数字。

## 一、验收脚本

`tools/gi_gather_test.py`（自启宿主、逐项采证、退出码）。四条判定线：干净锚、场景 A/B 矩阵、
墙背面变暗（方向性）、零 VUID，外加一条**取证新鲜度自检**。用法与 `tools/gi_estimation_test.py` 同形。

首轮结果：**5/5 通过**（读数见下）。

## 二、两条取证铁律（都是踩出来的）

1. **取证必须用 `ash_renderer/frame_dump`，不能用 PrintWindow**。第一版用
   `tools/capture_window.py`，四个不同机位拿到的截图 **md5 完全一致**（均值都 59.2）——
   窗口被遮挡/失焦后 winit 不再呈现，PrintWindow 返回最后一帧。`frame_dump` 是渲染器自回读
   （`src/remote/census/frame_dump.rs` 头注写明"不依赖桌面会话，是画面取证的兜底通道"）。
   并加**新鲜度自检**：转一下太阳，前后两帧差分必须 > 0.5/255（实测 23.8，过）。
2. **轨道相机正 pitch 才是俯视**。`camera_control.rs`：`offset = r·(sin yaw·cos pitch,
   sin pitch, cos yaw·cos pitch)`。前两版把 pitch 写成负值，相机钻到地面以下，四个机位全废。

另一个坑：**默认世界那栋砖楼在原点**，测试场要挪到 `x = 80` 的空地，否则摆进楼里。

## 三、测试场与矩阵

场地（`spawn_shape` 现搭）：地面 30×24、背墙 12×5（挡住 -z 侧天光）、白箱、红柱（色渗源）、
绿球、自发光面板（0.8²，emissive 6/3/0.6）。

- 机位：`cam_front`（正面）、`cam_close`（近景）、`cam_behind`（墙背面，漏光/遮挡判据）
- 灯光：`sun_hi`（55°）、`sun_low`（12°）

## 四、读数（1600×900，调档后）

| 组 | IBL 均值 | SCGI 均值 | A/B 差分 |
|---|---|---|---|
| sun_hi / cam_front | 116.1 | 114.3 | 3.64 |
| sun_hi / cam_close | 118.1 | 113.6 | 6.52 |
| **sun_hi / cam_behind** | **47.4** | **42.6** | 4.78 |
| sun_low / cam_front | 56.7 | 56.2 | 0.91 |
| sun_low / cam_close | 51.5 | 50.5 | 1.08 |
| sun_low / cam_behind | 160.8 | 159.7 | 1.58 |
| 干净锚（常量天空 L=1，太阳地平线） | 29.42 | 30.30 | 比值 **1.0298** |

**判读（"符合预期"的实质证据）**：

1. **墙背面变暗**（47.4 → 42.6）：那一侧看不到天空，缓存如实反映遮挡，而 IBL 的无限远假设会
   高估——这正是 SCGI 相对 IBL 的核心价值，方向正确。
2. **干净锚比值 1.03**：常量天空下两条路径给出同一量级的画面（±5% 内），说明注入公式与单位
   口径没有差一个常数；IBL 侧锚点仍然精确（`ibl_stats.probe16.center_energy` = π）。
3. 低太阳与只开天空两组差分很小（0.9～1.6），因为这两种情况下缓存与 IBL 都主要看天光，
   结果接近是应该的。
4. 自发光面板在近景里能看到对邻面墙的抬升（读图确认）。

## 五、滤波调档（本段唯一的实现改动）

原默认 `spatial_radius = 1.5` + 1 遍去噪，在大面积白墙上能看出 **40～80 px 的方形亮度台阶**。
扫档（同机位同灯光）：

| 组合 | 读图结论 |
|---|---|
| r1.5 / p0 | 块状明显 |
| r1.5 / p2 | 减轻，仍可见 |
| r3.0 / p1 | 明显减轻 |
| **r3.0 / p2** | 基本抹平，几何边缘仍锐（双边权重在工作） |
| r6.0 / p2 | 最干净，但 3 m 半径会把不同房间的光糊在一起，不取默认 |

取 **`spatial_radius = 3.0`、`denoise_passes = 2`** 作新默认（理由写进 `gi/mod.rs` 的默认值注释）。

## 六、`scgi_stats` 的读数不可靠（如实记录）

本段新增的 `scgi_stats`（读回全分辨率辐照度求均值/覆盖率）**数值不稳定**：同一条锚在
不同轮次读到过 1.17、3.14、-5.9、509。原因未查明（怀疑读回时机与布局迁移、或 fp16 解码在
大动态范围下的处理）。因此**判定线不依赖它**——干净锚改用屏幕比对（`frame_dump` 的整屏均值），
那一侧稳定可复现（1.0298）。`scgi_stats` 的覆盖率与 alpha 读数在各轮一致（覆盖率 1.0、
alpha 0.995～0.999），可以留用；`l0_*` 三项在修好之前只能当调试线索，不能当判定依据。
