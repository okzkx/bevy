## 一、场景验收的方法（两条铁律，都是踩出来的）

### 1. 取证用 `frame_dump`，不用 PrintWindow

第一版用 `tools/capture_window.py`（PrintWindow）取证，四个不同机位拿到的图**完全相同**
（md5 一致、均值都 59.2），也就是窗口停在了最后一帧——被遮挡/失焦时 winit 不再呈现。

改用仓库现成的 `ash_renderer/frame_dump`（`src/remote/census/frame_dump.rs` 的头注就写了
"渲染器自身的回读不依赖桌面会话，是画面取证的兜底通道"）。并加了**新鲜度自检**：转一下太阳，
前后两帧的整屏差分必须 > 0.5/255，否则说明渲染停了、本轮取证作废。实测 24.05/255，通过。

### 2. 轨道相机：**正 pitch 才是俯视**，yaw 0 = 相机在 +Z 侧

`camera_control.rs` 里 `offset = radius · (sin(yaw)·cos(pitch), sin(pitch), cos(yaw)·cos(pitch))`。
前两版把 pitch 写成负值，相机钻到地面以下，看到的是地面背面与墙背面（一屏灰/黑），
四个机位全废。改用正 pitch（6°～45°）后画面立刻正常。

### 3. 测试场要避开默认世界

默认世界那栋砖楼在原点，第一版把测试场摆在 `z ≈ 10`，其实是摆进了楼的内部。现在整场挪到
`x = 80` 的空地上（头顶开阔天空），机位目标跟到 `(80, 1.0, 9.5)`。

## 二、测试场与矩阵

场地（全部 `spawn_shape` 现搭，不动默认世界）：

| 件 | 尺寸/位置 | 用途 |
|---|---|---|
| 地面 | 30×0.3×24（顶面 y = 0） | 大平面，块状最容易看出来的地方 |
| 背墙 | 12×5×0.3（z = 4） | 挡住 -z 侧天光 → 靠墙内侧应当变暗（漏光/遮挡的判据） |
| 白箱 | 1.2³ | 接触阴影与"靠墙变暗" |
| 红柱 | 0.9×2.6×0.9 | 色渗源（红柱旁边的地面/球是否带红） |
| 绿球 | r = 0.5 | 法线朝向与球面过渡 |
| 自发光面板 | 0.8×0.8，emissive(6, 3, 0.6) | "自发光 → 缓存 → 邻面"的间接光路径 |

机位 6 个：`cam_front / cam_left / cam_right / cam_high / cam_close / cam_behind`（含墙后那一侧）。
灯光 4 组：`sun_hi`（55°）、`sun_low`（12°）、`sky_only`（太阳压地平线）、`point_wall`
（贴墙暖色点光，半径 6、强度 40、开阴影）。每组机位都做 `scgi=0 / 1` 的 A/B。

## 三、当前读数（1600×900，调档后）

整屏均值与 A/B 差分（`/255`）：

| 组 | IBL 均值 | SCGI 均值 | A/B 差分 |
|---|---|---|---|
| sun_hi / cam_close | — | — | 6.44 |
| sun_hi / cam_front | 115.99 | — | 3.33 |
| sun_hi / cam_behind（墙背面） | 47.4 | **42.8** | 4.83 |
| sun_low / cam_front | 56.7 | 56.5 | 0.79 |
| sky_only / cam_front | 30.7 | 31.6 | 1.08 |
| point_wall / cam_close | 58.2 | 59.5 | 1.73 |

**方向性检查（这是"符合预期"的实质证据，不是亮度变化）**：

- 太阳高照时，开阔地面的缓存能量高于"无限远 IBL"，所以注入后画面**变亮**（cam_front 差分 3.33）；
- **墙背面变暗**（47.4 → 42.8）：那一侧看不到天空，缓存如实反映遮挡，而 IBL 的无限远假设会
  高估——这正是 SCGI 相对 IBL 的核心价值，方向正确；
- 低太阳（12°）与只开天空两组几乎不变（0.79 / 1.08）：这两种情况下缓存与 IBL 都主要看天光，
  结果接近是应该的；
- 自发光面板在工作台右侧有明显的光晕，面板附近墙面被抬起头（读图确认）。

## 四、滤波调档（本段唯一的实现改动）

`spatial_radius = 1.5`、`denoise_passes = 1`（原默认）在大面积平面上**看得出块状**：
墙上是一块块约 40～80 px 的方形亮度台阶。扫档（`.temp/tune_filters.py`，同机位同灯光）：

| 组合 | 读图结论 |
|---|---|
| r1.5 / p0 | 块状明显（墙面方块边界清楚） |
| r1.5 / p2 | 减轻，仍可见 |
| r3.0 / p1 | 明显减轻，残余 |
| **r3.0 / p2** | 基本抹平，几何边缘仍然锐（双边权重在工作） |
| r6.0 / p2 | 最干净，但 3 m 半径会把不同房间的光糊在一起，不敢默认 |

取 **`spatial_radius = 3.0`、`denoise_passes = 2`** 作为新默认，理由与代价写进
`gi/mod.rs` 的默认值注释。
