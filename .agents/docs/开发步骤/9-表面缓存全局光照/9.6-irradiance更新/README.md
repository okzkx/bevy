**一句话**：每个活跃 patch 每帧发少量半球射线，命中点取"直接光（方向光阴影、光源侧点/聚光采样清单、自发光三角形）+ 邻近 cell 的缓存自查询"，投影成与 9.3 同口径的 RGBL1 辐照度并按方差引导做时域混合——多跳由缓存自查询自然形成；本段只把辐照度算进 patch 表、给出调试视图，不接屏幕查表/滤波/注入（归 9.7），`estimation` 关与 GI 关两种状态都不改画面。
