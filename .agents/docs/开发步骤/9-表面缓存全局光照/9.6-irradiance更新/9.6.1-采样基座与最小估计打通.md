# 9.6.1 采样基座与最小估计打通（施工记录）

> 2026-11-24 开工首日。依据[施工计划](施工计划：irradiance更新与多跳.md) §9.6.1 与 §3 闸门 1、闸门 2。
> 本记录写"实际做了什么"与"裁决结果"，计划文档只流转状态。

**一句话**：把 Kronecker 2D + 均匀半球 + SH 折叠落成 `gi_sampling.wgsl`，把 CSM 从合成 shader
整段抽成 `common/shadow.wgsl` 并加低档 5 tap PCF，再接一条最小 estimation compute（只取方向光、
未命中取天空辐亮度）；GI UBO 扩到 288B、BRP 补估计参数与 `gi_estimate_probe`——闸门 1 的
"单 patch 半球射线、零 VUID、`update_count` 开始涨"全部拿到，且 `mean` 与其中一份辐照度
**逐位相等**（ping-pong 与时域记账自洽）。

## 数学链与自检口径（本段钉死的部分）

- 投影把 **Y 基常数**乘进去（`y0 = 0.28209479`、`y1 = 0.48860252`），所以累加器是"求值式"；
  半球均匀采样的 1/pdf 是 `2π`，逐样本权重 = `2π/N`。
- 卷积与基常数合并成两个乘数：`GI_FOLD_L0 = π·y0`、`GI_FOLD_L1 = (2π/3)·y1`，**一次乘法**完成
  "余弦卷积 + 折基常数"，写进 `PatchIrradiance` 的就是消费端可直接 `l0 + l1·n` 求值的形式。
  消费端只再乘 `albedo/π`（`gbuffer_composite.wgsl` 的 `Fd_Lambert`），**不再乘 π**。
- 等价形式（便于手算核对）：`l0 = (π/2)·mean(L)`、`l1 = π·mean(L·ω)`。均匀半球常量 `L` 下
  `l0 + l1·n = πL/2 + πL/2 = πL`，与"常量天空 E = πL"的锚点一致。
- 时域（本段只有第一段数学）：`oldCount == 0` 时**整体替换种子**（权重 0），否则
  `w = oldCount/(oldCount+1)` 的精确累计平均；方差引导滞后与 `short_hysteresis` 留 9.6.4。

## 裁决与偏差（相对计划）

1. **未命中射线的辐射亮度取 `sky_radiance(dir, false) * ibl_intensity`**，不取 9.2 的环境 cubemap
   （计划 §0.2 只写"环境"，未钉源）。理由：天空函数是 IBL 捕获的同一份上游（口径天然一致），
   且省掉把 IBL 集 b0/b1（cube+sampler，当前只声明 `FRAGMENT`）扩到 `COMPUTE` 的一处改动；
   debug 版实测 2 样本档下 `gi_ms` 仍 < 1.3 ms。代价：每次未命中做一次 16 步大气积分，
   Sponza 这类封闭场景几乎不触发，开阔场景的读数留 9.6.5 记录。
2. **`gi_estimate_probe` 从 9.6.6 提前到本任务**：判定线①（多跳色渗）、④（自发光 A/B）都要
   "单点对账"，而 `gi_stats` 只有计数。口径按 9.6.6 的钉子走：复用 `readback` 通道、
   `device_wait_idle` 取一致快照（人工低频调用，不在每帧链上）。回读数里 `parity_hint` 只作提示
   ——UBO 按帧槽写、读的是当前槽，可能比最后一帧早一拍，**对账以"与 `mean` 逐位相等的那份"为准**。
3. **闸门 2 取"扩阶段位"一案**：阴影集 b1..b4 直接扩 `COMPUTE`（一份布局一份集，与 9.5 扩
   G-buffer/IBL 阶段位的先例同侧），不另立 compute 变体；两层屏障同步补 `COMPUTE_SHADER`。
   代价：级联图的 WAR 等待面变宽（compute 也要等），实测无可见停顿。
4. **`bounce_enabled`（`frame.z`）按 `estimation && multi_bounce` 写**，不是直接照抄
   `multi_bounce`：`eviction.wgsl` 的 `frame.z != 0` 分支会"先把 rank 0 降成 1、本轮不淘汰"，
   若估计关着却因为默认 `multi_bounce = true` 打开它，9.5 的淘汰行为就被改了（回退硬线）。
   `multi_bounce`（`estimation.z`）同样按这个合取写。
5. **ping-pong 的读者契约**：写 `b3 if frame&1==0 else b4`，自查询与视图都读另一份；
   奇偶由 GI UBO `frame.x & 1` 给出。本段视图（1～8）不读辐照度，所以 9.5 的三处编号/画法不动；
   9.6.6 加 9～13 视图时按同一奇偶取。
6. **未接预算换算**：本段 `samples` 直接取设置值，`budget` 只落参数（9.6.5 做活跃数→样本档）。
   判定线③的降档稳定性因此还不能测。
