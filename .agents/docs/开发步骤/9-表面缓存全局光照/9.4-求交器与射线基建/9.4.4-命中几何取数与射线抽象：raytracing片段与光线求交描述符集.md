# 9.4.4 命中几何取数与射线抽象：raytracing 片段与 光线求交描述符集

**做什么**：把"射线怎么打、打到什么、命中后怎么取属性"收成一份公共 WGSL 片段 + 一个 光线求交
描述符集；宿主侧用 `RayScene` 做入口，不向上泄漏 `vk::AccelerationStructureKHR` 类型。

## `shaders/common/raytracing.wgsl`（新）

- 只放结构与函数，`enable wgpu_ray_query;` 由入口文件第一行携带（`#import` 是文本展开，
  指令进片段会被多处展开）。
- 契约：片段引用四个全局名，由入口声明——`scene_tlas`（`acceleration_structure`）、
  `objects`（对象表）、`vertices`（顶点池 `array<f32>`）、`indices`（索引池 `array<u32>`）。
- `trace_scene(origin, dir, tmin, tmax, mask) -> SceneHit`：`var q: ray_query` →
  `rayQueryInitialize(&q, scene_tlas, RayDesc(0u, mask, tmin, tmax, origin, dir))` →
  `while (rayQueryProceed(&q)) {}` → `rayQueryGetCommittedIntersection(&q)` → `Terminate`。
  `SceneHit` 带 `hit/t/instance_slot/primitive/bary/front_face/object_to_world`。
- `hit_geometry(slot, primitive, bary)`：对象记录给 `first_index/vertex_base/material_index`
  → 索引池取三角形三索引（加 `vertex_base`）→ 顶点池 8×f32/顶点取位置/法线/UV →
  重心插值（`w = 1 - x - y`）。`hit_world_pos/normal/uv` 再经 `object_to_world` 变世界空间。
- 坑：naga 的 `RayIntersection` 成员名是 `instance_custom_data`（不是 `instance_custom_index`），
  `object_to_world` 是 `mat4x3f`。

## build.rs

- 校验 caps 加 `Capabilities::RAY_QUERY`（naga 默认不含；缺它会校验失败）。
- ABI 反射补 `TypeInner::AccelerationStructure` 分支（handle 空间 → `AccelerationStructure`）。
- `HOST_LAYOUT_GATE` 加 `("TlasInstance", 64)`：WGSL 实例记录 span 与
  `VkAccelerationStructureInstanceKHR` 字节数编译期互证。

## 光线求交描述符集（`render/passes/ray_tracing/mod.rs`）

| binding | 类型 | 内容 |
|---|---|---|
| b0 | `ACCELERATION_STRUCTURE_KHR` | 本帧槽 TLAS |
| b1 | storage buffer | 顶点池（命中重建） |
| b2 | storage buffer | 索引池 |
| b3 | storage image | RGBA16F 调试图 |
| b4 | storage buffer | 统计（u32×2：射线数、命中数） |

- 布局 `RAY_TRACING_SET_DESC` 在 `layout_registry` 登记；两条管线：
  `tlas_build`（set2 单集 + 4B push）、`ray_debug`（set0 实例表 / set1 帧 UBO / set2 光线求交集
  + 16B push）。
- 描述符集按帧槽各一套；TLAS 句柄或网格池 buffer 变化时才重写（`ensure_bindings`），
  写前一个"句柄键"比对，稳态零更新。

## `RayScene`（`render/ray_tracing/mod.rs`）

- `new(ctx) -> Result<Option<Self>>`：能力门不过返回 None，整段不实例化；过了建
  `BlasRegistry` + `TlasFrame` + AS loader + 属性快照。
- 暴露：`ensure_blas/retire_blas/record_blas_builds/drain/blas_address/blas_generation/
  ensure_tlas_capacity/tlas_handle/record_tlas_build/stats/split`。宿主侧不出现 ash 的 AS
  类型（录制层拿到的是句柄与打包字节）。
- `split()`：录制期把 `&mut BlasRegistry` 与 `&TlasFrame` 拆开借，一次录制同时满足
  "待建转正"与"只读 TLAS"。

## 验证

- `ray_debug.spv` 过 `spirv-val --target-env vulkan1.3`，capability 4472（RayQueryKHR）+
  `SPV_KHR_ray_query`（前置闸门 1）。
- 调试图 view=1 的世界法线图逐面颜色正确（Sponza 拱廊/柱子/地面朝向自洽），说明
  `instance_custom_data → 对象记录 → 三索引 → 三顶点 → 重心插值 → object_to_world`
  整条命中重建链通了（读图证据见 9.4.7）。
- `every_shader_entry_has_a_pipeline` 通过；102 项库测试全过。
