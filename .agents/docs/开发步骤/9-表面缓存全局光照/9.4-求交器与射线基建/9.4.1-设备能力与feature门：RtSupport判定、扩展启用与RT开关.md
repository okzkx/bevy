# 9.4.1 设备能力与 feature 门：RtSupport 判定、扩展启用与 RT 开关

**做什么**：建设备前把"硬件 ray query 能不能用"查清楚，能用才启用——三项 feature（BDA /
accelerationStructure / rayQuery）与三个设备扩展（VK_KHR_acceleration_structure /
ray_query / deferred_host_operations）齐备才开；缺任一记一行 info 后 RT 关，不报错、不建
半套资源。RT 关的设备创建参数与 9.3 逐位一致。

## 能力判定是纯函数

- `render/core/device/rt.rs`（新）：`RtCaps`（六个布尔位）+ `RtSupport::resolve(caps)` +
  `enabled()` + `missing()`（缺项日志文案）。不碰设备句柄，"无 RT 设备"分支由单测覆盖
  （`no_rt_device_is_disabled` / `any_missing_bit_disables` 逐位清场 / `full_support_has_no_missing`）。
- 判定放在 `core` 而不是 `render/rt`：`context.rs` 是底层，不能反向依赖 `render/rt`；
  `render/rt/mod.rs` 只把 `RtSupport` 重出口给上层用。

## 设备侧接线（`context.rs`）

- 查询链加三个结构体：`PhysicalDeviceBufferDeviceAddressFeatures`、
  `PhysicalDeviceAccelerationStructureFeaturesKHR`、`PhysicalDeviceRayQueryFeaturesKHR`，
  与既有 vk12/vk13 查询同一次 `get_physical_device_features2`（先查再用的既有纪律）。
- 设备扩展枚举提前到建设备之前（原来在队列配置之后），RT 判定要用它。
- 启用面：RT 开 →
  - `VkPhysicalDeviceVulkan12Features::bufferDeviceAddress(true)`；
  - AS/RQ 两个 feature 结构体进 `DeviceCreateInfo` pNext；
  - 三个扩展名进 `dev_exts`（`deferred_host_operations` 是 AS 扩展的 vk.xml depends 项，
    漏启用 AS 扩展不合法）。
- RT 关 → `bufferDeviceAddress(false)` 也不链 feature 结构体（扩展未启用时链它的 feature
  结构体非法），设备创建参数与 9.3 完全同形。
- 设备建成后查一次 `PhysicalDeviceAccelerationStructurePropertiesKHR`，`Context` 持
  `rt_support()` 与 `rt_properties()`；另加 `buffer_address(buffer)`（BDA 查询的唯一宿主口，
  调用方必须先过能力门）。

## 运行期开关与资源门

- `RtSettings { enabled, view }`（`render/rt/mod.rs`，`Resource`）：**恒插入**（RT 不支持也
  存在，BRP 要能报读数），初始 `enabled = 设备支持`。
- 三个 RT 资源族（`RayScene` / `RtTargets` / `RtPipelines`）只在设备支持时创建并由
  `init.rs` 的 `VulkanBundle.rt` 可选插入；不支持时视图里没有它们，`draw_frame` 的
  `RtInput` 全 None、整段跳过。
- 拆除：三者不在 `InitChain` 表里，`teardown_vulkan` 显式按 pipelines → targets → ray
  反序移除，且早于 `Context`。

## 实测（本机 RTX 2060，2026-11-24）

```
硬件光线求交门: 三项 feature(BDA/AS/rayQuery) + 三个扩展齐备 → 启用
加速结构属性: maxInstanceCount 16777215 maxPrimitiveCount 536870911
              maxGeometryCount 16777215 minScratchOffsetAlignment 128B
```

零 VUID；RT 关（`rt_set enabled=false`）与 RT 开两条运行期路径都零 VUID。

## 坑

- 初始 `enabled` 写"支持即开"（施工计划 §9.4.1 提案）：RT 开关不改画面，只决定基建是否
  活跃；首发成本由 9.4.7 计量（Sponza 下 tlas_ms ≈ 0.12ms、调试图 dispatch ≈ 2.3–2.7ms）。
- 能力查询必须"先查再用"：`vulkaninfo` 只能当预期，不能写死。
