# 9.4.6 调试视图与 BRP：调试图、统计与 PPM 取证

**做什么**：给求交器一条独立 compute 的调试视图（不改画面、不接后链）与四个 BRP 口：
开关/子视图、读数、调试图 PPM 取证、实例字节对照；帧计时加 T9/T10 两位。

## `shaders/scene/rt/ray_debug.wgsl`（新）

- set0 对象表 / set1 帧 UBO（`inv_view_proj` + `camera_pos`）/ set2 RT 集；
  push 16B = `width / height / view / pad`；1D dispatch，`x = px % width`、`y = px / width`。
- 主射线：像素 → uv → NDC（y 翻转与 `gbuffer_composite.world_from_depth` 同式）→
  reverse-Z 近平面点（`ndc.z = 1`；`z = 0` 是无限远点，w=0 反投影出 NaN）→ 方向 = 近点 − 相机。
- 三个子视图：0 = 命中距离（`1 - clamp(t/40)` 灰度）、1 = 世界法线（`n*0.5+0.5`）、
  2 = 实例槽 hash（乘法散列三通道伪色）。未命中写背景色。
- 统计：`atomicAdd` 射线数与命中数（u32×2），宿主每帧清零本帧槽（`wait_for_slot` 之后）。

## `RtTargets`（`render/passes/rt/mod.rs`）

- 按帧槽各一张 RGBA16F storage image（`ColorTarget::new_storage`：格式须支持
  STORAGE_IMAGE + TRANSFER_SRC，查 `vkGetPhysicalDeviceFormatProperties` 后建）+ 统计 buffer
  （`BufferRole::Storage`，8B）+ RT 描述符集。
- resize 级：`rebuild` 尺寸变了先 `device_wait_idle` 再重建图/统计/描述符键（与 G-buffer/
  Bloom 同款），接在 `rebuild_size_dependent` 里。
- 布局：每帧 `UNDEFINED → GENERAL` 进场（整张重写，旧内容不要）。

## BRP 方法族（`remote/features/rt.rs`，新）

| 方法 | 行为 |
|---|---|
| `rt_set` | `{"enabled": bool, "view"?: 0..2}`；回写生效值与 `supported`；`view` 越界回 INVALID_PARAMS |
| `rt_stats` | `enabled/supported/view`、`support` 六个能力位 + `missing`、`blas{count,pending,bytes}`、`tlas{instances,capacity,bytes}`、`debug{rays,hits,hit_rate,last_tlas_ms,last_rays_ms}`；RT 缺席不报错，回 `enabled:false` 形态 |
| `rt_dump` | `{"path": "...ppm", "view"?: 0..2}`：调试图 → PPM（P6，RGBA16F 取 rgb clamp）；`view` 给了必须等于当前 `rt_set.view`；关档回 INVALID_PARAMS |
| `rt_census` | `{"slots"?: N, "instances"?: N}`：读地址表两帧槽非 0 行 + TLAS 实例数组前 N 条（变换 12 float、Packed24_8 拆开、地址） |

- 读数口径：`rt_stats` 统计缓冲读"本槽"（下一帧要重录的槽，其上次提交已由帧首 fence 等完
  = 两帧内新鲜）；实例数取 `RtTargets` 记下的上一帧值。
- `rt_dump` 读回：一次性命令缓冲 + fence（复用 `OneShotReadback`），布局
  `GENERAL ↔ TRANSFER_SRC`；离开时停在 TRANSFER_SRC 无妨——下帧从 UNDEFINED 进场。
- `rt_census` 读实例数组走 `readback_buffer`（一次性拷贝 + fence，设备本地 buffer 也可读）。

## 帧计时（`render/stats/perf.rs`）

- `TimestampPoint` 加 `RtTlas = 9`、`RtRays = 10`；`QUERIES_PER_FRAME` 9 → 11。
- 既有 `fetch` 的 9 段口径不变；新增 `fetch_rt(slot)` 返回 `[tlas_ms, rays_ms]`。
- `FrameSample` 加 `gpu_rt_tlas_ms / gpu_rt_rays_ms`；`perf_stats`/`perf_samples` 一并输出。

## 验证

- `rt_stats`（Sponza 默认机位）：`rays = 1,440,000 = 1600×900`、`hit_rate = 1.0`（相机在
  Sponza 中庭、全画面几何）；`tlas_ms ≈ 0.12ms`、`rays_ms ≈ 2.3–2.7ms`。
- 三个子视图 PPM 落图（`.temp/rt_test_view{0,1,2}.ppm`）；法线图 89,172 种颜色（逐面朝向）。
- 关档：`rt_stats.enabled = false`、`rt_dump` 被拒、LDR 帧与开档逐字节一致。
