# 9.2.5 高光注入（split-sum）

> 施工记录。对应[施工计划：天空盒IBL](施工计划：天空盒IBL.md) §0.4/§0.5 与任务 9.2.5。把预滤波 cubemap + DFG LUT 接进不透明与透明的高光项；太阳高光仍归直接光。

## 做了什么

1. **`ibl_specular`（`shaders/common/ibl.wgsl`）**：
   ```
   R = reflect(-V, n)
   pre = textureSampleLevel(env_cube, samp, R, perceptualRoughness · max_mip)   // max_mip = 8
   ab  = textureSampleLevel(dfg_lut, samp, vec2(NoV, perceptualRoughness), 0)
   specular = pre · (F0 · ab.x + ab.y)
   ```
   - 粗糙度用 **perceptualRoughness**（合成 `matparam.b` / 透明 `surf.perceptual_roughness`）；`PixelParams.roughness` 是 α = p²，直接喂 mip 会把粗糙面算得过锐。
   - mip 选择 = `p × (级数−1)`，硬件三线性在相邻预滤波级之间插值——粗糙度增大时反射连续变糊，没有硬边 mip 跳变。
   - `energyCompensation` **不开**（默认 1.0）：与 LUT 同时引入两个变量会让 A/B 的验收对不上；9.2.7 的裁决项，本段维持关。
2. **不透明**（`gbuffer_composite.wgsl`）：`ibl.diffuse + ibl.specular` 替换旧常量项（`select` 两支）；金属只有高光（`diffuseColor = albedo(1−m)` 为 0），介电体高光由 F0 控制（`computeDielectricF0` 已把 reflectance 0.5 换成 0.04）。
3. **透明**（`transparent_forward.wgsl`）：同一 `ibl_specular`，乘 `ibl_intensity`。
4. **AO 暂不乘 IBL**：与旧环境项同口径；室内漏光/缝隙过亮作为已知局限（9.2.7 记录），AO 接入留给 9.7/9.8。
5. **pre-exposure**：IBL 在 pre-exposure 域，合成/透明末尾统一乘 `EXPOSURE`；IBL 内部不乘。

## 验证

- **高光可见**：DamagedHelmet 头盔面罩反射天空的蓝色渐变；Emerald day 公交车车窗（透明）出现天空蓝反射，`ibl_specular` 视图里车窗/树叶/金属边缘全亮——与"环境高光只来自天空 cubemap"的预期一致。
- **太阳圆盘不进捕获**：`ibl_census(mip:0)` 的六面最大值 **6596**（太阳附近米氏前向峰的宽亮区），远小于太阳圆盘本体的 `light_color × sun_gain × sky_intensity = 20000×1.5×2 = 60000`——圆盘没进捕获；金属上不会出现第二个圆盘/月牙，太阳本体高光始终由直接光即时给出。
- **粗糙度响应**：粗糙路面（p≈0.5-0.9）在 `ibl_specular` 视图里是低对比的暗区、只有法线贴图带来的细碎高光；光滑车窗/面罩是清晰天空反射。预滤波 mip 链与 DFG LUT 联合工作正常。
- **能量合理**：常量天空 L=300 下，`ibl_diffuse + ibl_specular` 的 HDR 最大值 **2.21**（×EXPOSURE 后），落在 Bloom 阈值 1.0 附近——没有爆点也没有死黑。

## 坑

1. **A 钳 1 之后掠射角仍然亮**：正常物理行为（Fresnel → 1）；树叶/草地在 `ibl_specular` 视图里接近白色是"白花树 + 天空反射"的叠加，不是 NaN。
2. **`ibl_specular` 里 `pre · (F0·A + B)` 的 A/B 都在 [0,1]**（LUT 已钳），与 F0 ≤ 1 相乘不会溢出 fp16。
3. **透明层也接 IBL**是有意为之（环境基线不是 GI），9.7 的 SCGI 开关不会影响透明。
