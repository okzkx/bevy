# 9.2.3 漫反射注入与 IBL 描述符集

> 施工记录。对应[施工计划：天空盒IBL](施工计划：天空盒IBL.md) §0.5/§0.7 与任务 9.2.3。把 SH-L2 辐照度接进不透明合成；IBL 描述符集（group 4）随本任务建集与绑管线，不留到 9.2.6。

## 做了什么

1. **IBL 集（group 4）**（`IBL_SET_DESC`）：b0 预滤波 cube（全 mip，采样）、b1 采样器（cube 与 LUT 共用）、b2 DFG LUT、b3 SH 系数（storage buffer，片元读）。b4 留空给 9.3（GlobalProbe 或复用 b3 + mode）。**不进 bindless set0**：cubemap 加不进 `binding_array<texture_2d>`。
2. **管线布局 4 → 5 组**：`composite_pipeline.rs` 与 `transparent_pipeline.rs` 的配方各加 `&IBL_SET_DESC`；`driver/host/init.rs` 登记 `ibl.set_layout()`；初始化时读 `maxBoundDescriptorSets`（本机 32，< 5 直接拒绝建资源）。
3. **合成着色器**（`gbuffer_composite.wgsl`）：
   ```wgsl
   terms.diffuse = pixel.diffuseColor * Fd_Lambert() * sh_irradiance(n, sh_coeffs) * ibl_intensity;
   let environment = select(albedo.rgb * frame.ambient_color.rgb,
                            ibl.diffuse + ibl.specular,
                            frame.ibl_enabled != 0u);
   ```
   - `Fd_Lambert()` 复用 `brdf.wgsl`，与直接光同口径；`diffuseColor = albedo·(1−metallic)`（金属没有 IBL 漫反射）。
   - **IBL 关的硬线**：`select` 的另一支原样是 `albedo * frame.ambient_color.rgb`，不做等价变形。
   - 漫反射用 `E(n)`（已含余弦卷积），不再乘 `1/π` 之外的任何东西；`ibl_intensity` 只乘在这一项（高光同）。
4. **透明层**（`transparent_forward.wgsl`）：同一分式接 IBL（环境基线不是 GI，透明也接）；粗糙度用 `surf.perceptual_roughness`（**不是** `pixel.roughness`——后者是 α = p²）。
5. **`ibl_enabled=false` 时零成本**：② 段不录、合成/透明走 `ambient` 支路；背景天空与 `ibl_enabled` 正交（`sky_enabled` 管）。

## 验证

- **隔离性**：Emerald day，天空区域（背景）在 IBL 开/关两帧 **逐像素相同（max diff = 0）**；几何区域平均差 11.5/255（约 68% 像素 >2）——IBL 只动几何像素。
- **IBL 关 = 基线**：见 9.2.7 判定线 1/2（与 9.2 开工前 HEAD 的 release 二进制逐像素一致）。
- **常量天空视觉同形**：L=300、IBL 开、`ibl_diffuse` 视图 = `albedo × 300` 的平滑图；`environment` 与旧 `albedo·ambient` 同构（只差 `E=πL` 与 ambient 的换算）。

## 坑

1. **NaN 法线**：G-buffer 法线在退化面片处是 `normalize(0) = NaN`（float16 存 NaN），IBL 的 `sh_irradiance(n)`/`reflection` 会把 NaN 带进 HDR；Bloom 的 soft-knee 里 `Inf/Inf` 再把它扩成**大块黑斑**（实测 53 个像素拖黑约 1/4 屏）。修在源头：`brdf.wgsl` 加 `safe_normalize(v, fallback)`，G-buffer 写入口与透明前向的 `normalize` 全部换成它（G-buffer 退化法线是既有缺陷，不在 9.2 边界内，但它是本段 NaN 的直接来源，就地修掉并在此登记）。
2. **`matparam.b` 是 perceptualRoughness**：8bit 量化值直接喂 LUT/mip；用 `pixel.roughness`（α）会把粗糙面算得过锐。
3. **组号**：IBL 在两条图形管线里都是 **group 4**（0..3 已占），compute 侧的小布局是另一套组号，写错即 VUID。
