# 9.2.4 高光预滤波与 DFG LUT

> 施工记录。对应[施工计划：天空盒IBL](施工计划：天空盒IBL.md) §0.4/§0.7 与任务 9.2.4。split-sum 的两半：GGX 预滤波 cubemap（mip1..8）与 DFG/BRDF LUT（一次性 128²）。本记录含两个实测缺陷的定位与修法。

## 做了什么

1. **`prefilter.wgsl`**（逐 mip 派发）：对 mip k（1..8）的每个 texel，以它的方向为 N 做 GGX 重要性采样（`importance_sample_ggx`，α = p²），把 mip0 的辐亮度按 NoL 加权平均写进目标级；采样数逐级下降 **128/96/64/48/32/24/16/8**（锐利级需要更多样本压噪，粗糙级 lobe 接近半球）。`mip 0` 不派发——它是锐利源，`perceptualRoughness=0` 的镜面反射直接采它。
   - push（8B）：`perceptual_roughness = mip / 8` 与 `sample_count`；
   - 每级一个 2D-array storage 视图（6 层），dispatch `(size/8, size/8, 6)`；
   - 源只读 mip0，级间不同子资源，**级间无屏障**；链尾一条全子资源迁移收口。
2. **`brdf_lut.wgsl`**（一次性 128²）：Karis 的重要性采样积分，V 固定在切空间 `(√(1−NoV²),0,NoV)`、N=+z；x 轴 = NoV、y 轴 = perceptualRoughness；输出 RGBA16F（xy = A/B）。与 cubemap 同格式，**一张格式能力查询覆盖两者**。
3. **触发**：DFG LUT 只在首次捕获帧生成（`plan.dfg`），之后只读；`ibl_census(lut:true)` 可读回验内容。
4. **storage 视图**：DFG LUT 一个 `TYPE_2D` 视图既作 storage 目标又作采样源（同一句柄，两种描述符种类）。

## 实测缺陷与修法

### 缺陷 A：DFG 在 NoV→0 发散出 Inf → Bloom 大块黑斑

- **现象**：IBL 打开后 Bloom 出现硬矩形黑块（screen-aligned、跨 1/4 屏），关 Bloom 即消失；`ibl_specular` 视图只暗不亮。
- **定位**：临时读回 HDR 目标（RGBA16F）发现 53 个像素是 **fp16 NaN（0x7FFF）**，位置是 1px 宽的轮廓线；这些像素的 G-buffer 法线也是 NaN（见缺陷 B）。另有一条独立线索：DFG 积分在 `NoV→0 且粗糙度→0` 时 `G_Vis = G·VoH/(NoH·NoV)` 按 `1/NoV³` 发散（1e-6 护栏挡不住），积分值可达 1e6 → RGBA16F 存成 **Inf**；Bloom prefilter 的 `contrib/max(luma,1e-4)` 对 Inf 得 `Inf/Inf = NaN`，逐级扩散成块。
- **修**：`brdf_lut.wgsl` 把 A/B **钳到 1.0**（物理上 A+B 是反射率 ≤ 1，超 1 全是数值产物）。顺带压掉掠射角"塑料感爆点"（叶片/路面的高频法线在 A 大的区域闪白）。
- **复验**：`ibl_census(lut:true)` → `min 0 / max 1.0 / non_finite 0`；HDR 非有限像素 0；Bloom 黑块消失。
- **9.2.8 订正**：Inf 的根因不是"没钳"，而是积分器把 `V_SmithGGXCorrelated`（可见性形态，已含 `1/(4·NoL·NoV)`）当成几何项 G 再除 `NoH·NoV`，多除 `4·NoL·NoV` → 掠射端 `1/NoV³` 发散。钳 1 只是止血，留下掠射端一段 A=B=1 的平台 + 陡崖，后来变成帘布/石墙上的高光火花。真修法与验收见 [9.2.8](9.2.8-高光火花、天空地平线噪点与天光开关联动.md) §2 A。

### 缺陷 B：G-buffer 退化法线 NaN → 经 IBL 扩散

- **定位**：HDR 的 53 个 NaN 像素坐标读回 G-buffer 法线，值为 fp16 NaN——`normalize(0)`（退化面片/零法线）写出 NaN；IBL 关时这些像素恰好 `dir_NoL` 为 NaN → 直接光分支跳过，NaN 不外泄（所以基线零 NaN），IBL 的反射/辐照度一用 n 就把它带进 HDR。
- **修**：`brdf.wgsl` 加 `safe_normalize(v, fallback)`（长度² 非有限或 ≤1e-20 就用 fallback），G-buffer 写入口（含 TBN 与法线贴图合成）与透明前向的归一化全部换用。
- **复验**：HDR 非有限像素 **0**；IBL 关与 9.2 开工前 HEAD 逐像素一致（Sponza / Emerald 两场景 md5 相同）。

## 坑

1. **`ComputeHandles::dispatch` 只发一维**：DFG LUT 128×128 用一维 16 组派发只写了第一行带（其余保持未定义），必须 `cmd_dispatch(16, 16, 1)`。首次读回发现 LUT "全零"就是这个坑 + 读回缺 `TRANSFER_SRC` 叠加的假象。
2. **读回要 `TRANSFER_SRC`**：DFG LUT 图最初只有 `STORAGE|SAMPLED`，`ibl_census` 的图像拷贝直接吃 VUID；加 usage 后正常（验证层抓到了，没白跑）。
3. **采样数不必上 2048**：mip1（128²）128 样本已无明显噪点；粗糙级 8 样本在 1×1/2×2 级足够。
4. **预滤波源视图只含 mip0**（`level_count=1`）：算错层级（用全链视图）会让 mip1 采样到未写的更高级。
