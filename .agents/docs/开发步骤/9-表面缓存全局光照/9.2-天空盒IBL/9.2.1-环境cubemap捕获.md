# 9.2.1 环境 cubemap 捕获

> 施工记录。对应[施工计划：天空盒IBL](施工计划：天空盒IBL.md) §0.6/§0.7 与任务 9.2.1。本任务落三件事：环境 cubemap 资源族、从 9.1 物理天空烘 mip0、以及"什么时候烘"（脏标记 + 节流 + 门控）。

## 做了什么

1. **`IblEnvironment` 资源族**（`src/render/passes/ibl/environment.rs`，进程级、不随 swapchain 重建）：
   - 环境 cubemap：`CUBE_COMPATIBLE`、256²×6 层、`R16G16B16A16_SFLOAT`、9 级 mip、usage `STORAGE|SAMPLED|TRANSFER_SRC`；
   - 三类视图：`TYPE_CUBE` 全链（片元采样）、`TYPE_CUBE` 仅 mip0（捕获链内部的源）、每级一张 `TYPE_2D_ARRAY`（storage 写入，WGSL storage texture 不带 mip 参数）；
   - 一个线性三线性 + CLAMP_TO_EDGE 采样器（cube 与 DFG LUT 共用）；
   - 格式能力查询照 hi-z 同款：`STORAGE_IMAGE | SAMPLED_IMAGE | SAMPLED_IMAGE_FILTER_LINEAR` 缺一即初始化报错（不静默降级）；另加 `maxBoundDescriptorSets < 5` 的显式拒绝（本机实测 32）。
   - **一张图两个角色**：mip0 = 天空锐利源，mip1..8 = 预滤波结果（写不同子资源，见 9.2.4）。
2. **`shaders/scene/ibl/sky_capture.wgsl`**：`texture_storage_2d_array<rgba16float, write>` 写 mip0 六面，`sky_radiance(dir, include_sun=false)`——只排太阳圆盘，米氏前向峰的宽亮区留在捕获里（HDRP cubemap 烘焙同口径）。面内像素中心 → 方向用 `cube_face_direction`（`shaders/common/ibl.wgsl`，Vulkan 面序与 UV 约定）。dispatch = `(32, 32, 6)`，z = 面号。
3. **脏标记 + 节流 + 门控**（`IblEnvironment::prepare`，draw_frame 每帧调用一次）：
   - `sky_hash` = FNV-1a 滚全部 `SkySettings` 数值字段 + 常量天空开关/颜色 + 方向光方向/颜色 + **按 100 m 量化的相机海拔**（物理天空以 `camera_pos.y` 当海拔；地面漫游的米级差永不触发重烘，飞行按需）；
   - 触发 = `ibl_enabled` 且（hash 变化 或 DFG LUT 未生成）且（距上次捕获 ≥ 0.1 s）；
   - `ibl_enabled=false`：整段不录、不 dispatch（零成本），捕获计数不增；账本（`captured_hash`/`last_capture`/`count`）留在资源里供 `ibl_stats` 回显。
4. **② 段录制位置**：`record_frame_steps` 的 ② 段最前（早于剔除/遮挡/LOD/shadow），脏帧才录。捕获在同一命令缓冲里先于 ⑤ 段合成，所以"开开关的同帧就能用"，不存在滞后一帧。
5. **屏障**（`core/record/barrier.rs` 扩子资源范围 + `ImageBarrier::transition`）：
   - 首次使用（一辈子一次）：cubemap 与 DFG LUT 全子资源 `UNDEFINED → SHADER_READ_ONLY`（描述符声明的是采样布局，不从 UNDEFINED 迁过去第一条 draw 就报布局不匹配）+ SH/stats 缓冲 `cmd_fill_buffer` 清零 + transfer→shader 内存屏障；
   - 捕获帧：全子资源 `SHADER_READ_ONLY → GENERAL`（src = 上一帧的采样读，WAR）→ 捕获 → **mip0 单级 RAW**（`GENERAL→GENERAL`，src SHADER_WRITE → dst SHADER_READ）→ 链尾全子资源 `GENERAL → SHADER_READ_ONLY`；
   - 另加一条**缓冲的跨帧 WAR** 内存屏障（片元/compute 读 → compute 写）：缓冲没有布局迁移可搭车，缺它会让下一帧的 SH 写入撞上一帧还在飞的合成读。
6. **`GPU 计时` 扩一位**：`TimestampPoint::IblCapture`（T0→T1 = 捕获链耗时），`FrameSample.gpu_ibl_capture_ms`，`perf_stats` 同步。

## 量测

- 捕获链（捕获 + SH 投影/归约/自检 + 预滤波 8 级）在 RTX 2060、256²×6、16 步大气积分下 **0.78～0.89 ms**（`ibl_stats.capture.last_capture_gpu_ms`，两次捕获实测：0.888 / 0.777 / 0.859）。
- 静止帧捕获计数不增；改 `mie` 一次计数 +1；`ibl_enabled=false` 后不再增（见 9.2.7 判定线 10）。
- cubemap 逐面读回（`ibl_census`）：9 级 × 6 面全部有限，mip0 各面 min/max 例如 +Y（天空）111.9/1641、−Y（地面）786.5/1259——地面面比天空面亮，与"HDRP 式单次散射天空 + 反照率 0.25 的地面"一致。

## 坑

1. **cubemap 不能走 bindless 2D 表**：`BindlessTextureTable` 只收 2D 视图、`ImageSpec` 只收 2D RGBA8，本段新建内部资源是唯一路。
2. **面方向约定**：Vulkan 的 cube 面序（+X −X +Y −Y +Z −Z）与面内 UV 方向写反 = 六面接缝 + 反射方向错位。`cube_face_direction` 与硬件 `textureSampleLevel(texture_cube)` 同约定；验收靠"±Y 反射天空/地面色相反"这条最直观的现象（见 9.2.7 判定线 9）。
3. **`ComputeHandles::dispatch` 只发一维**：六面必须 `(32,32,6)` 三维直调；DFG LUT 也踩过同一个坑（一维派发只写第一行带），见 9.2.4。
4. **海拔兜底**：地下/室内负高度按 0 兜底是 9.1 的既有口径，本段沿用；飞行场景的 IBL 会滞后一个 100 m 量化台阶，记录在案。
