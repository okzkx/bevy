# 9.2.6 调试视图、BRP 与计量收口

> 施工记录。对应[施工计划：天空盒IBL](施工计划：天空盒IBL.md) §0.8 与任务 9.2.6。本任务只做"看得见、读得到"：两档调试视图、四个 BRP 方法、GPU 捕获计时。

## 做了什么

1. **调试视图**（`RenderMode` 9/10 = `ibl_diffuse` / `ibl_specular`）：合成 pass 在光照累积后直出 `ibl.diffuse * EXPOSURE` / `ibl.specular * EXPOSURE`；背景按既有约定回清屏色（调试模式不画天空）；`present_tonemap` 的 `mode != 0` 旁路自动跳过 bloom/tonemap。
2. **BRP 方法族**（`src/remote/features/ibl.rs`）：
   | 方法 | 形状 | 说明 |
   |---|---|---|
   | `ibl_set` | `{"enabled": bool, "intensity": f32?}`，缺省字段不动 | 写 [`IblSettings`]，回显当前值 |
   | `ibl_stats` | 只读 | 设置、9 个 SH 系数、自检误差（l=0 / 14 法线最大）、捕获计数/最近 hash/最近捕获 GPU ms/窗口最大、合成段 p50 |
   | `ibl_census` | `{"mip": 0..8}` / `{"lut": true}` | 读回 cubemap 某一级的六面（min/max/mean/非有限计数/中心像素）或 DFG LUT（min/max/非有限） |
   - 读数走一次性拷贝 + fence（`readback_buffer` / `OneShotReadback`），与 `hiz_census` 同口径：低频、阻塞、只进验证。
   - `ibl_stats` 的捕获耗时取"窗口内 >0.1ms 的最近一个样本"——普通帧的 IBL 时间戳区间只有 µs 级噪声，直接找非零会读到噪声。
3. **GPU 计时**（`render/stats/perf.rs`）：`QUERIES_PER_FRAME` 8 → 9，新增 `TimestampPoint::IblCapture`（② 段烘焙后），`FrameSample.gpu_ibl_capture_ms`，`perf_stats`/`perf_samples` 同步；`FrameStopwatch` 的 GPU 段数组 8 → 9。
4. **`IblSettings` 资源**（默认 `enabled=false` / `intensity=1.0` / `mode=0`）由 `AshHostPlugin` 插入，BRP 与帧 UBO 同源。

## 量测

- 捕获链 GPU 耗时：**0.78 / 0.86 / 0.89 ms**（RTX 2060、256²×6、16 步大气积分 × 六面 + SH 1024 + 预滤波 8 级）；`gpu_lighting_ms` p50 在 Sponza 0.64～0.67 ms（与 9.1 同量级，IBL 只加采样不加分支膨胀）。
- `ibl_census` mip0：六面 min/max 144.3/2334（+X）、167.6/4712（−X）、111.9/1641（+Y）、786.5/1259（−Y）、227.1/6596（+Z）、149.4/2438（−Z），非有限 0；mip1..8 同样全有限。
- `ibl_census(lut:true)`：min 0 / max 1.0 / 非有限 0。

## 坑

1. **`ibl_stats` 的读数允许滞后**：SH/stats 缓冲由捕获帧 compute 写，读回是一次性提交 + fence，取到的是"某个完整状态"——不是当前帧的值。BRP 不是正确性路径。
2. **`ibl_census` 的图像拷贝需要 `TRANSFER_SRC`**：DFG LUT 最初没有，读回直接吃 VUID（已把 usage 补进角色，见 9.2.4 坑 2）。
3. **egui 面板本段不接**：BRP 已够跑判定线；9.1 的天空面板不动，IBL 页可后置到 9.3 之后。
4. **`RenderMode::ALL` 长度与名称表**：`[Self; 11]` 与 `label`/`from_name`/`as_u32`/`NAME_HINT` 必须同改，单元测试 `label_round_trips` 覆盖新档。
