# 9.2.0 常量天空开关与帧 UBO 扩列

> 施工记录。对应[施工计划：天空盒IBL](施工计划：天空盒IBL.md) §0.9 与任务 9.2.0。本任务是后面所有验收的锚点：常量天空给出 `E(n) = πL` 的解析真值，IBL 三个字段是整段的门控与旋钮。

## 做了什么

1. **帧 UBO 304 → 336B**（`src/render/resident/tables/frame_uniform_table.rs`）：
   - `ibl_enabled`(304, u32) / `ibl_mode`(308, u32) / `ibl_intensity`(312, f32) / 对齐垫 316；
   - `sky_uniform`(320, vec4：xyz = 辐亮度，w = 1 开 / 0 关)；
   - 五处同改：`FRAME_UBO_SIZE`、`FrameUniformTableLayout` 的 `offset_of!` 断言（新增 304/308/312/320 与 size 336）、`pack_frame_uniforms`、`identity_frame_uniforms`、`FrameUniformsData` 字段；
   - `shaders/common/frame.wgsl` 结构体与头注偏移表同步。
2. **`sky_radiance` 常量分支**（`shaders/common/sky.wgsl` 开头一句）：`if (frame.sky_uniform.w > 0.5) { return frame.sky_uniform.rgb; }`。**故意放在 `* sky_intensity` 之前**——自检锚点必须精确等于 L，倍率旋钮不该污染它。
3. **`SkySettings` 加 `uniform_enabled` / `uniform_radiance`**（默认关、颜色全 0），`driver/host/frame/scene.rs` 的 `write_frame_ubo` 映射到 `sky_uniform`（w = 开关）。
4. **BRP `sky_uniform`**（`src/remote/features/sky.rs`，单独方法）：`{"enabled": bool, "color": [r,g,b]?}`。独立方法的理由：它带"关 = 回物理天空"的清空语义，与 `sky_set` 的"缺省字段不动"是两种更新形状。
5. **`RenderMode` 扩到 11 项**：`ibl_diffuse` / `ibl_specular`（`FRAME_MODE_IBL_DIFFUSE = 9` / `..._SPECULAR = 10`），`label`/`from_name`/`as_u32`/`NAME_HINT` 四处与单元测试往返同步（着色器分支在 9.2.3/9.2.5 落地，本任务只落宿主侧名称表）。

## 验证

- 常量天空 L=300：`ibl_stats` 的 `C00` = **3341.0083**，解析值 `4π²·Y00·300 = 3341.0` ✓；l=0 相对误差 3.3e-6。
- 9 个系数只有 l=0 非零：其余 8 行最大 |C| ≈ 3.8（相对 3341 约 0.1%，是 RGBA16F 采样量化），见 9.2.2 施工记录。
- `sky_enabled` 与 `ibl_enabled` 正交：常量天空开着、IBL 关时背景是常量色、几何仍是 `albedo·ambient`（画面可见，无回归）。

## 坑

1. **常量天空不受 `sky_intensity` 影响**是有意为之：若乘倍率，`E=πL` 的锚点要先除回去，验收就不"解析"了。
2. `sky_uniform` 只作测试：打开时**可见天空也是常量色**，不能当"环境光倍率"用——倍率归 `ibl_intensity` / `sky_intensity`。
