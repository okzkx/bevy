# 9.9.4 颜色页

**状态：✅ 已完成并截图验收（2026-11-26）。** 工具窗口「渲染 → 颜色校验」页可用：三域直方图、CbCr 热力图、曝光/曲线/强度控件都在，默认窗口尺寸下滚到底无裁剪。

## 页面结构

`ash_renderer/src/overlay/tool_window/color.rs`（506 行，`ColorPage` + `ColorPageState`），按纵向顺序：

1. **采样行**：「颜色校验采样」复选框、`单帧采样` 按钮；状态后缀三态（开启 / 单帧排队 / 关闭）；提示"8 Hz 回读；关掉零 dispatch、零回读"。
2. **链未启用提示**：`mode != 0` 或 tone mapping 关闭时显示"链未启用（当前非 Lambert 或 tone mapping 关闭）：present 直出 HDR，C 域无数据"。
3. **曝光区**：自动/手动 radio、目标中灰 `key`（对数滑杆 0.002…0.05）、倍数下限/上限、提亮/压暗速率。
4. **曲线区**：tone mapping 复选框、Narkowicz / Filament ACES radio、ACES 增益（0.5…=16，对数）、校色强度（0…=1）。
5. **快照头**：轴说明（`A/B −16…+8 EV（0.09375 EV/bin）· C 0…1 sRGB（1/256 per bin）`）、分辨率与 bins 帧号、`frame_age`、曝光快照。
6. **A/B 域块**：luma 一张 + RGB parade 一张 + 计数行（样本 / 低于轴 / 高于轴 / 零 / 触顶）+ `bin 均值`；B 域再多一行与 `avg_log2 + log2(scale)` 的差（≤0.15 绿、否则黄）。
7. **C 域块**：luma + RGB parade（0…1 轴）+ 计数行。
8. **CbCr 热力图**：64×64，色块 = 该 CbCr 的可显示色，亮度按 `log(1+样本数)`。

数据来源统一是 `ColorScopeReader` 的快照；页面不自己回读，只在 `enabled` 时调 `reader.refresh(..., force=false)`，节流在 reader 里。CbCr 纹理按快照帧号缓存（`ColorPageState.cbcr`），帧号变了才重建。

## 绘图

`plot(ui, series, ticks, max)`：`allocate_exact_size` 固定高度 84 px，4 等分网格，竖条用 sqrt 压缩（否则长尾全被压平），底部留 14 px 刻度带，无样本时画"无样本"。刻度标签按 `layout_no_wrap` 实测半宽做 `clamp`，否则两端的 −16 / +8 会被裁掉一半——这是截图时抓到的问题。

RGB parade 三通道用同一横轴叠画（R 红、G 绿、B 蓝），luma 单独一张白/灰，这样"亮度分布"和"三通道是否偏色"能分开看。

## egui 0.36 的布局坑

- `ScrollArea` 给内容区的 `content_max_size` 取 `inner_size`（"优先压缩不滚动"），靠底部的 `egui::Image` 会被压扁。修法：`ColorPage::show` 开头 `ui.set_max_height(f32::INFINITY)`，并按 `allocate_exact_size(168×168)` + `painter().image(texture.id(), rect, uv, WHITE)` 自己画，不依赖 `Image` 的自适应。
- `egui::Image::new(texture.id())` 不编译（`SizedTexture: From<TextureId>` 没实现），必须写成 `(texture.id(), vec2(w, h))` 形式。
- 页面已经被外层 `ScrollArea` 包住，内容里不要再套一层滚动。
