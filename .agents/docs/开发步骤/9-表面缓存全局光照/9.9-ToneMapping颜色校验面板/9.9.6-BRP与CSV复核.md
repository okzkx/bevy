# 9.9.6 BRP 与 CSV 复核

**状态：✅ 已完成并实测（2026-11-26）。** `color_scope_set` / `color_scope_get` 可用，字段与面板同源；`tools/color_scope_check.py` 对 BRP JSON 逐字段复核通过。

## 两个方法

`ash_renderer/src/remote/features/color_scope.rs`（191 行）：

- `ash_renderer/color_scope_set`，参数 `{enabled?: bool, once?: bool}`，**至少一项**，写 `ColorScopeSettings`，返回 `{enabled, once}`。`once` 与面板「单帧采样」按钮同义：只录一帧、录完自动复位，不动总开关。
- `ash_renderer/color_scope_get`，参数 `{slot?: u32, force?: bool, cbcr?: bool}`：
  - `force: true` 先置 `once = true`（下一帧重采），再按队列序读该槽最近一次完整帧；
  - `slot` 缺省取 `targets.last_slot()`；
  - 返回 magic/宽高/stride/bins 长度与期望值、`frame_index`、`frame_age`（= 当前帧号 − 快照帧号）、`stale`（age > 4）、`enabled`/`once`/`requested`/`slot`、曝光快照、三域（luma 256、RGB 各 256、counts、ratios、`mean_axis`）、可选 CbCr 4096；
  - `B` 域另给 `mean_axis`，面板与脚本都用 `avg_log2 + log2(scale)` 作为期望值（口径见 9.9.3）。

注册：`ash_renderer/src/remote/features/mod.rs` 加模块、`ash_renderer/src/remote/mod.rs` 加 import 与两条 `.with_method_main(...)`（紧跟 `exposure_get`），文档表同步加行。

## 复核脚本

`tools/color_scope_check.py`（255 行，只用标准库），用法：

```
python tools/color_scope_check.py [--once] [--csv 路径] [--cbcr-csv 路径] [--json 路径] [--strict] [--wait 秒] [--host/--port]
```

- `--once`：先 `color_scope_get {"force": true}` 强制重采，再轮询到 `magic_ok && frame_age <= 2`（早期写 `frame_age == 0`，在 8 Hz 节流下永不成立，已改）；
- 校验：magic/stride/bins 长度；三域 `luma 和 + below + above + zero == samples`；`samples == ceil(w/4) * ceil(h/4)`；B 均值 vs `avg_log2 + log2(scale)` ≤0.15 EV；`below > 5%` 告警；C 域 `clip` 只报告不判失败；
- 输出：控制台表格 + 可选 `--csv`（每域一行）与 `--cbcr-csv`（64×64 长表）；退出码 0 过 / 1 失败 / 2 连不上。

## 实测

```
python tools/color_scope_check.py --once
```

通过：帧 248、1600×900、stride 4、bins 7199、三域 samples 90000、账平、A −6.258 EV、B −6.643 EV（期望 −6.643）、C +0.222、C 零 0.49%、clip 0%。

## 踩过的坑

- 脚本里 `sys.path.insert(0, 'tools')` + `from brp import rpc` 会生成 `tools/__pycache__`，而 workspace 的 `tools/*` glob 会把它当成员 crate，构建报 `failed to load manifest for workspace member .../tools/__pycache__`。每次跑完删掉，别把它提交进去。
- BRP 的 `res::<T>()` 返回 `&T`，所以 `read_bins(ctx, slot)` 直接传 `ctx`，写 `&ctx` 会被 clippy 判 `needless_borrow`。
- `example`/`Value` 参数解析统一走 `crate::remote::common::params::{parse_params, invalid_params, internal_err}`，错误信息用中文、带字段名。
