## 快速使用

- 面板：工具窗口 → 渲染 → 颜色校验；勾「颜色校验采样」或点「单帧采样」。展开且开启时才以 8 Hz 回读，`单帧采样` 只录一帧、不动总开关。
- BRP：`ash_renderer/color_scope_set {"enabled":true}` / `{"once":true}`；`ash_renderer/color_scope_get {"force":true}` 强制重采；返回 `frame_age`/`stale`/三域 luma+RGB+counts+mean_axis。
- 复核：`python tools/color_scope_check.py --once`（默认 `127.0.0.1:15702`，退出码 0 过 / 1 失败 / 2 连不上）。
- 脚本用完删 `tools/__pycache__`，否则 workspace 的 `tools/*` glob 会把缓存目录当成 crate。

## 已知局限 / 未做项

- 天空在 8-bit LDR 下可见渐变环带/竖条（量化伪影，不是钳位）；要根治需抖色或更高位深，未列入本段。
- AWB（自动白平衡）与软肩压缩仍属后续段；测光未做太阳盘排除（默认参数已能让天空不钳位，故本段不启用排除规则）。
- `tools/color_scope_check.py` 提交时 Git 提示会被 CRLF 化（仓库 `* text=auto` + `core.autocrlf=true`），属仓库既有行为，脚本本身按 LF 读无影响。
