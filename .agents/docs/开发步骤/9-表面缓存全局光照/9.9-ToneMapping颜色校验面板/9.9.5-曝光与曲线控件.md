# 9.9.5 曝光与曲线控件

**状态：✅ 已完成（2026-11-26）。** 颜色页补齐曝光/曲线控件；管线页的 ACES 增益滑杆不再卡在 2.5，能覆盖默认 8.0。

## 做了什么

颜色页（9.9.4 的第 3、4 区）：

- **曝光**：`ExposureMode` 自动/手动 radio；`key` 用对数滑杆（0.002…0.05），并显示当前值；`min_scale`（0.05…1.0）、`max_scale`（1.0…16.0）、`rate_brighten` / `rate_darken`（0.1…10.0）。自动模式下禁用这些滑杆没有意义——适配器会覆盖它们，所以仍可调，只把 `key` 标成"目标中灰"。
- **曲线**：`bloom.tonemap` 复选框、`curve` 两选一（Narkowicz / Filament ACES）、`gain` 对数滑杆 0.5…=16.0。

修 `ash_renderer/src/overlay/tool_window/pipeline.rs:47`：ACES 增益滑杆范围原为 `0.5..=2.5`，而 `BloomSettings::default().gain` 是 8.0——滑杆够不到默认值，拖动一下就把画面从 8 拉到 2.5，等于"面板一碰就变画面"。改成 `0.5..=16.0`（对数），与颜色页一致。

## 为什么曝光控件放颜色页而不是管线页

曝光直接影响 B 域（校色输入）和 C 域（输出），调它的时候眼睛盯的就是这三张直方图。把它和直方图放同一页，调参闭环不用来回切页。管线页保留 Bloom / SMAA / 阴影这些线性域设置的入口。

## B 域差的显示

B 域块多一行：`B 域均值 … · 期望（avg_log2+log2 scale）… · 差 …`。这个不是装饰：它把"测光值"和"实际乘进画面的值"的差直接摆在眼前，|差| ≤ 0.15 EV 显示绿色，否则黄色告警。口径推导见 [9.9.3](9.9.3-回读与节流.md)。

## 验证

- 截图确认：`自动/手动`、`目标中灰 0.0100`、`倍数下限 0.25`、`上限 4.00`、`提亮 0.70`、`压暗 3.00`、`tone mapping` 复选框、`Narkowicz / Filament ACES`、`ACES 增益 8.00`、`校色强度 1.000` 都可见且可交互（9.9.9 之后默认值变为 key 0.01305、min 0.05、gain 6.13）。
- 增益滑杆覆盖默认值：滑杆显示 8.00 与默认一致，拖动上限到 16.00、下限 0.50。
- `cargo clippy -p ash_renderer --all-targets -- -D warnings` 0 警告；`cargo test -p ash_renderer --lib` 全过。
