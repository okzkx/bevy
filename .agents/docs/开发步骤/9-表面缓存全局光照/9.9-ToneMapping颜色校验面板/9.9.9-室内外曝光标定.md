# 9.9.9 室内外曝光标定

**状态：✅ 已完成（2026-11-26）。** 同一套默认值在室内中庭、纯天空 45°/70°、日照地面、日落 5°/15° 六组场景下都成立：室内画面不变（scale 1.001、C p50 差 0.00%），天空不再整体发白（clip 0%、天顶 B>R），低太阳保留红移（地平线 R/B 1.878 / 1.522）。

## 先取基线再说

按计划要求，改任何默认值之前先取六组基线（`ash_renderer/exposure_get` + `color_scope_get` + `frame_dump` 转 PNG 读图）。机位：

| --- | --- | --- |
| 室内大厅 | az −27 / el 35 | `set_cam([0,3,0], 90, 5.05, 5.0)`（进货机位，看向中庭） |
| 纯天空 45° / 70° | az 160 / el 45 或 70 | `set_cam([0,300,0], 340, −45, 10)`（300 m 高向上看，整帧天空） |
| 日照地面 | az 160 / el 45 | `set_cam([0,0,0], 90, 35, 6)`（中庭俯视，含亮斑与拱廊阴影） |
| 日落 5° / 15° | az 160 / el 5 或 15 | `set_cam([0,300,0], 340, −5, 10)`（地平线附近） |

`frame_dump` 出来的是**线性 LDR**，直接当 sRGB 看会偏暗，脚本同时导出了 sRGB 编码版再读图。室内 5 s 适应后才采，`color_scope_set {"once":true}` 保证读到的是新一帧。

问题不在钳位（ACES 把所有场景的 clip 都压到 0%），而是天空/日落被 `min_scale` 钳在 2.6 倍以上偏亮，p50 0.40–0.47，高光去饱和，读图是"白茫茫一片"。

## 推导（这是本段唯一的"调参"决策）

- **不改 key 就改不了天空**：未钳位的场景，曲线输入恒等于 `key × gain`。所以改 key 必须同步改 gain，才能让室内画面逐位不变。
- key 取 **0.01305 = 2^−6.261**（默认机位的实测 avg_log2），室内倍数回到 1.0（判定线⑭要求 0.9–1.1）。
- gain 取 **6.13 = 0.08 / 0.01305**，乘积仍是 0.08，未触下限的场景与改前同级。
- **min_scale 0.25 → 0.05**：天空需要 0.096 才不过曝，0.05 给正午/日落留约 2 倍余量；室内 0.77–1.0 远在它上面，不受影响。
- 不改曲线数学、不改测光结构；**不启用**太阳盘排除——默认参数已经让天空不钳位，再加排除规则属于另一段的事。

先用 BRP 试参（`exposure_set {"key":0.01307,"min_scale":0.05}` + `bloom_set {"gain":6.13}`）逐场景复核，确认后再写进代码默认值：

- `ash_renderer/src/render/passes/post/exposure.rs`：`Default for ExposureSettings` 的 `key: 0.01305`、`min_scale: 0.05`，注释重写为实测口径 + 乘积不变的理由 + 天空下限依据。
- 单测 `default_key_matches_accepted_baseline_exposure` 改成断言 `scale_for(−6.261) ≈ 1`（±0.03）、默认太阳 −7.9 → 2.5–3.5×、天空 −2.873 → 0.05–0.2×（下限不钳制）。
- `ash_renderer/src/render/passes/post/bloom.rs`：`gain: 6.13`，注释说明与 key 同步、天空交给 min_scale。

- ⑮ 低太阳红移：日落地平线（脚本按地面边界自动取带，四张图 boundary 均 row 555）R/B 1.878 / 1.522 ≥1.3。

读图：室内中庭石墙与绿/红/蓝帷幕颜色可辨、不灰平；天空是深蓝天 + 白太阳盘 + 米氏辉光；日落橙带保留。**已知局限**：8-bit LDR 下天空可见渐变环带/竖条，属量化伪影（不是钳位），要根治需抖色或更高位深，记录备查、不在本段处理。
