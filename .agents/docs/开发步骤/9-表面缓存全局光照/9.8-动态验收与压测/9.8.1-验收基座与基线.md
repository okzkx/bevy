# 9.8.1 验收基座、条件单与基线

> 2026-11-26 施工，分支 `goal/9.8`（起点 `eaac3da21`）。依据
> [施工计划](施工计划：动态验收、压测与局限对照.md) §2 的 9.8.1 与 §3 的 G1–G3。

## 一、基座

新增 `tools/gi_acceptance.py`（Python 3.11，UTF-8/LF）：

- `Host`：先探 `gi_stats`，端口占用则 attach，否则用 `ASH_BRP_PORT` 起
  `target/release/ash_renderer.exe`，stdout/stderr 落 `host.log`。
- `Session.snapshot`：`frame_dump` 回读 LDR PPM → sRGB PNG，同时算整屏均值、p50/p95/p99、
  黑像素占比与 `pose_valid`。画面取证只走这条通道（9.7.7 的 PrintWindow 失帧事故）。
- `Session.sample`：一次取 `gi/scgi/ibl/perf/residency/draw/light/exposure/sun` 八类读数。
- `condition_sheet`：HEAD、分支、exe 路径/sha256/mtime、GPU 驱动与显存、分辨率、启动命令行。
- `apply_baseline`：关 GI → 写规格四件 → 开 GI 与固定设置 → `ibl_set sh_l2` →
  `exposure manual` → 太阳 45°/55°。规格与 `enabled=true` 拆成两次请求（`gi_set` 只允许关态改规格）。
- `diff_frames`：sRGB 整屏 mean/p99/p999/max、>8/>16/>32 变化占比与 bbox；判定用 >16 的占比，
  基线噪声在 >2 阈值下就有 6.2%，不能用。

运行：

```
python tools/gi_acceptance.py baseline --keep
```

## 三、读数

- **新鲜度**：太阳 55°→30°，前后整屏差分 mean 15.71（阈值 0.5/255，过）。
- **噪声底**（同机位 10 s）：mean 0.108、p99 6、max 13（8-bit sRGB）。后续残影阈值按
  `max(1, 2×噪声底)` 取，避免把时域抖动当残影。
- **四机位**：default / gallery / courtyard / overhead 均有 `frame_dump` PNG 与读数，
  均值分别为 42.51 / 40.25 / 32.08 / 34.08（见 `baseline.json`）。
- **SCGI 读数**：coverage 0.9990、alpha mean 0.9984、negative 0、non_finite 0；
  `l0_all_mean` = [107.7, 129.2, 170.7]，仅作参考，不作判定（9.7.7 已证读数不稳）。

## 四、读数补齐

`perf_samples` 原导出漏了 `gpu_gi_ms`（`FrameSample` 有此字段、`perf_stats` 有分位块，只有原始
样本没有），导致压测无法按帧统计 GI 段耗时。已在
`ash_renderer/src/remote/census/perf.rs` 的样本 JSON 补上该键，release 重建后压测使用。
