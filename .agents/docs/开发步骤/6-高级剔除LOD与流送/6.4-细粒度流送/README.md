# 6.4 细粒度流送

对应[执行路线图](../../学习目标实现步骤.md)步骤 6 第四段（流送深化），[段施工计划](施工计划：细粒度流送拆解.md)（2026-10-19 转正立案，未施工）。本 README 是段任务面板与材料目录；任务面板随开工转入。

**定位**：6.2（GPU 选档）与 6.3（CPU 驻留预算）的合流：LOD 变体档按独立 Mesh 身份管理，贴图按整张资产加第二列字节预算。**现状不是整级 mip 流送**：一张图的 mip 链仍整张进出，缺图回退永驻白图；mesh 的 level 0 是最细基准档，变体档缺席时 GPU 向更细的低编号档回退，基准若被 6.3 预算淘汰则整行暂缓。页级 VT 仍挂[外置拓展条目 6](../../外置拓展需求.md)，不属于步骤 6。

**一句话说明**：6.4 在 6.3 管理器上加入 LOD 变体需求集与逐档淘汰、贴图整资产字节预算和永驻白图兜底；请求复用脏行上传，绘制时从选中档向更细档找在场引脚。基准档（level 0，最细）仍是 DrawList 可绘前提，若被 mesh 预算淘汰，该行暂缓；没有远景低模/HLOD 常驻，也没有按 mip 层流送、替换式贴图或 sparse residency。页级 VT 保持外置；真实磁盘 IO 与大资产场景归步骤 7。
