# 6.2 GPU LOD

对应[执行路线图](../../学习目标实现步骤.md)步骤 6 第二段，[段施工计划](施工计划：GPULOD拆解.md)（2026-10-19 立案，未施工）。本 README 是段任务面板与材料目录；任务面板随开工转入。

**定位**：步骤 6 第二段。视锥（5.2）与遮挡（6.1）两刀之后补第三刀"远近该画多细"——远处实例画粗网格，把 5.5 压测出的顶点与光栅化前端开销按距离收敛；同时给后续变体档驻留管理备好消费半边（缺档时从选中档向更细的低编号档回退；基准缺席则整行暂缓）。

**一句话说明**：这一段只做 GPU 侧 mesh LOD 选择与 indirect 命令联动——前置施工件 BRP 场景脚本化（场景生成序列录成 Python 脚本持久化，测试场景一键重建，先于本段测试落地）+ 生成器/测试实体出多档 mesh（细分阶梯）+ compute 按屏幕覆盖尺寸选档（迟滞防抖）+ 档位经标记链传给 build_indirect 改写命令的 indexCount/firstIndex/vertexOffset + LOD 开关与三开关矩阵的 A/B 计量；为 6.4 逐档管理铺"缺变体档向更细档回退"的消费地基（6.2 本段全档常驻；后续淘汰变体才触发回退，基准缺席则不绘制）。不做流送、不做 cluster 级（meshlet）路线，不承诺画面质量提升（画质归步骤 8/9）——主张的是"同画面下省工作"的计量收益。
