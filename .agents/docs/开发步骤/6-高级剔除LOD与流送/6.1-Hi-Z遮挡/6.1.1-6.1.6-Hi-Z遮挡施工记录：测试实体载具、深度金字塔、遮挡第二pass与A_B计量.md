- 资产经济：`TestShapeAssets` 资源惰性首建，mesh 按形状缓存、材质按颜色缓存（键=sRGB 位模式）。实测：五形状各建一份（mesh_created=true），同参重复 spawn 共享 AssetId 零新上传（稳态上传批次 mesh 0 个）。

### 6.1.2 深度金字塔底座（feat `f5afa0a90`）

- **能力实测留痕**（§2 核实三件全落）：D32_SFLOAT 的 SAMPLED_IMAGE 位（depth.rs 查询+日志）；R32_SFLOAT 的 STORAGE_IMAGE | SAMPLED_IMAGE | TRANSFER_SRC（HizPyramid::new 查询+日志）；naga textureLoad/textureDimensions/textureNumLevels 的 mip 层参数——两新 shader 过 build.rs 全链 + spirv-val **原生零补丁**。
- **取数通道**（待决 2 收口=倾向方案）：`DepthTarget` usage 扩 SAMPLED（一行 usage + 能力查询 + 连带核对 VUID-08914 无影响——深度附件格式声明未变）；**storeOp DON'T CARE→STORE**（深度被同帧尾归约采样，采完即弃，下帧 UNDEFINED 进场照常丢弃——深度不跨帧持久，金字塔才是持久层）。
- **金字塔本体**（`vulkan/hiz.rs`）：R32_SFLOAT ×2 帧槽、级数复用 `full_mip_chain`（1600×900 → 11 级）、usage STORAGE|SAMPLED|TRANSFER_SRC（TRANSFER_SRC 为判定线 3 读回预留）、per-(槽,级) 源/目标视图、遮挡测试全链采样视图与描述符（独立小布局，set2 冻结纪律不破——立案钉明）；重建走 `rebuild`（device_wait_idle + image/视图重建 + pool reset + 描述符重写），warmup 重置。
- **归约链**：`hiz_downsample.wgsl` 逐 2×2 MIN，逐级 dispatch（不搬 bevy SPD 单 pass 批量重排——学机制不搬架构的既定取舍）。**级序施工订正（运行实抓）**：原形状把 2×2 MIN 写进全尺寸 level 0（只有 1/4 被写、其余未定义，整链读垃圾）——改为 **level 1 起步**（level 1 = 深度 2×2 MIN，L≥2 = 上一级 MIN），level 0 不派发，occlusion 侧 mip 选择下限 1。bevy 的 mip0=深度本体形状不搬：那要一次全尺寸拷贝 dispatch，本仓以"可查层从 1 起"为代价省掉。
- **reverse-Z 保守方向**（判定线 3 最危险单点）：tile 上界 = MIN（值小=远）；正向 Z 同类写法是 MAX，方向相反取错=系统性错杀——单测 + 两 shader 注释 + CPU 参照纯函数三方同源钉死。

### 6.1.3 遮挡测试接入剔除链（feat `f5afa0a90`）

- **落点**（待决 3 收口=倾向兑现）：独立第二 compute pass（`vulkan/occlusion.rs` + `occlusion.wgsl`），录制序 = 视锥剔除 → 遮挡 → indirect 组装；自有 80B push（view_proj + screen + bound）。
- **descriptor 落位（施工钉明，偏离立案倾向）**：Hi-Z 采样 binding **不进 set2**——金字塔随 swapchain 重建整体换 image，与 set2"描述符 init 一次写入永不更新"冻结纪律冲突；独立小布局（b0 全链采样视图，每帧槽一套）收在 hiz 模块，遮挡管线 layout = [set2, hiz]。set2 只新增 b6（遮挡独立标记 buffer，冻结纪律内——buffer 固定容量）。
- **标记合并语义**（待决 5 收口=倾向兑现）：遮挡独立标记 b6（A/B 归因读数口）+ b3 合并写（视锥 ∧ 遮挡）——build_indirect 消费形状零触碰（立案边界兑现）。
- **判定算法**（bevy occlusion_culling 同构）：8 角点世界推导 → 任一 w≤0 恒可见（透视无意义早退）→ 像素矩形（Y 翻转与正高度视口直出同约定）→ NDC z 的 MAX = 物体深度上界（clip z/w 对盒拟仿射，极值在角点）→ mip=ceil(log2(最大边)) clamp [1, levels-1] → 2×2 tap 取 MIN → `obj_max < occluder` 判遮挡（等号可见）。
- **CPU 参照件**：`aabb_screen_rect`（投屏参照）+ `occlusion_probe` BRP 方法（逐实体中间量：矩形/层/tap/occluder/物体深度上界/判定）——只进验证不进绘制路径（红线）。实测：CPU 探针与 GPU 标记逐实体一致（7 剔 1 留）。

### 6.1.4 历史深度与边界情形（feat `f5afa0a90` + `1c1fd66d2`）

- **滞后语义**（待决 4 收口=倾向兑现）：2 帧滞后（遮挡读**同帧槽**金字塔 = 两帧前本槽归约输出，`wait_for_slot` fence 免费保证完成——零新同步形状，与标记环读数同纪律）。1 帧滞后（跨提交信号量）未做，留压测证明滞后不可接受时再评估。
- **帧内时序**：同帧"遮挡读旧（命令缓冲前段）→ 渲染写深度 → 归约写新（帧尾）"，遮挡读与归约写落在同一条命令缓冲，屏障收口（ hiz::record_reduction 的进场/级间屏障 + frames.rs 的深度附件→DEPTH_READ_ONLY 屏障）。
- **fallback**（判定线 2）：四判据（disabled/cull_off/pyramid_warmup/camera_jump）任一命中整帧跳过遮挡 dispatch，b3 保持视锥纯结果、b6 host 填全可见；`OcclusionGate` 相机跳变判据 = 本帧 vs **两帧前**（与读数滞后同窗），阈值位移 0.5/旋转 15°，两帧累计语义单测钉死（连续微动累积超阈同样让路——滞后窗语义下金字塔内容确实落后了，让路是诚实行为）。跳变窗仅 2 帧，HTTP 轮询观测不到，以单测为判定线 2 的证据形态。
- **resize**（负例实测过）：金字塔随 swapchain 重建（幂等 + device_wait_idle + warmup 重置），遮挡 warmup 期 fallback。**实抓 bug 一枚**：`build_occlusion_sets` 重建路径未 reset occlusion pool（原 2 套未释放再分 2 套 → ERROR_OUT_OF_POOL_MEMORY，宿主走 Tier② 优雅退出）——修复后 resize ×2 全过（金字塔两次重建、warmup 后遮挡恢复、零 VUID）。

## 3. 钉子（施工实抓）

1. **级序钉（最危险）**：金字塔 level 0 必须不派发（原形状 2×2 MIN 写全尺寸图 = 1/4 内容 + 未定义垃圾），归约从 level 1 起步、mip 选择下限 1。
2. **VUID-00344 布局声明**：深度采样描述符的 image_layout 必须声明 DEPTH_STENCIL_READ_ONLY_OPTIMAL（与帧尾屏障落位一致），声明 GENERAL 即验证层报。
3. **occlusion pool 重建 reset**：重建路径先 reset 再分（resize 负例实抓 OUT_OF_POOL_MEMORY → 宿主优雅退出）。
4. **惰性资源首建**：`world.resource_mut` 不建资源，首次 spawn_shape 即 panic（6.1.1 实抓）——`get_resource_or_insert_with`。
5. **遮挡样本摆位陷阱**：轨道相机 yaw=35° 时相机在 (+x,+z) 侧——遮挡对/墙体样本必须沿"相机→目标"视线放置（set_camera 显式钉机位后再摆，否则样本在相机背后探针报 w≤0 恒可见）。

## 4. 遗留与顺延

- **1 帧滞后**（待决 4 的另一半）：未做——2 帧滞后 + fallback 在实测场景无长期误剔，压测证明不可接受时再评估（立案即此口径）。
- **遮挡开启档与 5.2 cull-stats 零 mismatch 判定线的共存**：遮挡开启时 mismatch = 合法遮挡剔除（语义已变），回归口径 = 遮挡关闭档零 mismatch（本段实测口径，写入流程篇供 6.2/6.3 沿用）。
- **金字塔 CPU 逐级对照的自动化**：`hiz_census`/`occlusion_probe` 是读数口，逐级自洽对照（L+1 tile = min of L 的 2×2）目前靠人读，压测批量脚本顺延 6.2 立案时一并考虑。
- **收益压测**（5.5 三档 × 遮挡开关）：本段样本规模（8 实体）验的是正确性；剔除收益的规模读数归 6.3 流送段的预算账（立案"不承诺压回预算"边界不变）。
