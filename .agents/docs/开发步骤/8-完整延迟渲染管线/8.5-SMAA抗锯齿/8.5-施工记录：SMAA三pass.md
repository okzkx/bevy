# 8.5 施工记录：SMAA 三 pass

> 2026-10-22 施工、2026-10-23 续工收官（`goal/8.5`）。对应[段施工计划（立案补档）](施工计划：SMAA三pass.md)。2026-10-22 当日代码完成但运行级验证未过（白图 + 布局竞争 VK-ERROR，当日如实留存不并回）；2026-10-23 续工定位修复后判定线四条全过，本篇为收官版。

## 实际做了什么

- **三 pass shader**（源 = bevy_anti_alias `smaa.wesl` @ 0.20-dev，MIT 官方移植，拆分器 `.temp/8.5/split_smaa.py` 行号提取 + 条件编译展开——HIGH 档、corner/diag 全开、无 predication/reprojection；实抓钉：@elif/@else 链、`} @else {` 同行块拆分、helpers 必须在 entry 之前、源段尾行 off-by-one）。绑定重排为 set0 共享（b0 输入纹理 / b1 SmaaInfo / b2 采样器 / b3+b4 LUT 或 blend）；neighborhood 加 flags.x 开关直通。
- **LUT 预生成纹理**（立案"官方预生成 texture"路线）：bevy_anti_alias 内置 ktx2（zstd 压缩）→ PNG 转档嵌入（`_smaa_area_lut.png` 160×560 / `_smaa_search_lut.png` 64×16），`Image::from_buffer` 解码 → upload 直传 GpuImage。
- **`render/pipeline/smaa.rs`**：SmaaTargets（LDR/edges/blend 三目标 ×帧槽环 + 两 LUT + SmaaInfo UBO（rt_metrics + flags）帧槽环 + 三组描述符集）+ SmaaPipelines（三全屏管线，本体持有——8.4 句柄拷贝陷阱先例）+ rebuild（随 swapchain 闸门③）。
- **链路重构**：tonemap 落点从 swapchain 改 LDR 目标（UNORM 线性存储，编码仍在 swapchain SRGB view 恰好一次）→ edge → blend → neighborhood（swapchain + UI 接画）；BRP `smaa_set` + `tools/brp.py smaa-set`。

## 主线程栈溢出钉（环境级，已修）

8.5 构建稳定 `has overflowed its stack`（基线 0/2、8.5 2/2），文件探针定位 Context::new surface→physical_device 段——主线程栈余量临界（MSVC 默认 1MB）被 init 主链 + 后处理段帧增量压破。修复 = build.rs `/STACK:16777216`（主线程栈保留 16MB；子线程不受影响）。init 链深度治理另立账。

## 续工修复（2026-10-23，三枚同根/同族缺陷实抓）

1. **白图 + 布局竞争 VK-ERROR 同根**：tonemap 落点改 LDR 后**漏录 LDR 的进场屏障**——tonemap 的 begin_rendering 期望 `COLOR_ATTACHMENT_OPTIMAL`，而 LDR 首帧在 `UNDEFINED`、之后每帧停在上一轮的 `SHADER_READ_ONLY`，恰好是全部 10 条 `VUID-vkCmdBeginRendering-pRenderingInfo-09592` 的两种 current layout 实录（两帧槽两条 image，验证层 dedup 上限 10 封顶）。布局错乱使 tonemap 写入不可靠 → nb 采样白图。修复 = tonemap 前补 LDR 的 `UNDEFINED→COLOR_ATTACHMENT` 进场屏障（edges/blend 同款纪律）。修复后画面恢复（非白 97.8%），VK-ERROR 清零。
2. **resize 闸门③漏 SMAA 重建**：闸门③重建清单有 G-buffer/Bloom/cluster，没有 smaa——resize 后 LDR/edges/blend 留在旧尺寸（日志实证：G-buffer 重建行存在、SMAA 重建行缺席）。修复 = 闸门③补 `smaa_targets.rebuild`。
3. **rebuild 幂等判据写坏**：`self.extent = extent` 写在幂等比较之前，比较恒真、重建永远早退（缺陷②补了调用也没生效，实抓）。修复 = 比较在前、赋值在后；修复后 resize 日志出现"SMAA 三目标随 swapchain 重建: 1262×753"。
