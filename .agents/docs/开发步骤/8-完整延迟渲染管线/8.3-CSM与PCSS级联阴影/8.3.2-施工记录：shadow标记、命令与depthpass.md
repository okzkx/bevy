# 8.3.2/8.3.3 施工记录：shadow 标记、命令与 depth pass

> 2026-10-22 施工（`goal/8.3`）。任务对应[段施工计划 §1 8.3.2/8.3.3](施工计划：CSM级联阴影与PCSS软阴影.md)（两任务同链连做，合并一篇）。

## 实际做了什么

- **cull 内联四 cascade 标记**（`cull.wgsl` + `gpu/cull.rs`）：同一世界保守盒逐 cascade 求交，写单份交错标记环；cull 管线 layout 扩 [set2, shadow set]（平面族 384B 超 push 上限走 UBO 的落位）；A/B 语义 = 开关关或空场时 host 全可见填充（读数语义 = 剔除量 0），有 dispatch 时 host 不碰（覆盖 compute 输出）。主视锥 A/B 关而 shadow 开时 dispatch 照跑（只产 shadow 标记）。
- **`shadow_build.wgsl` + `gpu/shadow_build.rs`**（compute 单入口）：读在场环 + shadow 标记 + LOD 档位环，逐在场行 × 每 cascade 组装命令；**两枚语义钉的执行面**：①只读 shadow 视锥标记（Hi-Z 不参与）；②引脚取主选档 +1 再粗一档（哨兵向细档回退与 5.3 同款，全哨兵回退对象记录基准）。屏障 = compute 写 → DRAW_INDIRECT 读（5.3 同款形状）。
- **四级联 depth pass**（frames.rs）：每 cascade 一个小 render pass（D32 clear 0 + GREATER + viewport 2048²）+ 一次 `cmd_draw_indexed_indirect`；4B push = cascade 索引；池 VB/IB 整绑。布局纪律：**进出屏障恒录**（UNDEFINED→ATTACHMENT 进 / ATTACHMENT→SHADER_READ_ONLY 出，UNDEFINED 作 oldLayout 从任意终态合法）——composite 的 shadow 描述符恒绑定（空场/关闭帧也在集内），地图布局必须始终合法（首跑实抓 VUID-09600 即修）。`gpu_shadow_ms` 计时区间插入 T2（后续段界顺移一位，QUERIES_PER_FRAME 7→8）。

## 钉子

- FrameDraw 增 `shadow_build`/`shadow`/`shadow_set`/`shadow_images` 四字段；shadow 输入的池句柄在场行非空断言（与主管线同一状态矛盾语义）。
- 计时段界顺移触及 perf.rs（[f32;6]→[f32;8]）与 frame.rs 样本映射——mark 序号 2..7 与 fetch 区间一一复核（dup mark(2) 首跑实抓即修）。
