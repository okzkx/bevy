# 8.3.1 施工记录：CSM 级联底座

> 2026-10-22 施工（`goal/8.3`）。任务对应[段施工计划 §1 8.3.1](施工计划：CSM级联阴影与PCSS软阴影.md)。

## 实际做了什么

- **级联矩阵**（`render/shading/shadow.rs`）：`cascade_matrices` 逐级拟合——切片角点经 inv_view_proj 反投影到世界、光空间（look_at + RH D3D 正交 + 反 Z 偏置 z'=1−z，与主深度链清 0+GREATER 成套）取 8 角点 AABB 收紧正交盒；log 分割 0.5→80m（超债函数 powf/exp/ln 在仓库禁用清单，边界值落常量表 + const 静态断言钉尾值）。单测两枚：切片中点投影进本级 NDC 盒且深度居中（0.5）、pack 往返校验。
- **shadow 资源族**（`render/pipeline/shadow.rs`）：`ShadowTargets`——4×D32 2048²（`DepthTarget` 复用，固定尺寸不随 resize）、逐帧槽 shadow UBO（704B：4×mat4 + 24 平面 + 分割带/相机基/尺寸+开关旗标）、单份交错标记环（[槽][cascade] 4×u32）+ 四命令环；描述符 set（b0 UBO / b1..4 深度图 / b5 标记 / b6..9 命令环）——shadow 域 binding 全收本 set，instance set2 冻结表零解冻。`ShadowPipeline` depth-only（[set2, shadow set] + 4B push cascade 索引；VUID-08914 深度声明面 = 实例附件全集仅 D32）。
- **`shadow_write.wgsl`**：顶点变换直出（firstInstance 携带槽号语义沿用），空片元；build.rs 自动编译（wgsl 目录即清单）。
- **`ShadowSettings`/`ShadowDiagnostics` 资源**（host/mod.rs init_resource）+ 帧槽 UBO 写入（draw_frame 4a-0-1，与主 UBO 同一 fence 证据）。
- **BRP**：`shadow_set`（开关）/`shadow_stats`（逐 cascade GPU 标记 vs CPU 参照对照）+ `tools/brp.py shadow-set/shadow-stats` 子命令。
