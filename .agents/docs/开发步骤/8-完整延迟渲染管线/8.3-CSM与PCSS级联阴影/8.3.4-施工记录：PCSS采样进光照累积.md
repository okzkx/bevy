# 8.3.4 施工记录：PCSS 采样进光照累积

> 2026-10-22 施工（`goal/8.3`）。任务对应[段施工计划 §1 8.3.4](施工计划：CSM级联阴影与PCSS软阴影.md)。

## 实际做了什么

- **composite 接 shadow 域**（`gbuffer_composite.wgsl` @group(3)）：b0 shadow UBO + b1..4 深度图（`texture_load` 自写滤波路线，无 compare sampler）；`CompositePipeline` layout 加第四集。
- **`shadow_visibility`**：开关旗标（UBO y）旁路 → cascade 选择按视深（dot(world−cam, forward) vs 分割带，带外保守无影）→ 盒外保守无影 → PCSS（blocker search 3×3 取"比片段更近"均值 + 相对比值放大半影半径 1~8 texel + PCF 5×5 随半径步进）；方向光项乘可见性（环境项/透明层不接影——段边界）。
- **防自遮蔽三件**：法线偏移（沿 G-buffer 法线抬采样点 0.01+0.03·级联序号）+ 深度 bias（比较阈值 own+bias）+ 级联序号加大的容差项。

## 实抓缺陷实录（读图驱动的三轮修复）

1. **全场景自挡**（首版全暗）：bias 符号反了——`own − bias` 在 reverse-Z 下把表面自身 texel 判成遮挡物；改正为遮挡须 `d > own + bias`。
2. **roof 满屏半影噪**：32× 放大差值可视化（临时诊断 path，验证后即删）实抓 `d − own` 有 ±0.0156 的逐像素抖动 = G-buffer 深度重建的世界坐标噪声在粗级联 ndc 范围里被等比放大，远超常量 bias——级联序号加大的容差（+0.012·ci）收口。
3. **UV y 翻转假设证伪**：翻转版 roof 噪声更差，原版正确——撤。

- 级联边界：内天井投影区横跨多级联读图无硬缝（PCSS 软影渐变）——判定线② ✅。
