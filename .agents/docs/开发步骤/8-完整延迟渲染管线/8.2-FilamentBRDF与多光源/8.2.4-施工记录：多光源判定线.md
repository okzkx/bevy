## 1. 实际做了什么

### 1.1 spawn-shape 扩 PBR 参数面（判定线③载具）

- `spawn_test_shape` 增 `metallic` / `perceptual_roughness` 两可选参（缺省 = StandardMaterial 默认 metallic 0 / roughness 0.5，既有调用零变化）；材质缓存键 `ColorKey` 升 `MaterialKey`（颜色 + 两标量位模式，缺省记 NaN 位与显式给值天然异键，缓存不串味）。
- BRP `ash_renderer/spawn_shape` 协议面与 `tools/brp.py spawn-shape --metallic/--roughness` 同步透传；LOD 阶梯调用点补 `None, None`。
- 判定线③由 BRP 驱动（测试规范 BRP 优先），零一次性探针。

### 1.2 金属/粗糙度梯度读图（判定线③）

- 场景：Sponza 默认场 + 金色球（sRGB 1.0/0.766/0.336）5×4 梯度阵浮于屋顶上空 y=25（金属度 0→0.25→0.5→0.75→1.0 五列 × 粗糙度 0.1/0.35/0.65/0.9 四行），双点光 e3~e4 量级（8000 cd ×2，依 8.2 段 README 点光量级钉）。
- 取证：`.temp/8.2-gradient/grad_grid_hi.png`（斜视）、`grad_top.png`（俯视，行=粗糙度/列=金属度）、`grad_side.png`（侧视）。
- 读图结论（俯视图）：①介电体列（metallic 0）漫反射带金色 albedo、高光白色不带色；②金属列（metallic 1）漫反射消失、底色暗、高光带金色 F0 色；③粗糙度行梯度：高光从锐点（0.1）渐变到宽软斑（0.9）；④中间列渐进过渡无跳变。**判定线③ ✅**。
- 写后读对账：`ring-census` 143 行（103 Sponza + 40 球 = 两轮 spawn），material_ring_match 全 True；20 组期望 (metallic, roughness) 对全部在账（材质环 metallic/roughness 逐球读回与 spawn 参数一致）。

### 1.3 DamagedHelmet 双渲染器对照（判定线①参照渲染半边）

- 资产：filament 仓库自带 `third_party/models/DamagedHelmet/DamagedHelmet.glb`（3.8MB）拷入 `assets/filament/`（本地资产，已随 sponza/zero_day 先例进 `.git/info/exclude` 本地排除）。
- 我方：宿主 `--scene filament/DamagedHelmet.glb` 单体进场，ring-census 1 行在账，材质记录 metallic=1.0/roughness=1.0（metallicRoughness 贴图槽挂 texture，逐 texel 语义运行期采样）。
- 参照：filament 本体 `gltf_viewer.exe`（rc/1.78.1-cut 开发线，本机已编译产出 `out/cmake-rel/samples/Release/`）。同参数配置（`.temp/8.2-gradient/filament_settings.json`）：阳光 20000 lx、方向 (0.405,-0.206,-0.891)（与宿主 `lights.rs` 实体 forward 同源）、白色、`castShadows=false`；`view.colorGrading.toneMapping="LINEAR"`（对齐我方无 tonemap 直出）；曝光标定到 8.2.4 口径（aperture 16 / shutterSpeed 5.17 / ISO 100 → 1/(2^10.37×1.2) ≈ 6.3e-4 = EXPOSURE 0.00063）；`iblIntensity=0` + 无效 `--ibl` 路径压掉默认 IBL（`assets/ibl/lightroom_14b`）+ 关天空盒。取证 `helmet_filament.png`（白屏废片，IBL 默认加载未压掉的教训）；`helmet_ref.png`（有效参照，--frames 300 等 glTF 异步加载完）。
- 读图结论（正面机位对照 `helmet_ref.png` vs `helmet_ours_front.png`）：几何形状、贴图映射（baseColor/normal/metallicRoughness）、UV 对齐**无可见形状偏差**；金属语义一致（穹顶金属暗底 + 日光高光、框架银白金属件）。**判定线①参照渲染半边 ✅**（照抄口径的函数级一致与数值收敛半边已在 8.2.3 施工记录收官）。

### 1.4 gltf_viewer settings 钉子（复用必读）

- `shutterSpeed` 单位是 1/秒（给 0.1935 = 实际曝光 5.17s 过曝白屏）；`toneMapping` 在 `view.colorGrading` 下且取字符串字面量（`"LINEAR"` 非 0）；light `type` 大写（`"SUN"`）；默认 IBL `assets/ibl/lightroom_14b` 在 `--ibl` 空串时兜底加载，须给无效路径压掉。
- `--screenshot` 与 `--frames` 组合：截图在 N 帧后落盘，glTF 异步加载未完时截到空场（40 帧不够，300 帧稳）。
