## 实际做了什么

### 迁移（提交 c80b87c56，纯移动零行为变化）

`vulkan/` 20 文件按职责归入 `render/` 三子目录后 `vulkan/` 退役（git mv 保历史，git status 全部识别为 rename）：

| 新位置 | 文件 | 职责 |
|---|---|---|
| `render/` 根 | mod / context / swapchain / perf / resources | 模块根/进程级上下文/present 引擎/计量/内存契约 |
| `render/assets/` | images / pool / uploader / mesh_convert / descriptors / instance_table | 资产级六件 |
| `render/gpu/` | cull / occlusion / lod / hiz / indirect | 5.x/6.x compute 家族 |
| `render/pipeline/` | frames / graphics_pipeline（原 pipeline.rs）/ overlay_pipeline / depth | 帧编排/管线/附件 |

钉明两枚：
- **`pipeline.rs` 更名 `graphics_pipeline.rs`**——`pipeline/pipeline.rs` 触发 clippy `module_inception`；内容零改动，`git log --follow` 历史连续。
- **shader 不分子目录**——build.rs 平铺扫描 `examples/shaders/*.wgsl`，新 shader 以 `gbuffer_`/`transparent_`/`present_` 前缀区分（§3 待决"shader 子目录"的落定）。

顺带收掉一处 main 上就有的 clippy 新 lint（asset_ops.rs collapsed-if，let-chains 改写，行为不变）——为守住"clippy 全净"判定线。

### G-buffer 基础设施（提交 5ce0ced70）

- **`render/pipeline/gbuffer.rs`（新）**：GBufferTargets——每帧槽 albedo（R8G8B8A8_UNORM）+ normal（R16G16B16A16_SFLOAT）+ HDR 中间目标（R16G16B16A16_SFLOAT）三附件 + 采样集（b0 albedo/b1 normal/b2 hdr/b3 depth/b4 线性采样器，SHADER_READ_ONLY 布局发布）。resize 生命周期照深度附件纪律（幂等判据 + device_wait_idle）。
- **`render/pipeline/fullscreen_pipeline.rs`（新）**：全屏三角管线骨架（无顶点输入——**pVertexInputState 不能为 NULL**（VUID-pStages-02097 首跑实抓），空绑定/空属性的结构即"无顶点"合法表达）+ CompositePipeline/PresentBlitPipeline 两个 Resource 包装。
- **frames.rs 多 pass 重构**：单 rendering 实例 → compute 半边 → G-buffer pass（双 color + 深度）→ 附件转只读屏障 → 合成（G-buffer 光照 → HDR 目标）→ Hi-Z → present blit + UI（swapchain）。计时 marks 5→7 位（T2=G-buffer / T3=合成 / T5=blit），PerfLedger 字段 gpu_graphics_ms 拆为 gpu_gbuffer_ms + gpu_lighting_ms + gpu_present_ms。
- **graphics_pipeline** 改多 color 声明（`&[Format]`，逐附件 blend 态），shader 从 debug_draw.spv 换 **gbuffer_write.spv**（新：albedo+normal 双输出，albedo.a 恒 1——背景判定走合成端 depth==0，不占 alpha）；debug_draw.wgsl 退役为参照。
- **新 shader**：`gbuffer_composite.wgsl`（延迟合成：mode 0 Lambert 与 forward 同公式同常量/1 unlit/2 normal viz；背景 = depth.r<=1e-6 → 清屏色）、`present_blit.wgsl`（HDR 目标 → swapchain，线性域直出，SRGB ROP 编码恰好一次）。
- init/teardown 链：GBufferTargets 先于 FramePool 拆（采样集里的深度视图先于深度本体）；全屏对先于 GBufferTargets 与 BindlessTables（layout 借用关系）。

### 首跑钉子（验证层实抓三枚）

1. pVertexInputState NULL（上述）；
2. **深度描述符布局**：采样集里 depth 用 SHADER_READ_ONLY 布局写描述符，而帧编排迁移到 DEPTH_READ_ONLY——VUID-00344 布局匹配规则，改 DEPTH_STENCIL_READ_ONLY_OPTIMAL；
3. **HDR 目标屏障序**：hdr 的"转只读"最初与 albedo/normal 同批（G-buffer 收口后）插——合成 begin_rendering 时 HDR 还在 SHADER_READ_ONLY；移到合成收口后（透明层 8.1.3 并入本区间时再次后移）。
