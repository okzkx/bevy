# 7.6 帧率与刷新率同步（M6 追加段）

对应[步骤 7 README](../README.md)与[路线图步骤 7 节](../../学习目标实现步骤.md)。

**目的**：7.5 收官记录"fps 锁 60.0"实为宿主 `WinitSettings` 写死 reactive(1/60) 的 update 节流，非渲染瓶颈（swapchain 已 MAILBOX 免 vsync 背压）——用户指出默认场景应能更快。本段把帧循环节奏做成可观察可控制：显示当前帧率与屏幕刷新率、UI 开关一键同步、首次运行自动按显示器刷新率同步。

**一句话说明**：本段给宿主装上帧率同步（刷新率读数 + "同步 vsync"开关 + 首次运行自动同步），监控窗口显示当前帧率/屏幕刷新率，BRP 通道可读写开关供脚本无人值守 A/B；不主张渲染机制特性，也不动 swapchain present mode（MAILBOX 保持），"同步 vsync"= 帧循环节奏对齐刷新率而非 present mode 切换。
