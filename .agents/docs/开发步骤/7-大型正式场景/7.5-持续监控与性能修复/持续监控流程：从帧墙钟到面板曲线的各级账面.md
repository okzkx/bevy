# 持续监控流程：从帧墙钟到面板曲线的各级账面

> 7.5 功能流程导读（无任务序号）：持续监控仪表 + FPS 恶化修复的机制走读——各级账面全景、新文件分工、逐时刻走读、失败与稳态路径，文末附代码改动简要解析（`git show --stat` 实数）。验收复述见[施工记录](7.5.1-7.5.4-持续监控与性能修复施工记录：监控仪表、FPS恶化取证与无界账修复.md)。

## 账面全景

```
draw_frame (Last)
  ├─ perf.mark_frame_start()            → frame_wall_ms（相邻起点墙钟差，F26 方向仪器）
  ├─ perf.push(FrameSample)             → PerfLedger 环形账（2048 帧；CPU 分段+GPU 区间+规模）
  └─ Vulkan 侧（memory_budget 只在采样时被现查）

run_egui_pass (Update)
  ├─ FpsMeter.tick(delta)               → 0.5s 出一次快照（返回"刚刷新"）
  │    ├─ MonitorHistory.sample()       → 监控历史账（7200 点 = 1h；窗口显隐不影响）
  │    │     ├─ process_working_set()   → GetProcessMemoryInfo（进程工作集）
  │    │     ├─ system_memory()         → GlobalMemoryStatusEx（系统总量/可用）
  │    │     └─ Context::memory_budget()→ VK_EXT_memory_budget properties2 现查
  │    └─ PerfPanelCache.refresh(&perf) → 三字段分位数（每字段一趟 sort）缓存
  ├─ MonitorWindow.show()               → 曲线 + 统计 + 内存/显存行（读历史账）
  ├─ DebugWindow.show()                 → 分位数行读 PerfPanelCache（逐帧零排序）
  └─ timing.last_ms                     → EguiPassTiming（Update 侧墙钟仪器）

BRP (RemoteLast)
  ├─ ash_renderer/monitor_stats         → 读 MonitorHistory 最近采样 + 现查 vram + 内部账
  └─ ash_renderer/perf_stats            → 读 PerfLedger 分位数（低频 BRP 调用，不缓存）
```

## 逐时刻走读

**① 帧起点（Last，draw_frame）**：`perf.mark_frame_start()` 记墙钟并得出与上一帧的间隔 `frame_wall_ms`——这是唯一覆盖"Update 调度 + winit + draw_frame"整帧的读数；帧尾随 `FrameSample` 入环形账。此前的 `cpu_total_ms` 只盖 Vulkan 提交路径（wait/acquire/组装/双环/录制提交/present 六段之和），Update 半边零计量——正是 7.5 取证时 35ms 缺口的藏身处。

**② Update（run_egui_pass 开头）**：`FpsMeter.tick` 累计 0.5s 出一次快照。**只有快照刚刷新时**才做三件重活——监控采样入账（Windows API ×2 + Vulkan properties2 ×1）、分位数缓存重算（3 趟 sort）、监控曲线的 span 重取。其余帧这三处全部复用缓存，逐帧成本只余文本塑形。

**③ 面板（pass 内）**：监控窗从 `MonitorHistory` 取 10 分钟 span 画折线（y 轴 0→窗内 max×1.15）并现算 min/p50/p95/max；调试窗分位数行读 `PerfPanelCache` 的 (p50,p95,p99,n) 元组。文本每 0.5s 才变一次——egui galley 缓存（单帧宽限淘汰）能命中，不再逐帧重塑。

**④ BRP（RemoteLast）**：`monitor_stats` 无参数只读，返回最近采样（≤0.5s 陈旧）+ 现查显存堆 + 内部账；`tools/monitor.py` 按 interval 轮询落 JSONL。

## 失败与稳态路径

- **VK_EXT_memory_budget 缺席**：设备创建时枚举设备扩展不支持 → 不加挂、`memory_budget()` 返回 None → 面板显存行显示"不可用"，BRP 字段为 null——降级不报错。
- **Windows API 失败**（句柄/权限）：采样字段记 None，面板显示"不可用"——监控缺一行不值一次报错（Tier①）。
- **Init 前空帧**：pass 里 `Option<Res<Context>>` 缺席时显存堆读数 None；主窗未建时 egui 整帧让路。
- **账本容量**：MonitorHistory 满容量挤最旧（1h）；PerfLedger 环形 2048——**Default 必须等于 new()**（本次根因，结构体注释钉死）。
