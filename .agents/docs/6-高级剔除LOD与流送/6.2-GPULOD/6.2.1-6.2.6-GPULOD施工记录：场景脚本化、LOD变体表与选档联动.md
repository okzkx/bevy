## 1. 逐任务实录

### 6.2.1 BRP 场景脚本化（前置施工件）

- **`ash_renderer/spawn_lod`**（[remote/shapes.rs](../../../../ash_renderer/src/remote/shapes.rs) 薄壳 + [scene/mechanism/assets/lod_registry.rs](../../../../ash_renderer/src/scene/mechanism/assets/lod_registry.rs) 本体）：sphere 阶梯四档（ico 细分 4/3/2/1，三角形数约 1280/320/80/20）。基准档复用 `TestShapeAssets` 形状缓存（同参零新资产），level 1.. 档位变体按（形状, 档位）缓存在 `LodGroups.variants`——重复 spawn 共享柄零重传。
- **`tools/scene_lod.py`**：场景生成持久化脚本——四距离阶梯（z=0/-8/-24/-56）+ 钉机位 + 判据参数设定，`--build-only` 供 6.3/6.4 复用；默认采证七项（§4）。tools/README 登记。
- **`ash_renderer/lod_census`/`lod_set_enabled`/`lod_set_params`**（[remote/lod.rs](../../../../ash_renderer/src/remote/lod.rs)）+ brp.py 四子命令（spawn-lod/lod-census/lod-set/lod-params）。
- **egui**：ash 调试窗加 "GPU LOD 选档" checkbox + 档位分布行（framework/ui.rs 参数束 + windows/debug_window.rs）。

### 6.2.2 LOD 数据底座

- **两条新环**（[instance_table.rs](../../../../ash_renderer/src/vulkan/instance_table.rs)，八→九份 buffer）：
  - **LOD 变体表环** b7（read，48B/槽 = 4 条 `LodEntry{first_index,index_count,vertex_base}` 12B）：draw_frame 对 LOD 脏行增量重写"槽 → 各档绘制引脚"，模型环同款两帧奇偶纪律；**未写条目 = 全零哨兵**（index_count=0 = 该档未驻留）。
  - **LOD 档位环** b8（read_write，u32/槽）：选档 compute 写本帧档位、LOD 关闭时 host 填 0、宿主诊断直读；init 时**零填充**（迟滞 prev 语义需要"未派发前 = 最细档"，未定义内容会让首帧迟滞读垃圾档位）。表环不填——哨兵语义自洽。
- **set2 解冻**（照 5.1.1/5.2.2 先例，清单）：b7/b8 两条 compute-only storage，pool 计数 7→9，其余 binding 不动；layout 超集声明句子同步。
- **`LodGroups` 登记处**（机制层新文件）：基准 mesh 身份 → 各档变体柄 + level→base 反查（档位到货重挂引用行）；AshLedgerPlugin init_resource 恒在账（flush_uploads 以 Res 读）。
- **upload 链挂点**（[driver/upload.rs](../../../../ash_renderer/src/driver/upload.rs)）：脏行扫描对登记组的**非基准档**补盘点（档位不被实体引用，此扫描是唯一上传触发点；失败档保持哨兵降级）；`set_instance_slot` 处 `mark_lod_dirty`（换槽 = 槽号变，表条目按槽直址必须重写）；档位资产 commit 成功后反查引用行重挂 LOD 脏标（`rows_with_mesh` O(rows) 稀疏事件）。
- **drawlist 写点**（[drawlist.rs](../../../../ash_renderer/src/driver/host/drawlist.rs)）：`write_lod_table_ring`——level 0 = 本行基准 mesh 槽位引脚，level 1.. = 登记组变体引脚（查无 = 哨兵保持 0），同槽档位环写 0（换槽 = 迟滞状态从最细档重新收敛）。

### 6.2.3 GPU 选档与命令联动

- **[vulkan/lod.rs](../../../../ash_renderer/src/vulkan/lod.rs)**：`LodPass` compute 管线（set2 单集 + 96B push）+ `LodSettings`（enabled/threshold_px=256/hysteresis=0.25）+ `LodDiagnostics`（档位分布 level_counts）+ 纯函数两件（`lod_raw_level` floor 分带、`lod_hysteresis_level` 状态机）。选档 pass 录制在遮挡之后、组装之前（[frames.rs](../../../../ash_renderer/src/vulkan/frames.rs) record_frame + FrameDraw.lod）。
- **判据**（[lod_select.wgsl](../../../../ash_renderer/examples/shaders/lod_select.wgsl)）：投屏复用遮挡同款 8 角点推导（一次投影两个消费端，待决 1 钉明按倾向落定）；尺寸度量 = **clamp 进屏后矩形最大边**（CPU 参照同式）；自然档位 = floor(log2(threshold/s)) clamp [0,3]。
- **命令联动**（[build_indirect.wgsl](../../../../ash_renderer/examples/shaders/build_indirect.wgsl)）：`pick_lod_entry` 从选档档位**向细档方向**找最近常驻条目（index_count≠0），全哨兵回退对象记录基准引脚（可绘行基准恒驻留 = 不差于 5.3 行为）；instanceCount 加"引脚全缺防御归 0"。
- **init 链**：LodPass 进 InitChain（创建序 = 拆除反序），host/mod.rs 恒插 LodSettings/LodDiagnostics。

### 6.2.4 边界与 fallback

- **选档无 fallback 专段**（计划任务 6.2.4 钉明收敛）：选档每帧从当前相机现算，无跨帧状态依赖——档位环只是迟滞状态不是真值；相机跳变/resize 的档位重算由"每帧现算"自然覆盖。未驻留档回退由 build_indirect 表内回退承担（§4 判定线 3）。
- **迟滞的 2 帧滞后语义**（钉明）：prev 读档位环本槽 = 两帧前本帧槽输出（与标记环同一条 fence 纪律），2 帧滞后由迟滞带吸收——收敛至多慢两帧，静态场景稳定值不受影响；换槽行档位环重写 0 重新收敛。

### 6.2.5 验证通道

见 §1 6.2.1 条（BRP 三方法 + egui + 场景脚本）。**GPU 计时口径**：选档 dispatch 落在 5.5 计时的 compute 区间内（T0→T1），不单列——A/B 开关对照的图形段/compute 段读数即含其开销（GpuTimer 五位不动）。

## 3. 施工钉子（首钉在前）

1. **首钉：LOD 组扫描把 level 0 重复推进上传清单**——档位变体 levels[0] = 基准 mesh 本身，脏行扫描不跳基准档会让同一身份进 fresh 两次，第二次 `MeshPool::commit` 撞"驻留缓存重复登记"Tier② 优雅退出（scene_lod 首跑实抓：第 4 个 spawn_lod 断连，日志 ERROR 指向去重判定被打破）。修复 = 扫描过滤 `h.id() != mesh_id`（跳过基准档，它由 mesh 腿正常处理）。
2. **档位环 init 零填充**：迟滞 prev 的语义起点必须是 0（未定义内容 → 首帧迟滞读垃圾档位）；表环不填（哨兵回退自洽）——两环初始化语义不同，勿"对称补齐"。
3. **6.1 遮挡首跑日志的帧序顺移**：遮挡 dispatch 首跑从"有实例第一帧"移到"档位 dispatch 首跑之后"（同一帧），hiz_test ①④ 照常过（不依赖日志序）。
4. **WM_CLOSE 单窗投递不关**（复踩 3.12 钉）：EnumWindows 须投递进程**全部**窗口（本机实测 5 个窗口）才可靠退出——scene_lod.py 的 close_host 沿 hiz_test.py 全窗投递版。
5. **残留宿主进程锁 exe**：构建前 tasklist 查残留（os error 5 拒绝访问即有在跑实例），WM_CLOSE 优雅关再建。
6. **图集整传代数随场景 spawn 增长**（第 5/6 代逐帧递增）：egui 图集在面板文字/中文行变化时重整传——非 LOD 链问题，读数口径照 5.4（graveyard 归零即无泄漏）。
