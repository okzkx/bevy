# 粗粒度流送流程：从预算账到请求/淘汰动作的各级账面

> 6.3 功能流程导读（2026-10-19 收官定例）：本段引入了新数据流（驻留管理器的预算账 → 请求/淘汰动作 → 既有重传/回收链），按定例写"从入口动作到最终落点"的走读。面向下一个读代码的人；验收证据归[施工记录](6.3.1-6.3.6-粗粒度流送施工记录：驻留管理器、超预算游历与A_B基线.md)。

## 0. 一句话全景

驻留管理器（`residency_tick`，Last 先于上传）每帧做三件事：把"mesh 身份 → 最近引用行距离/视锥内"聚合出来；半径内的非驻留身份把引用行**重挂脏标**（既有重传链重新驻留）；超预算时按"视锥外优先、距离远优先"把身份**写进卸载回收账**（4.4 既有链回收）。策略层与数据面零新增 Vulkan 形状。

## 2. 逐时刻走读

**每帧 tick（Last，先于 flush_uploads）**：
1. **读数先行**：used_mesh_bytes = recycle_ledger 现读（顶点+索引）；B 面（关/预算 0/空场）只刷读数，激活→关闭**下降沿**全行置脏（被淘汰资产无请求者会永远缺席——B 面完整语义 = 恢复 4.x 全常驻，关闭沿重传链逐帧消化）。
2. **身份聚合**：账本走访一次，mesh 身份 → (最近引用行距离, 任一行视锥内, 引用行清单, 驻留态)。视锥判定复用 cull CPU 参照件（frustum_planes + conservative_world_aabb + aabb_visible）。
3. **冷却走账**：剩余帧递减，归零出表。
4. **请求侧**：非驻留 ∧ 半径内 ∧ 冷却已过 → 全部引用行 mark_dirty → **同帧 flush** 把它们当普通脏行盘点（容器内资产查无 → 转换 → 上传 → commit → arrive 才发布）。
5. **淘汰侧**：used > 预算 → 候选（驻留身份带 min_dist/字节）按"视锥外先、距离远先"排序逐个 `retirements.eject_mesh(id)` + 进冷却表，直到 ≤ 预算；over_budget（候选耗尽仍超）如实报出。

**同帧上传（flush_uploads）**：请求行 = 普通脏行（零新路径）；脏行若属于 LOD 登记组，上传扫描还会收集该组所有未驻留变体，而非仅某个目标档。淘汰身份进 meshes 回收集 → 驻留条目出账 → 网格区间进停尸房 → 排空（图形最后使用 + 上传票据）后归还 free list。

**消费侧（draw_frame，无改动）**：被淘汰的基准 mesh 对应行暂缓（不进在场环 = 无命令 = 无幽灵），即使其他 LOD 变体仍在显存也不会作为远景代理继续绘制；重新请求后重传链换槽重写（新槽 + 旧槽停尸房）。

**失败与稳态路径**：容器内资产必然重传成功（程序化资产即时到货）；容器内缺失（异步加载身份）走 pending/readiness 账（重试通道 6.4 驻留账接管）；静态场景管理器关（默认）= 零动作零成本。

## 3. 语义要点（读代码前先读这段）

- **预算列 = mesh bytes**（顶点+索引）；贴图 bytes 只计量不约束（6.4 下沉）。
- **决策粒度 = 资产身份组**：共享 mesh 的行同进同出；unique 独立资产 = 行级。
- **冷却窗（60 帧）**：淘汰后的防抖窗——回访恢复的延迟上限 ≈ 冷却 + 请求传播帧数，游历读数如实呈现。
- **eject ≠ Removed 事件**：同一回收账、不同计数器（事件累计语义诚实）。
