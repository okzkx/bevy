## 1. 逐任务实录

### 6.3.1 驻留管理器与预算账

- **[scene/mechanism/residency.rs](../../../../ash_renderer/src/scene/mechanism/residency.rs)**（新文件，282 行）：`ResidencySettings`（enabled/budget_mesh_bytes/request_radius/eject_cooldown_frames，默认关 = 全常驻语义不变）+ `ResidencyStats`（预算/实占/请求/冷却/淘汰累计/over_budget 读数）+ `EjectCooldown` 冷却表 + `residency_tick` 系统 + `AshResidencyPlugin`（tick 挂 **Last 先于 flush_uploads**——请求/淘汰动作进同一帧上传账）。
- **预算口径**（待决 3 钉明）：6.3 预算列 = **mesh 驻留字节**（顶点+索引，`recycle_ledger` 现成读数）；贴图 bytes 进 census 计量（张数）但不受约束——贴图整资产淘汰连带材质五槽反向映射与降级白图语义，归 6.4。staging 环瞬态不入账。
- **决策粒度**（待决 1 钉明）：**按资产身份组建组**——共享 mesh 的行天然同进同出（= "chunk 级为主"的等价形状；引用计数由"身份只在其引用行距离满足请求条件时保留"承担）；unique 独立资产时退化为行级（最细可测）。位置 = 引用行世界位置最近距离。

### 6.3.2 请求侧

非驻留身份 ∧ 最近引用行 ≤ request_radius ∧ 冷却已过 → **全部引用行 mark_dirty**（重传链复用：容器内资产查无 → 转换 → 上传 → commit，就绪才发布——判定线 3 的发布语义由 4.3/4.1 既有链承担，管理器零特判）。**淘汰冷却**（待决 2 钉明）：刚淘汰身份 60 帧（可配）内不重请求——预算边界"淘汰→重请求→再淘汰"的逐帧 thrash 被冷却窗吸收；回访恢复 = 相机进入半径且冷却已过（延迟如实计量，游历读数可见 cooling 窗）。

### 6.3.3 上传与发布

零新机制——请求侧只是重挂脏标，上传/发布/就绪账全走 4.1~4.3 既有链（flush_uploads 的 pending/readiness/commit/arrive 路径原样消化）。**这是本段的结构主张**：驻留管理器是策略层，数据面不新增形状。

### 6.3.4 淘汰与回收

- **`AssetRetirements::eject_mesh`**（asset_events.rs 新方法）：管理器发起的淘汰进同一回收账（幂等 insert），**不进 `Removed` 事件累计**（计量诚实：淘汰数归 ResidencyStats.ejected_total）；出账/停尸房/free list 复用与 4.4 完全同路（flush 开头统一排空点）。
- **淘汰排序**：视锥外优先（`aabb_visible` CPU 参照件，宁多留不错杀）、同状态距离远优先——逐个出账直到 used ≤ budget。
- **幽灵防线**（判定线 4）：先撤引用后回收 = DrawList 可绘判定（mesh 未驻留 → 行暂缓不进在场环）——5.3 幽灵对象教训的枚举源头语义自动兜住，管理器零额外动作（实测：淘汰期间 draw_stats 命令条数 ≤ 在场行数、零 VUID）。

### 6.3.5 验证通道与压测

- **BRP**：`residency_stats`（聚合读数 + 逐资产清单：驻留态/最近距离/引用行数/待失效标记）+ `residency_set`（开关/预算/半径/冷却）；brp.py 两子命令。
- **测试基建**：`spawn_shape`/`spawn_lod` 加 **`unique` 参数**（绕过形状/变体缓存直造新资产）——共享资产模拟不出"世界大于驻留"，每实体独立 mesh 身份是压测前提。
- **`tools/scene_stream.py`**：4×4 独立阶梯网格（间距 14，全常驻 ≈3.4MB）+ 预算现算 = 全量 1/3 + 四站环游 + 回访起点 + A/B；`--build-only` 复用入口。

## 3. 施工钉子（首钉在前）

1. **首钉：关闭沿不重驻留，B 面回不到基线**（压测 ④ 实抓）——关掉管理器只停止淘汰，被淘汰资产无请求者永远缺席（used 停在 890KB ≠ 全量 3.4MB）。修复 = 激活态**下降沿全行置脏**（Local<bool> 记 prev_active，active→inactive 沿全行 mark_dirty，重传链恢复全常驻；④ 复测 used 精确回到 3397144B 全量口径）。
2. **eject 与 Removed 事件计量分家**：`eject_mesh` 复用同一回收账但不进 `removed_meshes_total`（事件累计语义诚实——管理器淘汰不是资产 Removed 事件），淘汰计数归 ResidencyStats。
3. **请求半径内身份被预算挤压淘汰时 over_budget 如实报出**（不硬凑预算数字——诚实计量优先于判定线字面）。
4. **tick 读数先于动作**：used/ejected_last 等每帧先归零/现读再走逻辑，空转帧读数不滞留（5.5 帧统计同款纪律）。
