# 步骤 6：高级剔除、LOD 与流送（M5）

对应[执行路线图](../学习目标实现步骤.md)。本 README 是步骤索引与材料目录；各段任务面板在段目录 README（开工时立），段施工计划随立案入段目录。

**目的**：在常驻 GPU-driven 已成立后，减少不可见/过细工作，并让大于驻留预算的世界可持续加载卸载。

**一句话说明**：本步给步骤 5 的"GPU 决定画哪些"再砍三刀——被挡住的不画（6.1 遮挡）、远处画粗的（6.2 GPU LOD）、放不下的按预算搬运（6.3 流送）——把 5.5 压测立起的图形段成本往"只花在可见且够用的像素上"推进；本步不主张画面质量特性（归步骤 8/9），6.4 细粒度流送已随 2026-10-19 增补转正立案、仍不阻塞 M5 主线（6.1～6.3）收官。

**当前验收状态：⬜ 步骤级未验收——6.1 ✅ 施工收官（2026-10-19 当日立案当日施工，[施工记录](6.1-Hi-Z遮挡/6.1.1-6.1.6-Hi-Z遮挡施工记录：测试实体载具、深度金字塔、遮挡第二pass与A_B计量.md)判定线五条全过，并回/推送留用户拍板）；6.3/6.4 ⬜ 已立案（2026-10-19 用户增补，施工计划已入段目录，未施工）。**
