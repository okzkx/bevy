# 步骤 5：最小 GPU-driven 与常驻大场景（M4）

对应[执行路线图](../学习目标实现步骤.md)。本 README 是步骤索引与材料目录；各段任务面板在段目录 README（开工时立），段施工计划随立案入段目录。

**目的**：先让 GPU 独立决定画哪些实例，再扩大规模；不能用逐对象 CPU draw 的结果验证 GPU-driven 大场景目标。

**完成标准**：小场景验证正确后再扩到 1 万、5 万、10 万档实际渲染实例；CPU 不回读可见集、不逐对象重建 draw list。1 万为起始档、5 万为目标档、10 万为压力档，能承载的规模由测量给出，不预先声称三档都能达到固定帧率。

**当前验收状态：⬜ 步骤级未验收——5.1 ✅ 收官（2026-10-15，[段 README](5.1-常驻绘制数据/README.md)）；5.2 ✅ 收官（2026-10-15 同日立案同日施工：判定线五条全过，[段 README](5.2-GPU视锥剔除/README.md)）；5.3 ✅ 收官（2026-10-19 当日立案当日施工：判定线五条全过，[段 README](5.3-indirect闭环/README.md)）；5.4 ✅ 收官（2026-10-19 当日立案当日施工：生成器/chunk 整块增删/基础 mip 链，判定线六条全过；读图半边两项因 DLP 遮挡受阻遗留，5.5 顺带补证——chunk 画面 A/B 与三模式基线已补、mip"远景不闪"半项遗留，[段 README](5.4-常驻大场景组织/README.md)）；**5.5 ✅ 收官（2026-10-19 当日立案当日施工：三档三形态压测 + GPU 帧计时/分位数计量底座，判定线五条全过，[段 README](5.5-分档压测/README.md)）——五段全收官，步骤 5（M4）全段施工完毕，步骤级验收归档未做。**

**场景与规模定案（2026-10-15）**：5.1～5.3 以 FlightHelmet 小场景验正确性；5.4 起交付"常驻大场景生成器"程序化铺实例（bevy_city 参照），不找更大 glTF；5.5 按 1 万/5 万/10 万三档压测。
