# 5.1 常驻绘制数据——实例槽、材质表与按实例索引读取

对应[步骤 5 README](../README.md)、[步骤 5 施工计划 §5.1](../施工计划：最小GPU驱动闭环与常驻大场景五段拆解.md)与[路线图](../../学习目标实现步骤.md)。主计划=[施工计划：常驻绘制数据拆解](施工计划：常驻绘制数据拆解.md)；本 README 是段任务面板。

**状态：⬜ 已立案（2026-10-15，未施工）。**

**目的**：把逐对象绘制参数从 CPU 逐 draw push（96B/对象）换成 GPU 常驻对象表/材质表、按实例索引读取——GPU frustum（5.2）与 indirect 闭环（5.3）的数据地基。

## 任务清单（5.1.1~5.1.6，草案，开工时定稿）

- [ ] **5.1.1 数据结构定案与实现**：对象表/材质表行布局、实例槽分配与回收（Entity→槽号）、表落位（set0 扩 binding vs 新 set）、3.6 冻结边界解冻清单。
- [ ] **5.1.2 包围体**：mesh AABB 源头核实、非均匀缩放保守变换、随行写入对象表（5.1 入库不生效，消费端归 5.2）。
- [ ] **5.1.3 增量写入接入**：flush_uploads 脏行写对象表槽、材质行接 4.2 失效联动、计量分报（槽位数/push 字节/分表上传字节）。
- [ ] **5.1.4 shader 与提交侧**：按实例索引读表、push 缩减为实例标识（或 gl_DrawID）、DrawCall/DrawList 终态、descriptor/pipeline layout 连带。
- [ ] **5.1.5 结构债兑现**：3.6 立账的 host/frames 摊薄，随结构大改一并处理。
- [ ] **5.1.6 验收回归**：判定线五条全过 + 三模式截图 + 负例 + 零 VUID + exit 0 + clippy 全净。

判定线草案见[施工计划 §0](施工计划：常驻绘制数据拆解.md)：逐对象参数不走 CPU 推送 / 画面零回退 / 包围体数据正确 / 增量链零回退 / 既有判定线零回退。
