# 5.1 常驻绘制数据——实例槽、材质表与按实例索引读取

对应[步骤 5 README](../README.md)、[步骤 5 施工计划 §5.1](../施工计划：最小GPU驱动闭环与常驻大场景五段拆解.md)与[路线图](../../学习目标实现步骤.md)。主计划=[施工计划：常驻绘制数据拆解](施工计划：常驻绘制数据拆解.md)；本 README 是段任务面板。

**状态：✅ 收官（2026-10-15，当日立案当日施工：判定线五条全过、零 VUID ×5 进程、WM_CLOSE exit 0 ×3 实抓、clippy 全净、库测试 4/4；[施工记录](5.1.1-5.1.6-常驻绘制数据施工记录：对象表、模型环与push退役.md)、[流程导读](GPU常驻绘制数据流程：从账本行到实例索引的各级账面.md)。）**

**目的**：把逐对象绘制参数从 CPU 逐 draw push（96B/对象）换成 GPU 常驻对象表/材质表、按实例索引读取——GPU frustum（5.2）与 indirect 闭环（5.3）的数据地基。

## 任务清单（5.1.1~5.1.6，全部收官）

- [x] **5.1.1 数据结构定案与实现**：`vulkan/instance_table.rs`——对象表（DEVICE_LOCAL 131072 槽 × 48B，写一次/槽）+ 模型环/材质环（HOST_VISIBLE ×2 帧槽）+ set2 三条只读 storage（init 一次写入）+ 实例槽 free list/停尸房/材质槽 bump-only；3.6 冻结解冻范围 = 仅新增 set2 + push 缩 4B，set0/set1 原样。
- [x] **5.1.2 包围体**：convert_mesh 同遍扫局部 AABB（记录存局部，保"写一次"不变式）+ `conservative_world_aabb` 8 角点保守纯函数 + 单测四枚；消费端归 5.2。
- [x] **5.1.3 增量写入接入**：flush 停尸房段消费 freed_slots 交接账；记录身份 (mesh/票据/材质) 三一致免重写；计量分报（对象记录字节/实例槽/材质槽 + BRP `gpu_tables` 段）。
- [x] **5.1.4 shader 与提交侧**：shader 按实例索引读三表（材质槽 flat varying）；push 96B→4B；DrawList 终态 = 槽位枚举；模型环拆出（施工发现：model 属易变数据，原地覆盖记录是规范级 hazard——三表按写形状分家，详见施工记录 §2）。
- [x] **5.1.5 结构债兑现**：DepthTarget 独立 `vulkan/depth.rs`、DrawList 组装独立 `driver/host/drawlist.rs`（3.6 P1 摊薄建议落地）。
- [x] **5.1.6 验收回归**：判定线五条全过（三模式截图零回退/移动单行/spawn-despawn 槽位闭环/mutate 材质环次帧生效/稳态零上传），增删后 resize×2 存活。

判定线收官口径见[施工记录 §0](5.1.1-5.1.6-常驻绘制数据施工记录：对象表、模型环与push退役.md)（逐条证据表）。
