对应[执行路线图](../../学习目标实现步骤.md)步骤 5 第二段，[段施工计划](施工计划：GPU视锥剔除拆解.md)（2026-10-15 立案，同日施工收官）。本 README 是段任务面板与材料目录。

**定位**：compute 对 5.1 常驻对象表做视锥→可见标记，GPU-driven 闭环第二环——数据常驻（5.1）之后让 GPU 自己决定"谁在视锥里"，indirect（5.3）消费这份标记。FlightHelmet 小场景验正确性。

**一句话说明**：这一段让 GPU 自己判断谁该画——compute 每帧对常驻对象表逐实例做"世界包围盒 vs 视锥六平面"求交、写出可见标记，给 5.3 indirect 铺路。本段只验"标记算得对"，不改画面、不做规模压测。
