## 0. 判定线（验收草案）

1. **读数报告成组**：报告实际实例数、CPU/GPU 时间（p50/p95/p99）、显存与瓶颈归因——不只给"流畅"截图；条件固定按统一口径 §2（版本/GPU 驱动/Release/分辨率/材质光照/present/节流/种子/相机轨迹）。
2. **静态场景仅移动相机时不重传全部实例**：稳态零上传口径在大档位下复验（4.x 五项计量读数为证）。
3. **O(N) CPU 扫描如实报告**：含 5.4 钉明继承的材质环全量重写 O(N) 走访——5.4 立案期定调"规模上去后该走访成本如实进计量，是否成为瓶颈归 5.5 判定"，本段出读数与归因，不做顺手优化。
4. **预算先写后测**：16.7 ms 初始预算、通过阈值与场景配置开跑前固定，不以"肉眼流畅"替代数据（统一口径 §5）。
5. **常规回归**：5.1～5.4 判定线零回退（cull-stats 对照零 mismatch、draw_calls 恒 ≤1、稳态零上传零盘点、chunk 增删精确、槽位闭环）、零 VUID、WM_CLOSE exit 0、clippy 全净、库测试全过、3.5 三模式截图零回退（若 DLP 仍受阻按 5.4 口径记遗留并给恢复条件）。

## 1. 定位：现状与要加的东西

5.4 收官后的形状：生成器（规模参数化、splitmix64 种子复现）+ chunk 整块增删 + mip 链已成立，绘制提交已与对象数解耦（draw_calls 恒 1）。**容量前提已就位（立案期复核属实）**：对象表容量 131072 注释钉明覆盖 10 万档（`instance_table.rs:46`）；命令环 10 万条约 2MB（5.4 立案期核实）。本段加的是"测量"，不是"特性"：

- **压测矩阵**：三档 × 变更形态（零变化/少量变化/全动态）× 静/动比例——增长斜率按统一口径 §4；矩阵参数开跑前钉死（判定线 4 约束）。
- **计量补缺**：CPU 侧分报基础已厚（4.1 五项、5.2 cull-stats、5.3 draw-stats、egui 面板），缺两样——GPU 侧工作区间计时（统一口径 §3 明文，现状 timestamp/query pool 代码零出现，grep 属实）与 p50/p95/p99 分位数统计；手段落点待决 1/2。
- **压测报告**：路线图步骤 5 产出"分档性能记录"的落点——读数、斜率、瓶颈归因成文。

**条件固定现状核实**：present = MAILBOX 优先（`swapchain.rs:10` 模块注释属实）——3.2 已钉 present 信号量≠已上屏，计时须区分真实工作与主动等待（统一口径 §2）；等待统计的边界按统一口径 §6（必要 fence/timeline 复用等待不算违规，显式停顿不隐去）。

## 4. 待决问题（施工时钉明，不写死）

1. **GPU 侧计时手段**：`vkCmdWriteTimestamp` + query pool（直读统一口径 §3"GPU 用对应工作区间计时"，代价 = query pool 生命周期与 reset/resolve 时点管理）vs CPU 帧侧区间近似（零新机制但测不到 GPU 真实工作）——倾向 timestamp query（口径明文要求 GPU 工作区间计时），query 面落点与每帧开销开工实测后钉明。
2. **分位数统计落点**：进程内环形采样 + egui/BRP 读数 vs 日志导出离线分析——倾向两段式：进程内采样读数（压测进行时可见）+ 报告期离线汇总（p50/p95/p99 成文）；采样窗口长度与清零时机施工钉明。
3. **变更形态与静/动比例定义**：少量变化 = 每帧 set_transform 多少行、全动态 = 全部实例每帧变换还是动态子集、静/动比例取哪些档（如 10%/50%/90%）——矩阵参数开跑前钉死（判定线 4 约束）；驱动入口用既有 BRP 方法族，不新增一次性脚本。
4. **相机轨迹固定**：10 万档下漫游输入本身占 CPU 时间，须与被测工作分开——倾向固定轨迹回放（BRP 驱动相机有 3.12 先例），轨道/WASDQE 手动漫游作人工抽查用；轨迹与种子一起进条件记录单。
5. **10 万档真机复核**：容量已核（131072 ≥ 100000），但 10 万实例下材质环规模、命令环规模、描述符与内存预算须真机首跑实测复核（5.4 立案期只算过命令环约 2MB）；驱动侧上限（`maxStorageBufferRange` 等）随首跑留痕。
6. **5.4 读图遗留两项的补证时机**（chunk 增删画面 A/B、mip 近清远稳）：不塞进 5.5 判定线；若压测读图时 DLP 已恢复，顺带补证并记 5.4 施工记录，不承 5.5 判定线责任。
