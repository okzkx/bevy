## 2. 逐时刻走读：一帧样本的一生

1. **帧首（draw_frame@Last）**：`wait_for_slot` 等本槽 fence——CPU wait 计时段；fence 过后 `GpuTimer::fetch(slot)` 读本槽上轮提交的 4 个 timestamp（fence 保证可用，不挂 WAIT），换算三区间（compute/graphics/全帧）。
2. **acquire**：计时段；OUT_OF_DATE 让路帧不入样本。
3. **组装**：`drawlist::assemble`（槽位枚举，O(N) 线性项 1）→ 计时段。
4. **双环写入**：`drawlist::write_rings`（模型环增量 + 材质环 O(N) 走访，线性项 2）→ 计时段。
5. **录制提交**：record_frame 内部 T0（进场屏障后）→ cull dispatch → build_indirect → T1 → rendering（场景一次 indirect + UI）→ T2 → T3；`queue_submit` 提交，fence 挂帧槽 → CPU record_submit 计时段。
6. **present**：计时段（不等同上屏，3.2 钉）。
7. **帧尾**：六段 CPU 合计 + GPU 三区间 + `instance_rows`/`visible_rows` 打包成 FrameSample push 进 PerfLedger（环形 2048，只进计量——诊断性回读边界照 5.2 拍板）。
8. **下轮同槽**：再隔一帧 fence 等完时，本轮的 timestamp 被 fetch——GPU 读数永远滞后两帧（混合口径，稳态同构）。

## 3. 采集时刻（压测会话走读）

```
起宿主（Release）→ BRP 探活
每档：clear_chunks（census→逐块 despawn→census 复核清零）
  → generate_chunks（100 块 × ipc）
  → set_camera 固定轨道 → 预热 8s
  每形态：workload 开关 → 稳定 2s → 记 n0
    → yaw 0→90 十步（每步 1s，第 3/6/10 步抓 perf_stats 快照）
    → 记 n1 → perf_samples --last (n1-n0) ← 该形态权威窗（切片防环窗跨形态混样）
    → stats 快照
  → 清场 → 下档
```

读数通道三入口：egui 调试窗口（人看）、BRP perf_stats（快照）、BRP perf_samples（离线汇总的原始账）。三入口同源 PerfLedger，无第二份账。

## 4. 失败与稳态路径

- **队列族无 timestamp**：`GpuTimer.enabled=false`（warn 一次），GPU 区间缺席、CPU 半边照常——渲染链不受影响。
- **取结果 NOT_READY**：空槽漏网 → 返回 None（无读数），不进取数路径（钉子 1/2：WAIT 挂死与 hostQueryReset feature 均由此关闭）。
- **让路帧不进样本**：最小化/acquire 过时的提前 return 帧不 push——样本窗只含真实工作帧。
- **对象表容量耗尽**：10 万档内对象槽 100006/131072 充裕；压测首日曾因驱动脚本信封 bug 跨档累积 17 万行触发显式报错（Tier② 优雅退出）——渲染器执法正确，脚本已修（施工记录钉子 4）。

## 5. 代码改动简要解析（`git diff --stat` 实数：13 文件 +217/−19 + 新增 2 文件）

**新增**：
- `vulkan/perf.rs`（约 260 行）：GpuTimer + PerfLedger + FrameSample——测量仪器的全部本体。
- `remote/perf.rs`（约 180 行）：BRP 三方法薄壳，读数组装与开关写。

**扩展（改动要点与取舍）**：
- `vulkan/frames.rs`（+25）：record_frame 四点采样——timer 走 `Option<&GpuTimer>` 参数（FramePool 不持有计时器：计时是诊断设施，与帧资源的生命周期解耦）。
- `driver/host/frame.rs`（+51）：七段 Instant 计时 + fetch + 样本 push——分段选在既有编排边界上（不新增段）；样本含 `visible_rows` 供"可见实例数 vs 成本"归因。
- `driver/host/init.rs`（+19）：GpuTimer 入创建链尾/拆除反序（只依赖 Device，顺序相对自由，Context 最后不变）。
- `scene/mechanism/workload.rs`（新增机制件）+ `main.rs`/`scene/mod.rs`/`mechanism/mod.rs` 注册：注入开关默认关，Update 每帧旋转——复用 Changed→账本→模型环链路，无任何渲染语义。
- `vulkan/images.rs`（+17）：alloc_bytes 记录 requirements.size（分配真值口径，非 width×height×bpp 估算）。
- `overlay/windows/debug_window.rs` + `framework/ui.rs`（+61）：面板 perf 行走 DebugUiParams 参数束（16 参数上限同款式）。
- `remote/mod.rs`：三方法注册 + 模块表。
- `tools/brp.py`（+34）：workload/perf-stats/perf-samples 三子命令（brp.py 合计三十子命令）。
