## 放置约定

- 新笔记按主题域进对应子目录，明确跨两域以上的通用方法论/工具留根。
- GPU-driven 决策层与着色层两篇姊妹篇讲的是引擎级取舍（决策权归属、管线模式），归 `引擎/`；`渲染/` 收高质量渲染技法调研，两者互为姊妹、文内互链。
- `渲染/` 内的调研篇共享"对 ash_renderer 的启示"收尾体例；新增调研篇记得同步其 README 表格。
