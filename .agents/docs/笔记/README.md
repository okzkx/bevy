# 笔记面板

跨步骤专题笔记的入口，按**机制**分文件夹。分类规则见《写文档纪律》与入口篇 §九；每篇正文的第一段就是入口，标题可直接当检索词。

## 目录结构

| 文件夹 | 收什么 |
|---|---|
| [命令与提交](命令与提交/) | 一帧怎么录成命令、怎么提交：命令缓冲状态机、执行时序、indirect 绘制 |
| [同步与队列](同步与队列/) | 多个异步主体怎么不打架：屏障/信号量/fence、帧槽、交换链与呈现 |
| [显存与资源](显存与资源/) | 数据放哪、怎么描述：内存落位、常驻表、bindless、纹理压缩与虚拟纹理 |

| [可见性与GPU驱动](可见性与GPU驱动/) | 谁决定画什么：遮挡剔除、LOD、决策权归属 |

## 放置约定

- 新笔记按**它讲的是哪条机制**归类，不按来源文档、施工段号或 API 家族。
- 项目级审查报告与复盘记录（一次性、带时点）不进笔记，住 [审查与复盘](../审查与复盘/)。
- 一篇只进一个文件夹；跨两域时按读者的主要任务选，另一域用互链指路。
- 文件名取主题短名，全称副题留在文内 H1；重命名时全库同步引用。
