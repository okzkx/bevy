### 2. 补丁痕迹（用户担心的"修 bug 留补丁"，核实为实的典型）

- `cull.wgsl` push 无"主视图剔除启用位"，靠 host 填 marks 绕——本次改为 push 位显式语义。
- `smaa.rs` 用 `role_bytes.len() > 10000` 区分两张 LUT；`SMAA_SKIP` 建出 null 布局/集的死路。
- `shadow.rs` 拆出无消费者的 `cpu_visible` 死字段（真值在 remote 本地现算）。
- `residency.rs` 同一笔请求 mark_dirty/计数做两遍（第二遍为补丁叠加）。
- `frame.rs` 遮挡判据抄两遍、帧槽别名 5 个（`cull_frame/shadow_frame/…`）、`slot_now` 重复声明。
- `upload.rs` mesh 腿三态判定 3 份 + 尾部收账日志/第二次 dirty_rows 写入是死代码。
- `ledger.rs` 的 `rebuild_all` 自认无写入点（死字段）；加入/退出逻辑整段重复。
- 名称表 4 份（RenderMode 在 frame/shading/monitor 三处 + env 解析）。

### 3. 结构与封装

- 上帝函数/对象：`frames.rs::record_frame` ~1580 行、`frame.rs::draw_frame` ~1080 行、`residency_tick` ~505 行、`flush_uploads` ~645 行、`cluster.rs` 1300 行四层混居。
