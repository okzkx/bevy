## 阅读顺序

1. **PBR**：着色模型的底座，其余四篇的光照结果最终都要经它落地到像素。
2. **全局光照谱系**：先建立全景，再决定选哪一档。
3. **SCGI**：谱系里"世界空间缓存"新范式的个案深潜，代表工业界当前方向。
4. **体素渲染**：谱系里 VCT 一档的成败复盘与判别式（决策类 vs 数据类），步骤 8 分簇与 9.3 patch 池的 pattern 出处。
5. **虚拟纹理**：与 GI 正交的另一条轴——数据量上大世界时才需要，先储备。

## 与本项目的衔接

这五篇共享一个背景约束：ash_renderer 已有 bindless 双表（对象表/模型环/材质环）、GPU 视锥剔除、indirect 闭环（步骤 5.1~5.3）。GI 数据结构与虚拟纹理的页表本质都是"GPU 常驻的大块数据 + 查询时寻址"，与 bindless 方向同构；SCGI 篇与谱系篇里反复出现的"射线预算花在哪"问题，在无硬件光追时等价于"软件求交器怎么搭"——这是后续步骤最大的新增基建。

调研时间：2026-10-19 起陆续建档（SCGI/PBR/谱系/VT/体素五篇调研 2026-10-19~20，Filament 两篇源码参考 2026-10-22~23）。SCGI 尚在 Unity 预览阶段（目标 6.7 LTS），相关条目以官方帖为准，后续有正式版文档应回来更新。
