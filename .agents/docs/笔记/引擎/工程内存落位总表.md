# 工程内存落位总表：按写者分组的分配点盘点

全工程渲染相关内存在一个角色系统里定形：[`BufferRole::spec`](../../../../ash_renderer/src/render/core/device/memory/role.rs) 八种角色，每种一份 usage + 内存属性规格（必需属性不满足即报错，不降级），buffer 创建与挑内存类型都从这里读；图像不走角色系统（附件/资产图各自创建，统一 DEVICE_LOCAL）。

本表按**写者**分组盘点全部分配点——写者不同，安全机制就不同，判据即[《常驻绘制数据组织》](常驻绘制数据组织.md)的三问框架（多久变 × 量级 × 谁来写）；宿主直写的时机纪律与撕裂分析也在该篇 §6/§7，本文不重复。

## ① 宿主直写（HOST_VISIBLE 持久映射 ×2 帧槽；fence 之后 memcpy）

落点：`render/resident/tables/`、`render/passes/`：

| 数据（内容） | BufferRole | 写者·时机 | 消费者 |
|---|---|---|---|
| 帧 UBO：相机矩阵、逆矩阵、**环境光参数**（ambient_color）、方向光方向/颜色、着色模式、相机位置 | FrameUniform | 宿主帧首 fence 后整块重写 | set1 b0，全 pass |
| shadow UBO：**阴影参数**（级联矩阵、分割带、四×六平面、相机基） | FrameUniform | 同上 | 阴影/composite |
| bloom/SMAA 参数 UBO | FrameUniform | 同上 | 后期链 |
| cluster 均匀数据（tile 尺寸等） | Storage | 同上 | 簇构建 compute |
| 模型环：**模型矩阵** | Storage | 宿主直写**增量**（奇偶脏集，改动行每帧写） | 顶点着色器 |
| 材质环：**材质参数**（基色/metallic/roughness/reflectance/四贴图槽/采样器槽） | Storage | 宿主直写**全量**（每帧从资产容器重投影） | 片元着色器 |
| 在场环：可绘行槽号列表 | Storage | 宿主直写全量 | build_indirect dispatch 上界 |
| LOD 表环/档位环：各档 first_index/count/vertex_base | Storage | 宿主直写增量 | 选档消费端 |
| 灯光常驻表（光源参数） | Storage | 宿主增量 | 光照 compute |
| UI 顶点/索引环（epaint 镶嵌产物，每帧整份重写） | DynamicDraw | 宿主直写全量 | overlay 图形管线 |

## ② 上传批次写一次（DEVICE_LOCAL；staging 经 transfer，换绑/换内容 = 新槽 + 停尸房）

落点：`render/resident/assets/`、`tables/instance_table.rs`：

| 数据（内容） | BufferRole | 写者·时机 | 消费者 |
|---|---|---|---|
| **网格**顶点/索引大池 | DevicePool | 上传批次 transfer 写一次 | 图形顶点拉取、compute |
| **纹理**（每资产一份 GpuImage） | ——（图像，DEVICE_LOCAL） | staging → `vkCmdCopyImage` 一次 | 片元按槽号 bindless 采样 |
| fallback 白图（缺贴图垫图，建表时一次） | 同上 | 同上 | 同上 |
| 对象表：mesh 区间三参数、**材质槽号**、局部包围盒 | DeviceStorage | staging 批次写一次，覆盖在结构上不存在 | 顶点着色器、剔除/组装 compute |

## ③ GPU compute 写

落点：`render/resident/tables/instance_table.rs`、`render/passes/`：

| 数据（内容） | BufferRole | 内存 | 消费者 |
|---|---|---|---|
| indirect 命令环（每在场行一条绘制命令） | IndirectCommands | DEVICE_LOCAL ×2 帧槽 | `cmd_draw_indexed_indirect`，宿主不碰 |
| 阴影命令环、透明命令环 | IndirectCommands | 同上 | 各自 dispatch |
| 透明索引表/键表（排序输入） | DeviceStorage | DEVICE_LOCAL | 排序 compute |
| 簇列表（tile → 灯号） | DeviceStorage | DEVICE_LOCAL | 光照 compute |
| 缺口标记环（驻留缺口请求） | Storage | HOST_VISIBLE ×2 | **GPU 写，宿主读**：帧尾读进 GapSnapshot → 驻留管理器 |
| 可见/遮挡标记环（cull 与遮挡判定） | Storage | 同上 | GPU 写，宿主 BRP 对账读（诊断） |
| 阴影标记环（cascade 内选档） | Storage | 同上 | GPU 写，shadow_stats 参照 |
| 簇计数 | Storage | 同上 | GPU 写，cluster census 读 |

## ④ 附件与交换链（DEVICE_LOCAL 图像）

落点：`render/core/target/attachment.rs`、swapchain：

| 数据 | 内存 | 备注 |
|---|---|---|
| G-buffer 附件（几何 pass 全屏输出） | DEVICE_LOCAL | 光照 pass 读回 |
| HDR 光照累积目标 | 同上 | 光照+透明混合同一张，全程线性域 |
| 阴影图（级联） | DEVICE_LOCAL | 阴影 pass 写，composite 采样 |
| Hi-Z 金字塔 | DEVICE_LOCAL mip 链 | 归约 compute 生成 |
| Bloom 链/SMAA 中间目标 | DEVICE_LOCAL | 后期链逐段 |
| 深度附件 | DEVICE_LOCAL | **附件重绑复用零拷贝**：G-buffer 写 → 透明 LOAD 测 → Hi-Z 读，换布局不换内存 |
| swapchain 底板 | DEVICE_LOCAL | UNORM 底板 + SRGB view 别名（mutable_format），唯一 sRGB 编码点 |

## ⑤ 通道性短命内存

落点：`render/core/device/transfer/uploader.rs`、`readback.rs`：

| 数据 | BufferRole | 内存 | 生命周期 |
|---|---|---|---|
| staging（上传批次暂存） | Staging | HOST_VISIBLE+COHERENT | 宿主写 → transfer 读，批次完即焚 |
| 一次性回读（Hi-Z 深度探针、句柄交换凭证） | Readback | HOST_VISIBLE+CACHED | transfer 写 → 宿主等 fence 读，用毕即销 |

## ②③ 的对偶

②③的宿主可见性正好对偶——②全 DEVICE_LOCAL（宿主碰不到，必须走命令），③里 GPU 写的产物若要宿主读（诊断/流送请求），就必须付出 HOST_VISIBLE 的代价，角色系统把这个取舍压成一行规格。
