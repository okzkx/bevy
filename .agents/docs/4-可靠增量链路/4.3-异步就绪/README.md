# 4.3 异步就绪——pending 账面、失败取消与动态加载

对应[步骤 4 README](../README.md) 与[路线图](../../学习目标实现步骤.md)。主计划=[施工计划：异步就绪与失败取消](施工计划：异步就绪与失败取消.md)；本 README 是段任务面板（**状态：⬜ 已立案 2026-10-12，未施工**——任务清单与判定线均为草案，开工时按计划定稿）。

## 任务清单（4.3.1~4.3.4 草案）

- [ ] **4.3.1 pending 账面与就绪门**：未到货资产的显式状态账（账本行内状态 vs 独立资源，施工钉明）取代 flush 内隐式计数；就绪判定口径（`Assets::get` 命中 vs `LoadedWithDependencies` 依赖链完整性，探针钉明）；等待帧数/到货计量。
- [ ] **4.3.2 失败与取消读侧**：`AssetLoadFailedEvent` 读侧接入（现行零读侧）；失败身份出重试队列 + 错误落账 + 计量；到货瞬间有效性检查——行已清账不上传（不错误复活）、行已换柄只服务新句柄。
- [ ] **4.3.3 BRP 动态加载方法族**：运行期加载驱动（路径→`AssetServer.load`→挂新实体/替换句柄）+ 资产状态读数（pending/failed/到货计数入 `increment_stats` 族）；`tools/brp.py` 子命令。
- [ ] **4.3.4 验收回归**：判定线全量 + 计量报告 + 既有判定线零回退。

## 判定线（计划 §0 草案）

延迟到货不读空槽（未到货帧画面照常、到货帧正确上屏）；失败可见且不无限重试（出队、计量可见、宿主存活）；等待期间删除或换柄不错误复活；零变化零上传不回退（pending 数/等待帧数/失败数/到货数/上传字节分开报）；既有判定线零回退（3.5 三模式 / 零 VUID 含拆 Device / WM_CLOSE exit 0 / clippy 全净 / 4.1 五类变更 / 4.2 全量）。
