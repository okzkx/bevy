## 判定线（草案）

- L1 状态机：恢复、再次失败、取消、同身份复用四类转换的最终账面不随系统调度顺序变化（针对 F4/F6/F7/F8/F9）；CPU 探针以正确行为断言全过。
- L2 输入边界：非法资产路径/标签经 BRP 动态加载返回协议错误，零 panic、宿主存活（F5）；多项 mutate 失败不留半完成状态（F11）。
- L3 统计口径：空事件帧当帧字段归零、累计量只增、存量另列（F10）。
- L4 失败路径：init 失败不再销毁在飞上传（F12）；Swapchain 半建失败无句柄泄漏（F13）；同尺寸 OUT_OF_DATE 不空转（F14）。
- L5 GPU 寿命：贴图更新不再覆盖在飞消费的描述符（F1）；共享采样器有独立所有权，A/B 共享先卸载所有者不悬空（F2）；停尸房排空双条件齐备（F3）。GPU 项关闭口径 = 代码内可见同步/寿命保证 + 适用运行证据，零 VUID 不单独构成关闭。
- L6 overlay：图集旧代走退役账，graveyard 水位有界（F15）。
- L7 防御与平台：F16~F21 逐条按清单方向落地或明示保留理由。
- L8 回归：既有判定线零回退——clippy 全净（禁 cargo fmt）、渲染主路径正常帧零 VUID、WM_CLOSE 优雅退出 exit 0。
- L9 注释同真：3.1 节九处注释失真与 F9 注释订正随修复同一提交收口。
