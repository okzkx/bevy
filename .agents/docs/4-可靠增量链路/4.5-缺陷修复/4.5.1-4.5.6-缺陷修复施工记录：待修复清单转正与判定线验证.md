## 1. 四问体例（按任务）

### 4.5.1 BRP 输入边界与 mutate 一致性（F5、F11）

**做了什么**：`object_ops` 增 `parse_asset_path`（`AssetPath::try_parse` 预校验→owned），`load_mesh_rebind`/`spawn_with_loaded_mesh`/`load_image_slot` 三封装统一走预校验；`reload_asset_cmd` 同口径；`ObjectOpError::InvalidAssetPath` → BRP `invalid_params`。`mutate_asset` 重排为"只读预校验段（就地收集换槽源槽柄/tint 目标柄，`Assets::get` 不触发 Modified）→ 执行段 get_mut 落改"，tint 前置校验拆 `check_tint_rgba8` + `tint_format_supported` 单一清单。

**验证**：探针 f5/f11；BRP reload 负例。

### 4.5.2 失败恢复状态机统一（F4、F6、F7、F8、F9、F10）

**做了什么**：`track_asset_failures` 整体退役，失败记账（LoadFailedEvent 三类）并入 `propagate_asset_changes` 单系统，系统内固定次序"先失败记账、后 AssetEvent 复活/重挂"（F4）；`expel_mesh/image` 移出 `warned.insert` 日志去重条件（F6）；材质复活集纳入早退条件（F7）；`Unused` 同步出清三类失败记录（F8）；`Added` 无条件参与复活/重挂、订正"能发 Removed 必无行引用"模块注释（F9）；帧窗口统计每帧先落账再谈早退、`asset_invalidations_total` 改累计只增、存量另列 `asset_invalidations_current`（IncrementStats/BRP stats 同步）、`dirty_rows` 在清标点定案（F10）。

**验证**：探针 f4/f6/f7/f8/f9/f10；旧探针的两顺序对立实验随单入口消亡（不再存在第二种合法调度）。

### 4.5.3 Vulkan 失败路径（F12、F13、F14）

**做了什么**：`try_init_vulkan` 在 Uploader 建成后插 `InitDrainGuard`（持 Device 克隆，Drop 时 `device_wait_idle`）——失败逆序 Drop 中护栏最先析构，半建资源不再在在飞 transfer 消费时析构（D4 补上失败路径缺口）；成功路径 `mem::forget` 让位 teardown 序。`Swapchain::new` views/render_finished 两环失败路径照 images 段全有或全无回收。`acquire` OUT_OF_DATE 分支重建后置 `gate.pending = true`（同尺寸表面失配由帧首闸门③接管）。

**取舍**：护栏方案优于"Uploader::Drop 自等票据"——tables（含 fallback GpuImage）先于 uploader 析构，仅等票据盖不住"表本体先销毁"的窗口；wait_idle 是唯一同时覆盖两者的收口点。

### 4.5.4 GPU 寿命三题（F1、F2、F3）

**做了什么**：`rebind`（原槽重写）整体退役——UAB 只授权"提交前后可更新可观察"，不授权覆盖仍被未完成命令消费的描述符（规范 descriptorsets.adoc ~4707-4729，验收复核 §7）；换内容重传改 `publish`（新槽）+ `ImageCache::swap_commit`（旧条目原子退场：旧图+票据进停尸房、旧纹理槽进 retire 账）。采样器本体所有权移交 `BindlessTables`（`sampler_bodies` 按槽持账，`SamplerKey::create_sampler` 按键建本体；`GpuImage` 不再建采样器）；槽退场 = 本体随待销毁账在排空点 `vkDestroySampler`。贴图/网格停尸房条目带上传票据，排空双条件 = 帧槽 fence + 票据时间线信号量（取最大值一次等待）。

**取舍**（钉明）：①"纹理槽占用不因内容变化增长"（4.2.3）被放弃——换内容每代新槽、旧槽经排空点一帧后归还 free list；换取的是在飞 draw 的描述符覆盖安全，槽容量 1024 下快速连续重传的 churn 未压测（§4 遗留）。②采样器共享语义不变（同键同槽），变的是槽内句柄不再随任何一张图生灭。③半建失败槽位回滚（publish 内纹理/采样器两槽归还 free list，账目不漂移）。

**验证**：clippy + 正常渲染零 VUID + exit 0；A/B 共享先卸载所有者等三场景的 GPU 复现未执行（见 §4）。

### 4.5.5 overlay 图集退役接账（F15）

**做了什么**：`AtlasGpu` 停尸房改 `(GpuImage, Ticket)`；整传换代时旧纹理槽 `retire_texture`（采样器槽不退——LINEAR 键与真实贴图共享）、旧本体进停尸房；`drain_graveyard`（双条件）挂进 flush_uploads 统一排空点（`UploadData.atlas: Option<ResMut<AtlasGpu>>`，overlay 未装 no-op）。graveyard 与纹理槽不再无界积聚。

### 4.5.6 防御缺口、平台泛化与小账（F16~F21 + §3.1 + §3.4）

**做了什么**：`scene_tree` 深度上限 1024 回 BrpError；mesh POSITION 长度核对升运行时检查（`PositionLengthMismatch`），NORMAL/UV_0 长度不符降级全零；材质缝 hook_count≠1 升 warn；相机 1° 越线升 warn；bevy_remote HTTP 层 Content-Length 上限 16 MiB 超限 413（F20 本层可做部分；上游分块读取无界记录在案）；`R8G8B8A8_UNORM` 补 SRGB 别名分支（`srgb_alias_if_supported` 共用查询）。注释九处订正 + 小账七项（expect 退役、死参数删除、AmbiguousCamera 分支、tier_handler 低档分流、fatal_gate 锚 First 集、spirv-val 混 pid、id_salt 混实体号、无灯占位向量拆共享常量 `PLACEHOLDER_DIR_TO_LIGHT`）。

**保留**（计划边界内明示）：F22 IME/剪贴板/光标桥接（功能级新增，不在缺陷修复边界）；计量欠账（耗时/上屏延迟测量未做）；input.rs 扩展鼠标键折叠（理论面）；init.rs FramePool/Uploader 半建依赖 Device 兜底（首建失败即退出，危害低）。

## 3. 待决钉子

1. **F1 槽位 churn**：换内容重传从"原槽重写"改"新槽+延迟回收"，槽容量 1024 下的极端 churn 未压测；步骤 5 若引入淘汰/流送需一并评估容量策略。
2. **F4 复活成本**：`Added` 无条件重挂在初始加载期会重复标脏已脏行（幂等零成本），大量实体反复重插场景的成本未测。
3. **F6 循环级未复现**：转换拒绝→复活→再拒绝的完整循环需畸形资产驱动，本轮只验证了账面语义（f6）与代码路径；运行级复现挂账。
4. **GPU 交叠窗口**：F1/F2/F3 的竞态窗口无确定性复现手段，关闭依据 = 代码级同步/寿命保证 + 正常路径运行证据；V1 验证环境建立后可补 present_wait 级严格验证（缺陷文档 §4 同源挂账）。
5. **计量欠账**：分阶段处理耗时、文件修改→上屏延迟仍未测（随步骤 5 相关修复补）。
