# 施工计划：右上角坐标轴指示器

> 2026-10-14 立案，同日开工。用户指令："右上角坐标轴需求放在 4.7，并开始实施"。做主窗右上角的视图朝向指示器（Unity Scene 视图右上角同款）：三色坐标线随相机旋转实时反映世界三轴在画面上的朝向。开工前先读：[代码生成规范 §3](../../../rules/代码生成规范.md)（注释两纪律）、[测试规范与方式](../../../rules/测试规范与方式.md)（BRP 首选）、[画面功能视觉验证](../../../rules/画面功能视觉验证.md)（截图读图）。
>
> **状态：✅ 收官（2026-10-14）。**判定线 L1~L4 全过，详[施工记录](4.7.1-右上角坐标轴指示器施工记录：视空间投影与拖拽跟拍验证.md)。

## 需求定界

- **做**：屏幕空间姿态指示器——右上角固定位置画背景圆盘 + 世界 X/Y/Z 三条轴线的正交投影，轴线颜色 Unity 惯例（X 红 / Y 绿 / Z 蓝），朝向观察者（视空间 z<0）的轴高亮加粗、背向的压暗，轴端标 X/Y/Z 字母。
- **不做**：点击轴线对齐相机、正交/透视切换、场景内随物体走的拖拽 gizmo（场景内 gizmo 已登记[外置拓展需求条目 4](../../../外置拓展需求.md)）；本段是纯显示 widget，零写路径。

## 技术路线

- 数据源 = `Query<&GlobalTransform, With<Camera>>`（本工程单相机，scene 用裸 `Camera`）；取旋转的逆把世界三轴变换到视空间（相机看 -Z），屏幕投影取 `(d.x, -d.y)` 归一化到盘半径，`d.z` 定亮暗。相机缺席时整帧让路不画。
- 画法 = egui painter 纯形状（圆盘 + 线段 + 字母标签），走既有 `EguiFrame` shapes 通道，**零新增 GPU 资源、零新增账面**；字母用已有拉丁字体，图集零增量。
- 挂接 = 照 `debug_hub_window.rs` 头注的加窗三步：独立 rs 文件 struct + `DebugWindowsOpen` 加开关字段 + 总控 checkbox + `run_egui_pass` 显示门。新模块 `overlay/axis_gizmo.rs`。

## 判定线

- **L1 常驻可见可关**：主窗右上角出现三色坐标轴指示器（截图取证）；总控 checkbox 关闭后消失、再开恢复。
- **L2 朝向正确**：默认相机姿态（视向 -Z）下 Z 线朝观察者高亮、X 朝右、Y 朝上；BRP `set_transform` 把相机转到已知姿态（yaw +90°、pitch 低头等）后指示器逐轴转动方向与场景视图一致（多姿态截图读图判定）。
- **L3 实时联动**：3.13 BRP 虚拟鼠标在视口拖拽 orbit 旋转相机，连拍截图指示器逐帧跟随，无可视断裂。
- **L4 零回归**：零 VUID、WM_CLOSE exit 0、clippy 全净；既有调试窗口与稳态零上传判定线零回退。

## 任务拆解

- **4.7.1 指示器施工**：`axis_gizmo.rs` 模块（投影数学 + egui painter）+ `DebugWindowsOpen.axis_gizmo` 开关（默认开）+ 总控 checkbox + pass 显示门接线。
- **4.7.2 收尾**：施工记录 + 三处状态流转。无新机制/新数据流（纯 overlay 读侧 widget，走既有 egui shapes 通道），免功能流程导读。

## 测试方案

- 运行冒烟（4.6 同款 `.temp/` 脚本）：启动 → BRP 负例 → 连拍截图 → WM_CLOSE exit 0；截图进 `.temp/4.7/`，当前会话模型读图判定（不比哈希）。
- L2 相机姿态三连：BRP `set_transform` 改相机 `rotation_euler_deg` = `[0,0,0]` / `[90,0,0]`（yaw 右转 90°）/ `[0,-45,0]`（pitch 低头），逐姿态连拍读图。
- L3 虚拟鼠标 orbit 拖拽（3.13 mouse 命令族）+ 连拍。
- L1 开关切换前后各一张截图。
- `cargo clippy -p ash_renderer --all-targets` 全净（手工排版仓库，不跑 cargo fmt）。

## 边界

- 多相机语义本段不定义：查询取任一 `With<Camera>`（本工程单相机），将来多相机需要时另定取法。
- 不新增 BRP 方法族（显示 widget 无运行时操作面；验证全用既有 `set_transform` 与 mouse 命令）。
- 位置与半径等视觉参数一次定死（margin 24pt、半径 34pt 量级），不做设置项。
