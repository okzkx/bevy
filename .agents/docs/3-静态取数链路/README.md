# 步骤 3：静态取数链路——glTF → Query → bindless 画出来（M2）

对应[执行路线图](../学习目标实现步骤.md)。主计划与本索引留步骤根目录，各段任务面板在段目录，其余专题在材料目录；现有 3.1～3.5 编号不变。

**目的**：打通 Assets 到 GPU 常驻资源、合批上传与 descriptor indexing 的正确静态版本。

**状态：✅ 3.1～3.8 全段收官（3.1~3.5 于 2026-09-29、追加段 3.6/3.7/3.8 于 2026-10-08）。**3.1 采集、3.2 上传、3.3 贴图+bindless 描述符、3.4 管线与绘制、3.5 光照对照均已验收（探针 + 宿主实跑证据，各段 README 逐项标注）；FlightHelmet 六 primitive 在自研管线中受 UBO 数据驱动光照画出，与官方 bevy_render 独立进程并排对照通过（几何/base color/光照方向分项），全程零 VUID。步骤 4（可靠增量链路）解禁；**收官后追加段 3.6（代码全量整理）、3.7（egui 调试 GUI——overlay 可见可交互、判定线五条全过）、3.8（system 标注宏）已收官 2026-10-08；追加段 3.9（鼠标摄像机控制——左键环绕/滚轮推拉/egui 层仲裁门判定线全过）已收官 2026-10-09**（2026-09-29 用户增补 3.6/3.7，2026-10-08/09 增补 3.8/3.9）。**2026-10-09 用户再增补追加段 3.10（egui 实体层级树）、3.11（egui 实体编辑）、3.12（CLI 直控/AI 通道）——3.10 已于同日收官**（独立窗口 struct + 调试窗口总控 + 相关实体过滤，判定线全过），3.11/3.12 待施工，依赖顺序 3.10→3.11→3.12 一次一段，施工上先于步骤 4；交付范围与验收草案见[路线图](../学习目标实现步骤.md)步骤 3 节尾，段目录随开工立。

## 验收资产与图示边界

FlightHelmet 有六个 primitive、六个材质、十五张去重贴图，其中镜片为 BLEND、Hose 为双面。M2 不做完整透明，但几何测试要用两侧一致的不透明覆盖保留六个 primitive；生产材质差异单列，不静默丢弃后声称完整。

主计划的旧跨帧图仅作历史链接保存，不再嵌入现行执行流程。当前同帧时序以主计划 §2 表格为准；本轮不生成新图、不宣称旧图已完成语义更新。
