对应[执行路线图](../学习目标实现步骤.md)。主计划与本索引留步骤根目录，各段任务面板在段目录，其余专题在材料目录；现有 3.1～3.5 编号不变。

## 验收资产与图示边界

FlightHelmet 有六个 primitive、六个材质、十五张去重贴图，其中镜片为 BLEND、Hose 为双面。M2 不做完整透明，但几何测试要用两侧一致的不透明覆盖保留六个 primitive；生产材质差异单列，不静默丢弃后声称完整。

主计划的旧跨帧图仅作历史链接保存，不再嵌入现行执行流程。当前同帧时序以主计划 §2 表格为准；本轮不生成新图、不宣称旧图已完成语义更新。
