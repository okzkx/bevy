## §2 第二批 P1:任务点名的两个摊薄评估(3.7 钩子前置)

### host.rs(668 行)

`draw_frame` 本体约 290 行,一个函数混六件事:resize 闸门 → 等槽 → acquire → DrawList 组装 → 相机/灯光 UBO 组装 → 录制提交+present。摊薄方向(建议,动不动拍板):

- 闸门状态机(`ResizeGate`)、DrawList 组装、帧 UBO 组装拆成 host/ 下小模块或同文件私有函数段;
