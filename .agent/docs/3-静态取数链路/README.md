# 步骤 3：静态取数链路——glTF → Query → bindless 画出来（M2）

对应[执行路线图](../学习目标实现步骤.md)。主计划与本索引留步骤根目录，各段任务面板在段目录，其余专题在材料目录；现有 3.1～3.5 编号不变。

**目的**：打通 Assets 到 GPU 常驻资源、合批上传与 descriptor indexing 的正确静态版本。

**完成标准**：FlightHelmet 六个 primitive 在统一不透明调试模式下核对完整几何，base color/UV 与光照方向分别做受控对照；同步和生命周期有验证层开启的证据。不是完整透明/PBR 一致性验收。

**状态：🚧 3.1 已收官，3.2 进行中。**3.2.1 已实现队列与 Vulkan 1.3 基线，但 timeline 显式启用回归待修；3.2.2 及后续上传、描述符、正式 draw 尚未实现。当前 GPU 端仍是清屏。

## 验收资产与图示边界

FlightHelmet 有六个 primitive、六个材质、十五张去重贴图，其中镜片为 BLEND、Hose 为双面。M2 不做完整透明，但几何测试要用两侧一致的不透明覆盖保留六个 primitive；生产材质差异单列，不静默丢弃后声称完整。
